`DirectionIcon`과 공통 `SvgIcon`이 원본의 투명도를 이용해 현재 컨트롤의 테마 글자색을 입힌다.
숫자 입력, 드롭다운, 스크롤바는 기존 Fluent 템플릿의 화살표 부분만 교체한다.
24×24 투명 영역의 중심을 기존 화살표 자리의 중심에 맞추며 버튼의 클릭 영역과 상태는 유지한다.
기록의 이전·다음, 날짜 펼침·접힘과 펫 관리의 방향 표시에 사용한다.
픽셀 에디터 UI는 제거했으며 기존 SVG 원본·viewBox·색상 적용 계약은 유지한다.

아이콘을 바꾸려면 같은 이름의 SVG를 교체한 뒤 빌드한다. 재생·일시정지·뒤집기 등 다른 의미의 아이콘은 포함하지 않는다.
