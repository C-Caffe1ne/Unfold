# 재생 아이콘

2026-09-30 사용자가 대화에 제공한 24×24 SVG를 원본 그대로 저장했다.

| 파일 | 사용자가 붙인 이름 | 앱에서 사용하는 상태 |
|---|---|---|
| `play.svg` | 재생 | 시작·계속 |
| `pause.svg` | 정지 | 일시정지 |
| `stop.svg` | 중지 | 타이머 중지 |

`PlaybackIcon`이 SVG의 투명도를 이용해 버튼의 현재 테마 글자색으로 표시한다.
타이머, 펫 팩 미리보기, 픽셀 에디터에서 함께 쓴다. 버튼의 접근성 이름과 동작은 각 화면이 관리한다.
