## 디자인 근거

- 현재 `src/Unfold.Desktop/DesignSystem.Themes.cs`의 오트·테라코타, 세이지, 라일락 색상.
- 현재 `web/index.html`의 '잠깐 쉬고, 내 리듬으로 돌아오세요'와 데스크톱 휴식 동료 포지셔닝.
- `Art/Characters/original-companions-v2/source/mochi-atlas.png`를 눈으로 확인하고 크림색 고양이, 둥근 윤곽, 기지개 동작을 2번 시안에 반영. 기존 캐릭터 자산은 편집하지 않음.

## 시안

- [01 / OPEN U](01-open-u.png): 펼쳐지는 U: 테라코타 리본과 열린 U로 Unfold의 이름을 표현.
- [02 / MOCHI STRETCH](02-mochi-stretch.png): 기지개 고양이: Mochi의 친근함과 스트레칭 동작을 직접 표현.
- [03 / BREATHING LEAF](03-breathing-leaf.png): 숨 고르는 잎: 세이지 색상과 펼쳐지는 유기적 U로 차분한 휴식을 표현.
- [04 / GENTLE PAUSE](04-gentle-pause.png): 휴식의 쉼표: 일시정지와 쉼표를 결합한 라일락 심벌.

모두 1536 × 1024 PNG. 생성 원본을 바이트 그대로 복사하고 SHA-256 동일성을 확인함. 네 시안의 Unfold 철자, 구성, 심벌·앱 아이콘·단색 예시를 시각 확인함. 배경이 포함된 시안이며 투명 PNG·SVG·ICO 납품 파일은 아님.
