# 기본 펫 포인터 전용 리소스

2026-09-24. 사용자가 요청한 고슴도치 공 모양, 나머지 4종의 뒷목이 들린 매달림,
포인터 업 이후 한 번 튕김과 자세 복귀를 위한 원본·재생 계약이다.

## 원본과 생성

- 도구: 내장 `image_gen`, 기존 펫 PNG를 참조한 새 포즈 생성. 외부 CLI/API는 사용하지 않았다.
- 전체 프롬프트와 참조 경로: [generation.md](generation.md).
- `source/<id>-pointer.png`: 생성된 1774×887 RGBA 원본, 펫별 4열×2행 8개 자세.
- `base/<id>/`: 추가 직전의 manifest와 런타임 시트를 보존한다. 이전 셀은 다시 그리지 않는다.
- `<id>-resource.json`: 원본·기존 시트·최종 시트 해시, 실제 자르기 영역, 크기 조정 비율,
  셀 배치, 내용 버전을 기록한다.

## 재생 계약

| 키 | 재생 | 모습 |
|---|---|---|
| `pickup` | 12fps, 4프레임, 한 번 | 원래 자세 → 접기/매달리기 시작 → 유지 자세 |
| `held` | 2fps, 4프레임, 반복 | 고슴도치는 얼굴·발이 숨겨진 공, 나머지는 매달림·깜빡임 |
| `land` | 10fps, 4프레임, 한 번 | 최종 착지 후 자세 복귀, 마지막은 원래 기본 셀 |

기존 10개 행동에 3개 선택 키를 추가했다. `unfold-original-v1` 프로필 및 10개 필수 키
계약은 그대로이며, 세 키가 모두 있고 정상 로드된 팩에 전용 모션을 적용한다.
일반 커스텀 팩은 기존 5개 행동을 유지한다.

포인터 업에서는 `held` 첫 셀을 고정해 한 번 튕긴다. 첫 바닥 접촉은 0.16초,
정점은 0.34초, 마지막 접촉은 0.52초이며 0.64초에 바운스를 끝낸다.
그 뒤 `land`를 재생하므로 고슴도치는 공 상태로 튕긴 다음에만 펼쳐진다.
이동하지 않은 클릭은 복귀를 마친 뒤 기존 `click` 클립으로 이어진다.

## 다시 적용하기

```sh
python3 Art/Characters/pointer-interactions-v1/build-assets.py
dotnet test Unfold.slnx -c Release --no-restore
dotnet src/Unfold.Desktop/bin/Release/net10.0/Unfold.dll --validate-characters
```

빌더는 원본 두 행 사이의 투명한 틈을 찾아 안전하게 자른 뒤, 펫별 한 가지 배율로
256px 셀에 맞춘다. 고해상도 생성 원본은 보존하고, 크기 조정은 패킹 과정에서만 수행한다.
기존 시트 하단에 두 행을 덧붙여 이전 픽셀·셀 인덱스·행동 타임라인을 보존한다.
v2/v3의 이전 빌더를 실행했다면 이 빌더를 마지막에 실행해야 새 행동을 복구할 수 있다.

| 펫 ID | 내용 버전 | 런타임 시트 |
|---|---|---|
| default-cat | 2.1.0 | 4×8셀 |
| bori-rabbit | 0.3.0 | 4×8셀 |
| puppy-dog | 0.2.0 | 4×6셀 |
| hedgehog | 0.2.0 | 4×6셀 |
| penguin | 0.2.0 | 4×6셀 |

실행 경로: `Assets/Characters/<id>/character.json`, `spritesheet.png`.
앱 배포 버전과 내용 버전은 별개다. 생성 도구 출력과 코드 검수는 사람이 실제 입력으로
전체 애니메이션을 승인한 것과 구분한다.
