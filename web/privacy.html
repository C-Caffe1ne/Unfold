현재 앱의 데이터 사용 방식

사용 행태를 추적하지 않습니다. 어떤 화면을 봤는지, 얼마나 자주 썼는지 수집하는 코드가 없습니다.

키 입력이나 실행 중인 프로그램을 보지 않습니다. 자리 비움 판단에는 운영체제가 알려 주는 "마지막 입력 이후 경과 시간"만 씁니다. 무엇을 눌렀는지는 알 수 없고 기록하지도 않습니다.

광고와 제3자 분석 도구를 넣지 않습니다.

완료 기록은 운동량을 측정한 값이 아닙니다. 완료 버튼을 누른 시각과 앱에서 진행한 휴식 시간을 기록합니다.

이 웹사이트에 저장되는 설정

선택한 색상 테마는 이 브라우저에 저장됩니다. 계정 정보와 연결하지 않으며, 브라우저의 사이트 데이터를 지우면 초기화됩니다.

다운로드 화면의 운영체제 안내는 브라우저 안에서 처리합니다. Mac의 칩 종류는 자동으로 판단하지 않습니다.

결제 정보

결제는 Lemon Squeezy가 처리하도록 연결할 예정입니다. 카드 번호를 비롯한 결제 수단 정보는 Unfold가 직접 저장하지 않고, 결제 화면은 브라우저에서 열리도록 설계합니다. 실제 수집 항목과 보관 기간은 서비스 공개 전에 확정합니다.

계정과 데이터 삭제 안내

현재는 이 사이트에서 계정을 만들 수 없습니다. 계정 삭제 방법과 처리 기한은 가입 기능을 공개하기 전에 안내하겠습니다. 앱의 로컬 데이터 위치는 설치 안내에서 확인할 수 있습니다.
