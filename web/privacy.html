하지 않는 것

사용 행태를 추적하지 않습니다. 어떤 화면을 봤는지, 얼마나 자주 썼는지 수집하는 코드가 없습니다.

키 입력이나 실행 중인 프로그램을 보지 않습니다. 자리 비움 판단에는 운영체제가 알려 주는 "마지막 입력 이후 경과 시간"만 씁니다. 무엇을 눌렀는지는 알 수 없고 기록하지도 않습니다.

광고와 제3자 분석 도구를 넣지 않습니다.

완료 기록은 운동량이 아닙니다. 사용자가 완료 버튼을 누른 시각과 시간일 뿐이고, 건강 정보로 다루지 않습니다.

결제 정보

결제는 Lemon Squeezy가 처리하도록 연결할 예정입니다. 카드 번호를 비롯한 결제 수단 정보는 Unfold가 직접 저장하지 않고, 결제 화면은 브라우저에서 열리도록 설계합니다. 실제 수집 항목과 보관 기간은 서비스 공개 전에 확정합니다.

계정을 지우고 싶다면

출시 전 계정 삭제 방법과 처리 기한을 확정해 이곳에 안내합니다. 계정을 삭제해도 컴퓨터에 있는 기록과 설정은 자동으로 지워지지 않으므로, 로컬 데이터 삭제 방법도 설치 안내에 함께 제공합니다.
