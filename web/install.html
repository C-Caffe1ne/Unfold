설치 안내

설치 관리자 없이 압축을 푸는 방식입니다. 처음 실행할 때 운영체제가 확인 절차를 요구하는데, 아래 순서대로 하시면 됩니다.

ℹ
공개 다운로드는 준비 중입니다

아래는 현재 개발 버전의 설치 절차입니다. 공개 파일이 준비되면 계정 페이지에 다운로드 링크와 설치 안내를 함께 제공하겠습니다.

  1. 내려받은 ZIP을 풉니다

    Apple 메뉴 → ‘이 Mac에 관하여’에서 칩을 확인하세요. Apple M 시리즈는 Apple Silicon(arm64), Intel 프로세서는 Intel(x64) 파일을 선택합니다.

  2. Unfold.app을 응용 프로그램 폴더로 옮깁니다

    자동 실행을 켜기 전에 사용할 위치로 옮겨 주세요. 나중에 위치를 바꾸면 자동 실행 설정을 다시 켜야 합니다.

  3. Unfold.app을 엽니다

    공개 배포본은 Developer ID 서명과 Apple 공증을 마친 뒤 제공합니다. 운영체제가 개발자를 확인할 수 없다고 표시하면 실행하지 말고 배포 상태를 확인해 주세요.

  4. 메뉴바에서 Unfold를 확인하세요

    설정 창을 닫아도 메뉴바에 남아 계속 실행됩니다. 완전히 끄려면 메뉴에서 Unfold 종료를 누르세요.

⚠
테스트 배포본과 공개 배포본은 다릅니다

현재 내부 테스트 번들은 Apple 공증 전입니다. 이 사이트에서는 서명·공증을 마친 파일만 공개하고, 다운로드 화면에 검증 상태를 함께 표시할 예정입니다.

  1. ZIP 전체를 압축 해제합니다

    압축 파일 안에서 바로 실행하면 동작하지 않습니다. 반드시 폴더로 풀어 주세요.

  2. 폴더 구조를 그대로 둡니다

    Unfold.cmd 옆의 app 폴더를 같이 두어야 합니다. 실행 파일과 리소스가 그 안에 있습니다.

  3. Unfold.cmd를 더블클릭합니다

    공개 배포본은 코드 서명을 마친 뒤 제공합니다. SmartScreen이 게시자를 확인하지 못하면 실행하지 말고 다운로드 화면의 서명 상태를 확인해 주세요.

  4. 작업 표시줄의 트레이를 확인하세요

    설정 창을 닫아도 트레이에 남아 계속 실행됩니다. 완전히 끄려면 트레이 메뉴에서 Unfold 종료를 누르세요.

⚠
테스트 배포본과 공개 배포본은 다릅니다

현재 내부 테스트 번들은 코드 서명 전입니다. 이 사이트에서는 서명된 파일과 SHA-256 값을 함께 제공하고, 실제 Windows에서 확인한 결과도 표시할 예정입니다.

설치 후 알아 두면 좋은 것

자동 업데이트가 없습니다. 새 버전이 나오면 변경 이력에 올립니다. 받아서 같은 자리에 덮어쓰면 설정과 기록은 그대로 유지됩니다.

설정과 기록이 저장되는 곳. Windows는 %LOCALAPPDATA%\Unfold\, macOS는 ~/Library/Application Support/Unfold/입니다. 앱을 지워도 이 폴더는 남습니다.

로그인 시 자동 실행. 설정에서 켤 수 있습니다. 앱을 최종 위치로 옮긴 뒤에 켜 주세요. 나중에 위치를 바꾸면 껐다가 다시 켜야 합니다.

문제가 생겼다면

데이터 폴더의 unfold.log에서 오류 기록을 확인할 수 있습니다. 공식 문의 채널은 공개 다운로드를 시작할 때 함께 안내하겠습니다.
