# Unfold 판매 웹 디자인 시안 4종

기존 웹사이트와 별개로 만든 HTML/CSS/JavaScript 시안이다. 현재 사이트의 HTML 구조를 복제하지 않고 네 가지 레이아웃과 시각 방향을 설계했다.

## 미리보기

현재 로컬 서버: http://127.0.0.1:4188/

| 시안 | 화면 구성 | 색상과 글꼴 | 모션 |
| --- | --- | --- | --- |
| A Quiet studio | 큰 영문 제목과 기울어진 펫 아치, 파일 형식 그리드, 좌우 앱 갤러리 | 크림·짙은 녹색·라임 / Geist | 이미지 확대·페이드, 갤러리 제목 고정 |
| B After hours | 한국어 제목과 펫을 나란히 배치, 원형 배경, 큰 앱 화면 | 딥 네이비·라임 / Cabinet Grotesk | 이미지 확대·페이드, 앱 카드 겹치기 |
| C Play club | 중앙의 큰 글자, 오렌지 포스터, 테두리와 선이 강조된 앱 카드 | 오렌지·버터 옐로 / Satoshi | 제목 고정, 앱 카드 겹치기 |
| D Daylight | 떠 있는 내비게이션, 중앙 제목, 펫이 놓인 부드러운 배경 | 스카이 블루·세이지 / Outfit | 글자 밝기 변화, 이미지 확대·페이드 |

비교 페이지의 데스크톱·모바일 버튼으로 화면을 전환하고, 각 카드에서 전체 시안을 열 수 있다. 갤러리, 메뉴, 구매 안내 창도 실제로 동작한다.

## 콘텐츠 기준

- 원하는 펫과 이미지·GIF·MP4·3D(GLB) 지원을 첫 화면과 기능 영역에 넣었다.
- 별도 펫 팩 미리보기 기능과 삭제된 화면은 포함하지 않았다.
- 실제 앱의 타이머·휴식 기록·휴식 알림 캡처를 사용했다. 캡처는 Beta v1.1.3 개발본이라는 표시를 유지했다.
- 긴 기능 설명 대신 짧은 제목과 화면을 사용했다. 실제 판매 상태와 Beta 이용 안내는 구매 영역에 유지했다.
- 4,900원은 세금 별도 테스트 기준가다. 이 시안은 결제나 이용 권한 발급을 실행하지 않는다.

## 검증

- Playwright CLI로 320·390·768·1440px의 네 시안, 총 16가지 화면 크기를 확인했다. 제목은 모두 두 줄이고 가로 넘침·누락 이미지·JavaScript 오류는 없었다.
- 85개 브라우저 동작 검사가 통과했다. 메뉴와 Escape, 키보드 갤러리·아코디언, 구매 안내 창과 초점 복원, 이미지 비율, 모션 감소 설정, 비교 페이지 전환을 포함한다.
- 후속 레이아웃 검증은 finish-layout-results.json에 기록했다. 수정 뒤에도 제목 고정, 첫 화면 높이, 로고 비율, 모바일 비교 페이지를 확인했다.
- 기존 웹사이트 public 파일 52개의 SHA-256이 시작 시점과 동일했다. 현재 사이트의 파일 변경·커밋·배포는 하지 않았다.
- Chromium의 로컬 브라우저 검증 결과다. 실제 결제·다운로드·앱 설치나 다른 브라우저의 검증 결과를 뜻하지 않는다.

측정 자료: capture-results.json, inspection-results.json, finish-layout-results.json, existing-site-integrity.json.

## 실행

```sh
python3 -m http.server 4188 --bind 127.0.0.1
```

이 디렉터리에서 실행하면 비교 페이지와 네 시안을 볼 수 있다. GSAP, 글꼴, 이미지는 로컬 파일로 포함했다. 글꼴 출처는 font-sources.txt에 기록했다.
