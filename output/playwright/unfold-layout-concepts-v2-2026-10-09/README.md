# Unfold 판매 웹 구조 시안 4종

기존 웹사이트 및 첫 번째 디자인 시안과 별개로 만들었다. 네 시안에 같은 중립색과 같은 실제 앱 자산을 적용하고, 첫 화면의 정보 배치와 탐색 방식부터 다르게 설계했다.

현재 로컬 비교 페이지: http://127.0.0.1:4189/

| 시안 | 첫 화면 | 탐색 방식 | 모바일 구성 |
| --- | --- | --- | --- |
| Field journal / 잡지 지면형 | 제목·펫·실제 앱을 세 칸으로 나눈 커버 | 목차에서 편집 지면과 앱 갤러리로 이동 | 제목 옆 작은 펫, 아래에 앱 지면 |
| App canvas / 앱 쇼케이스형 | 왼쪽 메뉴 레일, 큰 실제 앱 화면, 오른쪽 이용 안내 | 메뉴 레일과 화면 선택 탭 | 짧은 소개와 이용 안내 다음에 실제 앱 화면 |
| Pause journey / 가로 스토리형 | 첫 장면과 다음 장면의 일부, 아래 장면 선택 바 | 세로 스크롤을 가로 장면 이동으로 연결. 버튼도 사용 가능 | 가로 넘기기와 장면 선택 버튼 |
| Your pet library / 파일 형식 카탈로그형 | 형식 필터, 파일 카드, 구매 요약 | 이미지·GIF/MP4·3D(GLB) 필터 | 가로 필터와 2열 카드, 아래 이용 안내 |

비교 페이지에는 첫 화면·전체 구성·모바일 전환, 기본 흑백 보기와 선택적 색상 보기, 각 구조의 배치 도식을 넣었다.

## 제품 문구와 자료

- 원하는 펫을 넣을 수 있으며 이미지·GIF·MP4·3D(GLB)를 지원한다는 점을 유지했다.
- 삭제된 별도 펫 팩 미리보기 기능이나 그 화면은 넣지 않았다.
- 현재 앱의 타이머·휴식 기록·휴식 알림 캡처만 사용했다. Beta v1.1.3 개발본이라는 표시를 유지했다.
- 카탈로그는 지원 파일 형식을 탐색하는 웹 구성이다. 펫 판매 목록이나 앱에서 제거된 기능을 뜻하지 않는다.
- 4,900원은 기존 사이트의 세금 별도 테스트 기준가다. 이 시안의 구매 버튼은 이용 안내만 표시하며 결제·권한 발급을 실행하지 않는다.

## 검증

- 320·390·768·1440px, 총 16가지 화면에서 제목은 2~3줄이며 제목 잘림·가로 넘침·이미지 누락·JavaScript 오류가 없었다.
- 메뉴·Escape·키보드 조작·화면 선택·이미지 비율·형식 필터·구매 안내·초점 복원·모션 감소·가로 장면 이동·실제 고정 위치·비교 모드를 확인했다. 최종 브라우저 검사 79/79가 통과했다.
- 가로 스토리의 초기 고정 좌표 오류를 실제 좌표로 확인하고, 스토리 구간 ID를 직접 지정하도록 수정했다.
- 초점 복원은 native close 이벤트 이후, 색상 전환은 CSS 전환 완료 이후 검증했다. 초기 검사와 후속 검사 자료를 모두 보존했다.
- 기존 웹사이트 public 파일 52개의 SHA-256은 시작 시점과 동일했다. 현재 사이트를 수정·커밋·배포하지 않았다.

검증 자료: capture-results.json, inspection-results.json, finish-inspection-results.json, final-inspection-results.json, existing-site-integrity.json.

Chromium 로컬 브라우저에서 확인한 결과다. 실제 결제, Beta 설치, 다른 브라우저의 검증 결과를 뜻하지 않는다.

## 로컬 실행

이 디렉터리에서 실행한다.

```sh
python3 -m http.server 4189 --bind 127.0.0.1
```

글꼴·GSAP·이미지는 로컬 파일로 포함했다. 글꼴 출처는 font-sources.txt에 있다.
