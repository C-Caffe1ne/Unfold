# Unfold Release QA

## 절차

1. `docs/verification.md`에서 변경 범위에 맞는 검사를 고른다.
2. 테스트·진단 실행에는 새 임시 `UNFOLD_DATA_DIR`을 사용한다.
3. 상태 생산자와 소비자, 파일 manifest와 로더, UI 명령과 서비스 호출을 양쪽에서 교차 확인한다.
4. 검사 결과를 종료 코드와 핵심 수치로 기록한다. 새 근거 없이 이미 통과한 검사를 반복하지 않는다.
5. 결과를 `자동 검사`, `실제 macOS`, `실제 Windows`, `사람 검수`, `미검증`으로 나눈다.

## 보고서 구조

```markdown
# 릴리스 QA 감사
## 환경과 범위
## 실행한 명령과 결과
## 경계면 교차 검증
## 통과·실패·미검증
## 출시 차단 요소
## 다음 검증 순서
```

제품 코드와 기존 문서를 수정하지 말고 Task가 지정한 보고서만 작성한다.
