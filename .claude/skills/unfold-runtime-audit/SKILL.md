# Unfold Runtime Audit

## 절차

1. `docs/README.md`와 `docs/mvp.md`에서 현재 범위를 확인한다.
2. 프로젝트 파일과 빌드 입력을 먼저 확인하고 소비되지 않는 과거 소스는 제외한다.
3. UI 이벤트 → 상태/서비스 → 저장 → UI 갱신의 생산자·소비자 양쪽을 함께 읽는다.
4. 문서, 구현, 테스트의 불일치를 파일 근거와 함께 기록한다.
5. 후속 작업을 주 소유 파일, 의존 작업, 회귀 위험, 수용 기준으로 분해한다.

## 보고서 구조

```markdown
# C#·Avalonia 아키텍처 감사
## 현재 구성과 데이터 흐름
## 구현·문서 정합성

## 작업 분할과 파일 소유권
## 의존성·수용 기준
## 미검증 항목
```

제품 코드와 기존 문서를 수정하지 말고 Task가 지정한 보고서만 작성한다.
