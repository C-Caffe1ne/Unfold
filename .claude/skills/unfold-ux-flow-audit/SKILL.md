# Unfold UX Flow Audit

1. 사용자 목표별 시작점, 단계, 완료 피드백, 취소·복구 경로를 추적한다.
2. 같은 의미의 동작이 화면마다 다른 위치·이름·우선순위를 갖는지 확인한다.
3. 빈 상태와 비활성 상태가 사용자가 다음 행동을 알 수 있게 설명하는지 본다.
4. 문제마다 현재 흐름, 개선 흐름, 필요한 코드 소유권, 행동 기반 수용 기준을 적는다.
5. 구현되지 않은 서버·결제·계정 흐름을 해결책에 끼워 넣지 않는다.

보고서만 작성하고 제품 코드는 수정하지 않는다.
