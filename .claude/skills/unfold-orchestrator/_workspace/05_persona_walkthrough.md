# 05 · 페르소나 인지적 워크스루 (B2)

## 요약

- 설치 직후 첫 화면이 **설명 없는 로그인 벽**이다. 앱이 무엇을 하는지, 왜 로그인이 필요한지, 유료(무료 체험 없음)인지 한 줄도 없고 대안 버튼은 `Unfold 종료`뿐이다. 비개발 사용자(지민)의 가장 큰 이탈 지점이다.
- 휴식을 시작해도 **무엇을 할지 안내가 나오지 않는다**. 루틴 단계 텍스트는 코드에 존재(`BreakSession.CurrentStep`)하지만 말풍선은 대사·타이머·`완료`만 보여준다.
- 기존 사용자(수아)의 "작업 간격 50분으로 바꾸기"는 **타이머 진행 중 입력란이 비활성**인데 그 이유가 500ms 툴팁에만 있어 막힌다. 시간 설정이 홈과 설정 화면으로 쪼개져 있어 찾는 위치도 어긋난다.
- 제작자(도윤)에게는 **같은 동작 키의 한국어 이름이 화면마다 3종**으로 다르고, 커스텀 펫 에디터는 8개 동작 중 무엇이 채워졌는지 한눈에 보이지 않으며, 내보낸 뒤 초안이 전부 초기화돼 수정 재진입 경로가 없다.
- 펫 우클릭 메뉴와 트레이는 발견 단서가 전혀 없다. `펫 숨기기`를 누르면 화면의 유일한 단서가 사라지고 복구하려면 트레이의 존재를 이미 알아야 한다.

## 방법과 한계

- 방법: 세 페르소나(지민·도윤·수아)의 목표를 단계로 쪼개 각 단계에서 보이는 것 → 기대 → 실제 동작 → 어긋남을 기록하는 인지적 워크스루. 근거는 읽기 전용 소스(`/Users/hwanghyeonseong/.codex/worktrees/beta-v1-1-0/Unfold`)의 화면 문자열과 off-screen 렌더 캡처다.
- 한계: **정성적 시뮬레이션이며 통계적 근거가 아니다.** 아래 발견은 검증할 가설이지 입증된 사실이 아니다.
- 앱 실행·빌드·실조작을 하지 않았다. 실제 macOS/Windows 입력 반응, 실거래·OAuth 흐름, OS 파일 연결은 미검증이다.
- 마찰 점수는 1(막힘 없음)~5(목표 실패) 주관 척도다.
- 기존 확인 항목(QA-01 자동 미루기, A-02 펫 페이지 포커스, GLB 속도·종료 포즈, 로그아웃 버튼 활성, 픽셀 에디터 영어, 긴 펫 이름 잘림)과 MVP 범위 밖 기능(루틴/프로필 UI, 회의·전체화면 감지, 수동 "지금 스트레칭")의 부재는 발견으로 올리지 않았다.
