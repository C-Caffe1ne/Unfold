# Unfold UI Visual Audit

1. 현재 작업 트리에서 생성한 기본·최소·스크롤 PNG를 화면별로 묶어 본다.
2. 제목→설명→콘텐츠→주 행동의 계층과 정렬 축을 확인한다.
3. 빈 공간, 카드 중첩, 버튼 우선순위, 선택·비활성 상태, 글자 대비를 비교한다.
4. 공통 문제는 `DesignSystem.cs`·`Ui.cs`, 화면별 문제는 해당 View/Window 소유로 분리한다.
5. 각 문제에 근거 이미지, 사용자 영향, 심각도, 수정 방향과 시각 완료 기준을 적는다.

보고서만 작성하고 제품 코드는 수정하지 않는다.
