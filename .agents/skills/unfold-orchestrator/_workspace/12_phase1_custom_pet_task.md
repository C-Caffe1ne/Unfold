## 요구사항

- `파일 가져오기 → 동작에 넣기`와 각 동작 카드의 `파일 선택…` 모두 이미 파일이 있는 동작을 교체하기 전에 확인 대화상자를 표시한다.
- 확인 문구는 어떤 동작의 파일을 바꾸는지 알려야 한다. 선택지는 `바꾸기`, `취소`로 하고 취소를 안전한 기본 포커스로 유지한다.
- 취소하거나 제목 표시줄로 닫으면 기존 클립, 미리보기, 생성 가능 상태가 그대로 남아야 한다. 가져온 pending 파일도 사용자가 다른 동작에 넣을 수 있도록 유지한다.
- 교체를 승인했지만 새 파일 검증이 실패하면 기존 클립을 유지하는 현재 `CustomPetDraft.SetClip` 계약을 보존한다.
- `동작에 넣기`로 배정에 성공하면 `CustomPetAction`을 아직 비어 있는 다음 동작으로 이동한다. 뒤에 빈 동작이 없으면 앞에서부터 찾고, 모두 채워졌으면 현재 선택을 유지한다.
- UI 문체와 기존 `Ui.Confirm` 안전 규칙을 사용한다.

## 회귀 검사

- 기존 동작 교체에서 취소하면 기존 파일과 생성 가능 상태가 유지되는 테스트.
- 교체 승인 후 잘못된 파일이면 기존 파일이 유지되는 테스트.
- 배정 성공 후 선택기가 다음 빈 동작으로 이동하는 테스트.
- 관련 집중 테스트를 실행하고 결과를 보고한다. 전체 테스트는 감독자가 통합 후 실행한다.
