## 진단 실행

Release 빌드 후 새 테스트 프로필을 자동 생성하는 명령:

```sh
dotnet run --project src/Unfold.Desktop -c Release --no-build -- --smoke-test
```

결과 위치를 직접 정하려면 `UNFOLD_DATA_DIR`에 **새 빈 디렉터리**를 지정한다.
실제 사용자 라이브러리를 지정하면 진단 캐릭터가 저장되므로 사용하지 않는다.
프로필 아래 `verification/smoke.json`의 성공 여부와 오류를 확인한다.

이 진단은 off-screen Settings·펫·호환성 검사용 루틴/프로필 편집기·픽셀 에디터·펫 말풍선·
주간 회고를 만든다. 일반 설정 화면에는 루틴·프로필 진입점이 없는지 확인하고, 진단 전용 경로에서는 사용자 루틴 2개·프로필 저장, 프로필 적용 시 Pause 유지,
진행 중 편집 후 기존 세션 유지, 테스트 캐릭터 저장·재열기, 휴식 완료·미루기·닫기,
완료 기록 재로드와 CSV 1건 생성을 수행한다. 설정 창은 기본 크기와 860×680의 최소 크기,
오른쪽 홈 시간 카드·카드 스크롤과 별도 설정 탭의 알림·타이머 섹션도 캡처한다. 공통 확인·이름 입력·오류 창 3장과 각 페이지의
하단 작업 버튼이 창 안에 있는지도 확인한다. 진행 중 간격 입력 잠금, 일시정지 후 명시적 적용,
정지 상태에서 적용 후 00:00 유지, Pause·Stop 후 각각 1.2초간 대기 유지와 초대 닫기·생성 취소도 확인한다. 펫 팩 미리보기·설치·
업데이트·손상된 이미지 재설치·잘못된 파일 거부도 검사한다. 세션 시간, CSV 목적지와
팩 선택 경로는 프로그래밍 방식으로 지정하고 버튼 이벤트를 실행한다. 네이티브 효과음 재생은 억제하고 호출 횟수와 WAV 파일을 검사한다.
실제 파일 선택 창, 마우스/키보드 입력, 로그인, 전체 애니메이션 타이밍,
사용자의 신체 활동, 장시간 CPU/메모리는 검증하지 않는다.

## 펫 팩 재생 진단

Release 빌드 후 `.unfoldpet` 파일을 지정한다. 그래픽 세션이 있는 실제 OS에서 실행한다:

```sh
dotnet src/Unfold.Desktop/bin/Release/net10.0/Unfold.dll \
  --review-pet-pack /path/to/Bori-0.1.0.unfoldpet
```

`UNFOLD_DATA_DIR`을 생략하면 OS 임시 폴더에 `Unfold-review-<고유값>` 프로필을 만든다.
위치를 직접 지정할 때는 새 빈 디렉터리를 사용한다. 이미 파일이 있는 디렉터리는
아무 파일도 쓰기 전에 종료 코드 2로 거부한다. 이 경로는 팩을 테스트 라이브러리에
설치하므로 결과를 보존하려면 프로필 위치를 직접 정하는 편이 좋다.

실제 설치 창의 미리보기·설치 버튼 이벤트를 실행하고, 선택·Pause 유지·디스크 재열기를
확인한다. 실제 dispatcher와 경과 시간을 사용해 각 클립을 어두운/밝은 배경에서 192px로
재생한다. 반응 시작, 1회 완료 이벤트, 펫의 idle 복귀, 숨긴 상태의 유지를 검사한다.
클립이 10초를 넘으면 이 진단은 실패한다. 성공/오류는 프로필의
`verification/pet-review.json`, 화면은 같은 폴더의 PNG로 저장한다.

설치 전에는 미리보기 Pause가 반응 길이보다 오래 유지되는지, Replay가 다시 시작하는지,
반응 종료 후 선택 항목이 남는지도 확인한다. 192·384 논리 픽셀 전환과 큰 미리보기의
가로 넘침을 검사하고 밝은/어두운 배경을 2배 픽셀 크기로 캡처한다.
`previewControls`에는 해당 결과와 실제 창의 `windowRenderScaling`을 기록한다.
반응이 없는 팩은 이 부분의 일시정지·Replay 반응 검사를 생략하며 `reaction: null`로 표시한다.

창은 off-screen이며 파일 선택 경로를 주입한다. 실제 마우스·키보드·OS 파일 선택 창,
다중 모니터·DPI 변경과 모든 프레임의 시각적 자연스러움은 검증하지 않는다.
2배 렌더링 캡처가 고해상도 원본 제작이나 고DPI 최종 아트 승인을 뜻하지 않는다.
`observedMs`에는 캡처·
dispatcher 처리와 의도한 100ms 여유가 포함되므로 프레임 정확도나 성능 수치로 해석하지 않는다.
보리의 [원본 결과 JSON](validation/2026-09-14-bori-review.json)과
[검증 기록](validation/2026-09-14-bori-candidate.md)에 이 구분을 유지한다.
미리보기 조작 검사를 추가한 결과는 [미리보기 검증 기록](validation/2026-09-14-pet-pack-preview.md)에 있다.

## 실제 OS 확인

자동 검사와 별도로 아래 항목을 테스트한 OS·아키텍처·커밋·배포물과 함께 기록한다:

- 배포물 설치와 실행·종료, 트레이/메뉴바와 설정 창.
- 타이머·아이콘 조작·간격 적용, idle 자동 일시 정지, sleep/wake, 자동 알림.
- 펫의 idle → stretch → idle, Hide/Show와 재시작 후 설정·위치.
- 투명 배경, 드래그, 다중 모니터·DPI·모니터 분리, Windows 클릭 통과.
- 실제 말풍선 입력·소리 출력, 알림이 작업 집중에 주는 영향.
- 게시된 앱의 로그인 실행, 실제 다운로드 파일의 OS 신뢰·서명 상태.
- 60–90분 사용 중 안정성, 자원 사용, 반복 사용 의사.

Windows는 [실기 체크리스트](windows-dogfooding-log.md)를 사용한다. macOS에는
[2026-09-11의 부분 관찰 기록](validation/2026-09-11-macos-dogfooding.md)이 있다.
체크되지 않은 항목은 미검증이다. 다른 브랜치·OS 또는 과거 버전의 통과를 복사하지 않는다.
