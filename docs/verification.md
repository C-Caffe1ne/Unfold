# 검증 안내

## 자동 검사

저장소 루트에서 .NET SDK 10으로 실행한다:

```sh
dotnet restore Unfold.slnx --locked-mode
dotnet test Unfold.slnx -c Release --no-restore
```

빌드 서비스의 선택적 telemetry를 끄려면 `AVALONIA_TELEMETRY_OPTOUT=1`과
`DOTNET_CLI_TELEMETRY_OPTOUT=1`을 환경 변수로 지정한다. .NET 테스트 러너는 로컬
소켓을 사용하므로 소켓이 금지된 실행 환경에서는 테스트 시작 전에 중단될 수 있다.

C# 테스트는 픽셀 모델, PNG/Piskel 왕복, 실제 번들 GIF 디코딩, 라이브러리 저장·충돌·
복구, 타이머 idle/sleep 처리, 휴식 세션·루틴 저장·완료 기록과 리소스 검사를 다룬다.
headless Avalonia 테스트는 에디터·루틴 편집·휴식 창의 입력·배치·저장을 확인한다.
이 테스트는 실제 펫 창의 클릭 통과나 알림 전달의 증거가 아니다.

현재 개인화 기능의 결과는 [2026-09-13 2차 구현 검증](validation/2026-09-13-companion-stage2.md)에 있다.
이후 타이머 조작 변경은 [타이머 수정 검증](validation/2026-09-13-timer-controls.md)에 있다.
최신 병합 복구·펫 팩 설치 기반은 [펫 팩 검증](validation/2026-09-13-pet-packs.md)에 있다.
휴식 세션을 처음 추가한 결과는 [1차 구현 검증](validation/2026-09-13-companion-stage1.md)에 있다.
아래 정리 작업 기록의 36개 테스트·PNG 4장은 그 이전 상태의 결과다.

## 진단 실행

Release 빌드 후 새 테스트 프로필을 자동 생성하는 명령:

```sh
dotnet run --project src/Unfold.Desktop -c Release --no-build -- --smoke-test
```

결과 위치를 직접 정하려면 `UNFOLD_DATA_DIR`에 **새 빈 디렉터리**를 지정한다.
실제 사용자 라이브러리를 지정하면 진단 캐릭터가 저장되므로 사용하지 않는다.
프로필 아래 `verification/smoke.json`의 성공 여부와 오류를 확인한다.

이 진단은 off-screen Settings·펫·루틴/프로필 편집기·라이브러리·픽셀 에디터·리마인더·
주간 회고를 만든다. 사용자 루틴 2개·프로필 저장, 프로필 적용 시 Pause 유지,
진행 중 편집 후 기존 세션 유지, 테스트 캐릭터 저장·재열기, 휴식 완료·미루기·닫기,
완료 기록 재로드, CSV 1건과 PNG 19장 생성을 수행한다. 간격 입력 즉시 저장,
Reset·Stop 후 각각 1.2초간 대기 유지, 초대 닫기·생성 취소도 확인한다. 펫 팩 미리보기·설치·
업데이트·손상된 이미지 재설치·잘못된 파일 거부도 검사한다. 세션 시간, CSV 목적지와
팩 선택 경로는 프로그래밍 방식으로 지정하고 버튼 이벤트를 실행한다. OS 알림은 억제한다.
실제 파일 선택 창, 마우스/키보드 입력, 로그인, 전체 애니메이션 타이밍,
사용자의 신체 활동, 장시간 CPU/메모리는 검증하지 않는다.

## 실제 OS 확인

자동 검사와 별도로 아래 항목을 테스트한 OS·아키텍처·커밋·배포물과 함께 기록한다:

- 배포물 설치와 실행·종료, 트레이/메뉴바와 설정 창.
- 타이머·아이콘 조작·간격 적용, idle 자동 일시 정지, sleep/wake, 자동 알림.
- 펫의 idle → stretch → idle, Hide/Show와 재시작 후 설정·위치.
- 투명 배경, 드래그, 다중 모니터·DPI·모니터 분리, Windows 클릭 통과.
- 실제 시스템 알림 전달과 방해금지 상태, 휴식 창이 작업 집중에 주는 영향.
- 게시된 앱의 로그인 실행, 실제 다운로드 파일의 OS 신뢰·서명 상태.
- 60–90분 사용 중 안정성, 자원 사용, 반복 사용 의사.

Windows는 [실기 체크리스트](windows-dogfooding-log.md)를 사용한다. macOS에는
[2026-09-11의 부분 관찰 기록](validation/2026-09-11-macos-dogfooding.md)이 있다.
체크되지 않은 항목은 미검증이다. 다른 브랜치·OS 또는 과거 버전의 통과를 복사하지 않는다.
