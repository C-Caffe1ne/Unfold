# Unfold 개발 계획

2026-09-13 · [제품 방향](product-direction.md)의 구현 순서.

## 1차: 휴식 경험과 펫 리소스 기반

- 선택형 짧은 휴식 루틴과 초 단위 진행 안내.
- 이름·안내 문구·시간을 편집하고 저장하는 내 루틴 1개(최대 3단계, 전체 10분 이내).
- 시작, 5분 미루기, 건너뛰기, 명시적 완료를 서로 다른 결과로 처리.
- 창을 닫거나 컴퓨터가 잠든 것을 휴식 완료로 기록하지 않기.
- 루틴·캐릭터를 세션 시작 시 고정하고 중복 알림을 하나로 유지.
- 완료 후 다음 작업 시간을 다시 예약하고, 휴식 창이 열린 동안 작업 시간 제외.
- 완료 기록을 로컬 파일에 원자적으로 저장하고 손상된 기록을 덮어쓰지 않기.
- 펫의 이벤트 클립을 정확히 선택. 누락된 이벤트를 다른 동작으로 잘못 재생하지 않기.
- 실제 런타임 디코더를 쓰는 펫 리소스 검사와 제작 원장 추가.

완료 조건: 코어 회귀 테스트, 실제 UI 컨트롤 경유 세션 테스트, 번들 리소스 검사,
Release 빌드, 새 데이터 프로필의 macOS 진단 및 화면 확인. Windows 실기와 장기간
사용·수요 검증은 자동 테스트로 대체하지 않는다.

## 2차: Plus 가치의 실제 데모

여러 사용자 루틴을 관리하는 라이브러리, 업무 프로필, 주간 회고/내보내기를 같은 세션 모델 위에
구현한다. [사용 안내와 저장 계약](personalization.md)에 구체적인 동작을 기록한다.
알림 방해가 주요 이탈 이유면 추가 프로필 기능보다 OS별 방해 상황 대응을 우선한다.
한국어 UI와 키보드·접근성 점검도 출시 전 범위로 관리한다. 1차에 이 기능들이
이미 있다고 문서화하거나 결제 잠금을 추가하지 않는다.

이번 데모는 사용자 루틴 최대 20개, 수동 업무 프로필 최대 10개, 7일 회고와 표시 구간의
CSV 내보내기로 범위를 정했다. 기존 단일 루틴·완료 기록의 호환성을 유지하며,
진행 중인 휴식과 기록은 당시 루틴·프로필을 보존한다. 이 개수는 현재 구현 한도이며
Free/Plus 상품의 확정 권한이 아니다. 시간대 자동 전환·OS 상황 감지는 별도 후속 기능이다.

## 3차: 판매 가능한 펫 한 팩과 구매 경험

[펫 리소스 기준](pet-resources.md)에 맞는 한 팩의 아트·재생 품질·제작 권리를
확인한다. 미리보기, 설치, 버전 갱신, 재설치 복원, 실패 시 기존 팩 보존까지 한 흐름으로
구현한다. 계정·원격 카탈로그·DRM은 실제 선택한 판매 채널에서 필요한 만큼만 설계한다.
리소스 manifest의 `paid` 같은 값은 구매 권한 증거로 사용하지 않는다.

## 4차: 판매 검증과 확장

완성된 상품의 가격별 구매·환불·지원 비용을 확인한다. 반복 구매가 있을 때 다음 팩,
원가와 납기가 맞을 때 개인 펫 제작을 확장한다. 무료 사용자 증가만으로 콘텐츠 제작량이나
서버 운영을 늘리지 않는다.

## 작업 상태

**1차 구현 완료 — 2026-09-13.** 기본 루틴 3개, 내 루틴 1개 편집·저장, 세션 진행과
명시적 완료, 오늘의 로컬 기록, 이벤트 반응 선택, 펫 제작 원장·검사 도구를 연결했다.
Release 테스트 56개 통과, macOS arm64 자체 포함 게시와 격리 네이티브 진단이 통과했다.
새 화면의 정적 캡처에서 배치도 확인했다. [검증 기록](validation/2026-09-13-companion-stage1.md)

출시 전에는 Windows 실기, macOS 실제 알림·로그인·sleep/wake, 장시간 자원 사용과
사용성 확인이 필요하다. 기존 Mochi의 크기·배경·선택 반응 경고도 남아 있다.
**2차 핵심 데모 완료 — 2026-09-13.** 여러 루틴·수동 업무 프로필·주간 회고·CSV를
Settings에서 사용할 수 있게 연결했다. 기존 56개에 회귀 테스트 15개를 더해 71개가
통과했다. macOS 게시 앱에서 루틴 2개·프로필 저장, 프로필 적용과 Pause 유지,
진행 중 편집의 분리, 기록 재로드·CSV 저장을 확인했다.
[2차 검증 기록](validation/2026-09-13-companion-stage2.md)

다음 작업은 이 데모의 실제 사용과 출시 전 OS 확인, 판매용 펫 한 팩의 품질·원본 정리다.
Plus의 시간대 자동 전환·상황 감지, 한국어 UI 전체 적용, 유료 팩 설치·결제·복원은
아직 구현하지 않았다. 판매 실험과 외부 배포가 완료된 상태로 보지 않는다.
