# Unfold 개발 계획

2026-09-13 · [제품 방향](product-direction.md)의 구현 순서.

## 1차: 휴식 경험과 펫 리소스 기반

- 선택형 짧은 휴식 루틴과 초 단위 진행 안내.
- 이름·안내 문구·시간을 편집하고 저장하는 내 루틴 1개(최대 3단계, 전체 10분 이내).
- 시작, 5분 미루기, 건너뛰기, 명시적 완료를 서로 다른 결과로 처리.
- 창을 닫거나 컴퓨터가 잠든 것을 휴식 완료로 기록하지 않기.
- 루틴·캐릭터를 세션 시작 시 고정하고 중복 알림을 하나로 유지.
- 완료 후 다음 작업 시간을 다시 예약하고, 휴식 창이 열린 동안 작업 시간 제외.
- 완료 기록을 로컬 파일에 원자적으로 저장하고 손상된 기록을 덮어쓰지 않기.
- 펫의 이벤트 클립을 정확히 선택. 누락된 이벤트를 다른 동작으로 잘못 재생하지 않기.
- 실제 런타임 디코더를 쓰는 펫 리소스 검사와 제작 원장 추가.

완료 조건: 코어 회귀 테스트, 실제 UI 컨트롤 경유 세션 테스트, 번들 리소스 검사,
Release 빌드, 새 데이터 프로필의 macOS 진단 및 화면 확인. Windows 실기와 장기간
사용·수요 검증은 자동 테스트로 대체하지 않는다.

## 2차: Plus 가치의 실제 데모

여러 사용자 루틴을 관리하는 라이브러리, 업무 프로필, 주간 회고/내보내기를 같은 세션 모델 위에
구현한다. [사용 안내와 저장 계약](personalization.md)에 구체적인 동작을 기록한다.
알림 방해가 주요 이탈 이유면 추가 프로필 기능보다 OS별 방해 상황 대응을 우선한다.
한국어 UI와 키보드·접근성 점검도 출시 전 범위로 관리한다. 1차에 이 기능들이
이미 있다고 문서화하거나 결제 잠금을 추가하지 않는다.

이번 데모는 사용자 루틴 최대 20개, 수동 업무 프로필 최대 10개, 7일 회고와 표시 구간의
CSV 내보내기로 범위를 정했다. 기존 단일 루틴·완료 기록의 호환성을 유지하며,
진행 중인 휴식과 기록은 당시 루틴·프로필을 보존한다. 이 개수는 현재 구현 한도이며
Free/Plus 상품의 확정 권한이 아니다. 시간대 자동 전환·OS 상황 감지는 별도 후속 기능이다.

## 3차: 판매 가능한 펫 한 팩과 구매 경험

[펫 리소스 기준](pet-resources.md)에 맞는 한 팩의 아트·재생 품질·제작 권리를
확인한다. 미리보기, 설치, 버전 갱신, 재설치 복원, 실패 시 기존 팩 보존까지 한 흐름으로
구현한다. 계정·원격 카탈로그·DRM은 실제 선택한 판매 채널에서 필요한 만큼만 설계한다.
리소스 manifest의 `paid` 같은 값은 구매 권한 증거로 사용하지 않는다.

## 4차: 판매 검증과 확장

완성된 상품의 가격별 구매·환불·지원 비용을 확인한다. 반복 구매가 있을 때 다음 팩,
원가와 납기가 맞을 때 개인 펫 제작을 확장한다. 무료 사용자 증가만으로 콘텐츠 제작량이나
서버 운영을 늘리지 않는다.

## 작업 상태

**1차 구현 완료 — 2026-09-13.** 기본 루틴 3개, 내 루틴 1개 편집·저장, 세션 진행과
명시적 완료, 오늘의 로컬 기록, 이벤트 반응 선택, 펫 제작 원장·검사 도구를 연결했다.
Release 테스트 56개 통과, macOS arm64 자체 포함 게시와 격리 네이티브 진단이 통과했다.
새 화면의 정적 캡처에서 배치도 확인했다. [검증 기록](validation/2026-09-13-companion-stage1.md)

출시 전에는 Windows 실기, macOS 실제 알림·로그인·sleep/wake, 장시간 자원 사용과
사용성 확인이 필요하다. 기존 Mochi의 크기·배경·선택 반응 경고도 남아 있다.
**2차 핵심 데모 완료 — 2026-09-13.** 여러 루틴·수동 업무 프로필·주간 회고·CSV를
Settings에서 사용할 수 있게 연결했다. 기존 56개에 회귀 테스트 15개를 더해 71개가
통과했다. macOS 게시 앱에서 루틴 2개·프로필 저장, 프로필 적용과 Pause 유지,
진행 중 편집의 분리, 기록 재로드·CSV 저장을 확인했다.
[2차 검증 기록](validation/2026-09-13-companion-stage2.md)

**3차 로컬 설치 기반 구현 — 2026-09-13.** `.unfoldpet` 파일의 미리보기·설치·내용 버전
갱신·같은 파일을 통한 재설치, 해시/런타임 검사와 기존 팩 보존을 연결했다.
[설치 계약](pet-packs.md)과 [검증 기록](validation/2026-09-13-pet-packs.md)을 참고한다.
착수 시 현재 커밋에 남아 있던 병합 충돌과 통합 회귀도 함께 복구했다.

**3차 아트 후보 제작 — 2026-09-14.** 오리지널 토끼 [보리 0.1.0](../Art/Characters/bori-rabbit/README.md)의
생성 원본·프롬프트·제작 원장을 보존하고, 반응 5종을 로컬 설치 팩으로 만들었다.
Release 테스트 119개와 macOS 게시 앱의 실제 시간 기반 재생 진단이 통과했다.
밝고 어두운 배경에서 192px 정적 캡처를 확인했다. 보리는 별도 설치 후보이며 기본 번들에
추가하지 않았다. [제작·검증 기록](validation/2026-09-14-bori-candidate.md)

**3차 설치 전 미리보기 개선 — 2026-09-14.** 밝은/어두운 배경과 100–200% 크기 비교,
Pause/Resume, 선택한 반응 Replay를 추가했다. 반응 종료 후 기본 대기로 돌아가면서
선택을 유지하고, 창 숨김과 사용자의 일시정지 상태를 구분한다. 전체 테스트 122개와
macOS 게시 앱의 미리보기 진단을 확인했다. 2배 렌더링 캡처는 원본 해상도 개선이나
실제 고DPI 모니터 검증으로 간주하지 않는다.
[사용 안내](pet-packs.md#설치-전-외형과-반응-확인) · [검증 기록](validation/2026-09-14-pet-pack-preview.md)

**우선순위 변경 — 2026-09-14.** 사용자 요청에 따라 UI 한글화를 먼저 진행하고,
보리 팩 완성도 작업은 후순위로 미뤘다. 보리 0.1.0 원본·런타임 이미지·배포 팩은 유지한다.

한국어 UI 적용 범위와 데이터 호환 원칙은 [한글화 안내](localization.md)에 기록한다.
**UI 한글화 구현 완료 — 2026-09-14.** 일반 사용자 화면, 기본 루틴, 트레이·펫 메뉴,
오류·접근성 이름을 한국어로 바꿨다. Release 테스트 127개와 macOS 게시 앱 진단이 통과했고,
한글 화면 캡처를 확인했다. 실제 IME·스크린리더·Windows 확인은 남아 있다.
[한글화 검증 기록](validation/2026-09-14-korean-ui.md)

**설정 화면 개편 완료 — 2026-09-14.** 참고 이미지 기반으로 왼쪽 바로가기, 가운데 펫·타이머,
오른쪽 설정 카드의 가로형 대시보드를 적용했다. 입력·저장 동작을 보존하고,
최소 크기에서 오른쪽 카드만 스크롤한다. 전체 테스트 130개와 macOS 게시 앱 진단을 확인했다.
[화면 구성](settings-ui.md) · [검증 기록](validation/2026-09-14-settings-dashboard.md)

**디자인 시스템 적용 — 2026-09-14.** 차콜·크림 팔레트와 공통 페이지·버튼·입력 규칙을
설정과 루틴·프로필·기록·펫 팩·휴식 알림, 중첩 확인·이름 입력·오류 창에 적용했다.
작업 버튼과 결과 안내를 하단에 고정하고 선택 상태의 글자 대비를 보완했다.
[디자인 규칙](design-system.md) · [검증 기록](validation/2026-09-14-design-system.md)

보리의 연속 재생 검수, 384px 제작 기준·고DPI 확인, alpha 잔여 픽셀 판단,
상업적 권리·판매 조건 확인은 보류한 후속 항목이다. 실제 사용 및 출시 전 OS 확인도 남아 있다.
Mochi는 원본·권리 미확인 상태이며 판매 승인된 팩이 아니다.
Plus의 시간대 자동 전환·상황 감지, 결제·계정 기반 구매 복원은 아직 구현하지 않았다.
3차 전체, 판매 실험과 외부 배포가 완료된 상태로 보지 않는다.
