# dsh-pet 비교 후속 적용 계획

기준: `codex/pet-overlay-hover` `8e2ad2c` / `1.2.0`. 공개 v1.2.0 소스는 `99db377`이다.
[dsh-pet](https://github.com/PC2005-cloud/dsh-pet) 0.3.7 배포본 비교에서 범위 안으로 분류한 네 항목만 다룬다.
dsh-pet의 애니메이션·프롬프트·영상 자산은 비상업 라이선스이므로 가져오지 않는다.

## 1. 최상위 유지 (Windows)

- 현황: 펫·말풍선·타이머 창은 생성 시 `Topmost`만 지정한다. 클릭 통과는 확장 스타일을 읽고 다시 쓰므로
  `WS_EX_TOPMOST` 비트가 남은 채 Z 순서만 밀리는 경우를 스타일로 구분할 수 없다. Unfold에서의 발생은 미검증이다.
- 변경: 보이는 창마다 5초 간격으로 `SetWindowPos(HWND_TOPMOST, NOMOVE|NOSIZE|NOACTIVATE)`를 다시 적용한다.
  누름·드래그·메뉴·소유 대화상자가 열린 동안은 건너뛴다. macOS는 기존 `NSFloatingWindowLevel`을 유지한다.
- 검증: 간격·건너뛰기 조건과 호출 플래그 단위 검사. 실제 Windows Z 순서는 미검증으로 남긴다.

## 2. 디스플레이 구성 변경

- 현황: 위치 보정은 창 열기와 드래그 놓기에서만 실행된다. 실행 중 모니터 분리·배율 변경은 처리하지 않는다.
- 변경: `Screens.Changed`에서 펫 위치를 현재 작업 영역으로 보정하고 말풍선을 다시 배치한다.
  자동 보정은 저장된 수동 위치를 덮어쓰지 않는다. 진단 모드·숨김·드래그 중에는 실행하지 않는다.
- 검증: 화면 밖 위치에서 변경 처리 후 작업 영역 안 복귀와 저장 위치 유지를 headless로 검사한다.
  실제 모니터 분리는 미검증으로 남긴다.

## 3. OS 동작 줄이기

- 범위 정정: 휴식 중 배회(`walk`)는 `b074c3f` 이후 시작 경로가 없다. 남은 위치 이동 효과는
  홈·휴식 말풍선·펫 타이머의 `AnimatedCountdown` 숫자 굴림이다. `AnimatedTimeText`는 사용처가 없고,
  타이머 바 페이드는 위치 이동이 아니므로 유지한다. 펫 클립 재생은 콘텐츠이므로 유지한다.
- 변경: macOS `accessibilityDisplayShouldReduceMotion`, Windows `SPI_GETCLIENTAREAANIMATION`을 2초 간격으로 읽어
  동작 줄이기가 켜져 있으면 바뀐 숫자를 굴림 없이 표시한다. 조회 실패는 기존 동작을 유지한다.
  테스트와 진단 모드는 호스트 설정과 무관하게 기존 전환 계약을 검사한다.
- 검증: 설정 값 주입 검사와 호스트 조회 호출 검사. 실제 OS 설정 전환 결과는 미검증이다.

## 4. MP4 펫 원본 제작 규칙

- 변경: [펫 관리](../pet-packs.md)의 MP4 제작 항목에 반복 이음새를 위한 원본 촬영 규칙을 추가한다.
  앱 안 안내 문구는 추가하지 않는다(2026-10-12 안내 제거 결정 유지).

## 공통 검증

항목별 집중 검사 후 `dotnet build Unfold.slnx -c Release --no-restore`와 전체 `dotnet test`를 한 번 실행한다.
진단 실행은 새 `UNFOLD_DATA_DIR`을 사용한다. 커밋은 사용자 확인 후 진행한다.
