# 말풍선 UI 후속 시안

2026-09-20 · BUI-01 4차 시안과 적용 기준. 사용자의 본문 제거·제목 중앙 정렬 요청을 반영해 제품 코드 적용과 검증을 완료했다.

## 현재 구현과 제안

`PetSpeechBubble.cs`와 [기존 초대 캡처](../validation/images/2026-09-20-home-ui-implementation/speech-top.png)를 기준으로 했다.
변경 전 사전·완료 알림은 170px, 초대·휴식은 268px 높이이며 폭은 320px였다.
4차 시안은 3차 시안의 폭과 상태별 크기, 타이머·버튼·하단 안내를 유지하고
**제목과 조작 사이의 본문만 모두 제거한다.** 제목은 말풍선 너비 기준으로 중앙 정렬한다.
아래 제안이 최신 기준이며, 3차 시안의 본문 유지 결정을 대체한다.

| 요소 | 변경 전 | 적용 |
|---|---|---|
| 제목 | 17px semibold | 홈·설정과 같은 18px semibold, 중앙 정렬 |
| 안쪽 여백·모서리 | 18px·22px | 위아래 14px / 좌우 20px·모서리 24px |
| 본문·보조 문구 | 14px·12px | 본문 제거, 하단 상태 안내 12px 유지 |
| 제목 아래 본문 | 남는 본문 영역의 수직 중앙 | 모두 제거하고 상태별 남는 높이는 여백으로 유지 |
| 타이머 | 34px | 40px, 중앙 정렬 |
| 시작·미루기·완료 버튼 | 38px 높이 | 40px 높이, 기존 위치 유지 |
| 내부 간격 | 8px 고정 행 포함 | 보이는 요소 사이 6px, 숨은 요소의 빈 행 제거 |
| 높이 | 170/268px 고정 | 3차 시안 크기 유지: 96/159/196/113px |

사전·완료 알림에는 제목과 접기 힌트, 초대에는 제목과 미루기·휴식 시작, 휴식 중에는
제목·타이머·완료 버튼을 보여준다. 초과 시간은 기존 노란색과 `+` 표기를 유지한다.
하단 접기·완료·한도 안내는 상태 이해와 다음 행동에 필요한 기존 요소이므로 유지한다.

대화 시안에서 휴식 시작과 완료를 눌러 배치를 비교할 수 있다. 시안 옵션으로 네 가지 테마, 여섯 알림 상태,
1·5·10·60분 미루기 레이블을 확인한다.
2:38·+0:10·+60:00·완료 3분 10초는 배치용 예시이며 실제 경과 시간이나 저장 기록이 아니다.
미루기 클릭은 시안 내 문구만 바꾸고, 실제 예약·소리·파일 저장을 수행하지 않는다.
펫 이미지는 기존 홈 시안의 Mochi 캡처를 재사용했다.

## 시안 검수

### 4차 — 본문 제거·제목 중앙 정렬

- 3차 시안의 폭 320px, 위아래 14px / 좌우 20px 여백, 모서리 24px, 버튼 40px,
  타이머 40px와 상태별 높이 96/159/196/113px를 그대로 유지했다.
- 제목과 타이머·버튼 사이의 설명 본문을 모든 상태에서 제거했다. 하단의 접기·완료·한도 안내와 모든 조작은 유지했다.
- 제목을 말풍선 가운데로 정렬했다. 오트 라떼 기본값과 세이지·미드나이트 블루·플럼 테마 선택도 유지했다.
- [4차 검수 데이터](../validation/2026-09-20-speech-ui-title-only-proposal.json).
  HTML 시안의 구조·브라우저 표시 검사다. 제품 적용 결과는 [구현 검증](../validation/2026-09-20-speech-ui-implementation.md)에 기록했다.

### 3차 — 세로 간격 축소

- 위아래 패딩을 20→14px, 보이는 요소 사이 간격을 8→6px로 줄였다. 본문을 늘리는 빈 영역을 제거했다.
- 320px 폭의 기본 문구에서 사전 알림 96px, 휴식 초대 159px, 휴식·초과 196px, 완료 113px를 측정했다.
  초대는 이전 268px보다 109px 줄었다. 긴 안내는 최대 4줄까지 내용에 따라 확장한다.
- 4테마 × 6상태 × 2폭 × 기본/긴 안내의 **96개 조합**에서 요소 겹침·경계 이탈·가로 넘침이 없었다.
  브라우저 736/320px에서 말풍선 실제 폭은 320/288px였다.
- 60분 미루기 버튼, 시작→휴식→완료 전환, 이전 시안의 268px 높이 복원도 확인했다. 브라우저 오류 로그 0.
- [3차 검수 데이터](../validation/2026-09-20-speech-ui-compact-proposal.json).
  측정치는 HTML 시안의 값이며, Avalonia에서는 실제 글꼴과 줄바꿈에 따른 콘텐츠 높이를 사용해야 한다.

### 이전 시안 기록

테마 적용 이후 `PetSpeechBubble.cs`, `DesignSystem.Themes.cs`와
[현재 오트 라떼 초대 캡처](../validation/images/2026-09-20-themes/theme-OatLatte-speech.png)를 다시 확인했다.
2차 시안은 **오트 라떼를 기본**으로 하고 세이지·미드나이트 블루·플럼을 동일한 제품 팔레트로 제공한다.
주요 글자와 버튼 강조를 분리하고, 초과 타이머는 각 테마의 `Warning` 색을 쓴다.
‘현재’ 비교 옵션도 현재 제품의 새 색상을 유지하면서 기존 치수·본문 중앙 정렬을 보여 준다.

- 4테마 × 6상태 × 2폭의 **48개 조합**에서 말풍선 내부 요소가 경계 안에 있으며 가로 넘침이 없었다.
- 브라우저 폭 736/345px에서 말풍선 실제 폭은 320/313px, 상태별 높이는 170/268px였다.
- 휴식 시작 → 휴식 중 → 완료 버튼 전환을 실행했고, 1/5/10/60분 미루기 레이블의 넘침이 없었다.
- 긴 안내를 켠 채 초과·최대 초과 상태를 확인했다. 제안 버튼은 40px이며, 현재 치수 옵션은 18px 여백·22px 모서리·17px 제목·38px 버튼으로 복원됐다.
- 최종 브라우저 오류 로그 0. [검수 데이터](../validation/2026-09-20-speech-ui-proposal.json)에 범위와 한계를 기록했다.

아래는 최초 시안의 검수 기록이다.

- 기본 320px 폭에서 시작 → 휴식 중 → 완료 전환과 버튼 40px를 확인했다.
- 좁은 대화 폭 313px에서도 여섯 상태의 가로 넘침이 없고 하단 힌트가 말풍선 안에 들어간다.
- 긴 휴식 안내·60분 미루기·+60:00 표시를 확인했다. 268px 휴식 상태의 본문 영역은 69px로,
  4줄 안내를 수용한다. 더 긴 내용의 기존 생략·전체 툴팁 계약은 유지한다.
- 브라우저 오류 로그 0. HTML 시안 검사이며 Avalonia 글꼴 측정·4방향 실제 배치 검증을 대신하지 않는다.

## 구현 결과

1. `PetSpeechBubble.cs`와 디자인 시스템에 제목·여백·모서리·타이머·버튼·간격·상태별 높이 토큰을 적용했다.
   모든 상태의 설명 본문을 제거하고 하단 상태 안내와 네 가지 테마는 유지했다.
2. `PetWindow.cs`는 이미 `bubble.Height`를 `PetBubbleLayout`에 전달하므로 직접 수정하지 않았다.
   바뀐 상태별 높이가 기존 생산자·소비자 계약을 통해 네 방향 창과 꼬리에 반영된다.
3. 사전·초대·휴식·초과·완료, 네 방향, 접기/펼치기, 타이머·버튼·기록·효과음 회귀를 검사했다.
4. Release 212개 테스트와 새 격리 프로필의 macOS 네이티브 off-screen 진단을 통과했다.
