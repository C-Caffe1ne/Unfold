# 앱 메모리 400MB 최적화 계획

기준: `a8fbd5bf6055f9d52359b13bd3678175ecc7ea71` / `1.1.1-beta`.
최신 공개 배포 `v1.1.0-beta`와 작업트리를 대조하고 로그인 유지·미사용 기능 제거를 포함한 최신 제품 소스에서 진행한다.

## 역할과 범위

Agency Agents의 Performance Benchmarker는 실제 macOS 측정 실행기·원시 결과,
Senior Developer는 2D 재생 이미지 최적화·회귀 검사,
Code Reviewer는 메모리 지표·지원 입력 경계·회귀 위험을 검토한다.
감독자는 캐시·리소스 수명·가져오기 중복·통합 검증을 맡는다.
기존 다른 작업트리의 미커밋 변경·자산·사용자 데이터는 보존한다.

## 측정과 통과 기준

- 400MB는 **400,000,000바이트**다. 관리 힙 수치만으로 판정하지 않는다.
- 동일 Release 소스·자산·고정 모델·화면 배율에서 200ms마다 RSS, macOS physical footprint, 관리 힙·누적 할당·GC 횟수를 기록한다.
- 샘플 최고치와 커널의 프로세스 생애 최고 physical footprint를 모두 비교한다.
- 기본 5종 펫·설정 반복 열기/숨기기·휴식 알림·Hikari/Kazusa 저장/수정/150% 재생·홈 복귀를 같은 실행기로 전후 측정한다.
- 허용 한도에 가까운 512×512·120프레임 GIF(디코딩 125,829,120바이트)의 펫+홈+제작 초안·재가져오기도 별도 프로세스로 확인한다.
- 실제 시간으로 이어지는 장시간 재생에서 반복 전환 후 증가 추세를 확인한다.
- 강제 GC, GC 힙 상한, 테스트 종료를 통한 숫자 축소는 사용하지 않는다. 지원 입력의 화질·타이밍·입력·저장 결과를 유지한다.

## 작업 순서

1. 기존 바이너리를 별도 복사본으로 고정하고 변경 전 실제 초과를 재현한다.
2. 2D 재생은 현재 표시 프레임의 WriteableBitmap 1개를 재사용한다. GLB의 기존 이중 픽셀 버퍼 계약은 유지한다.
3. 클립 캐시를 32MiB로 제한하고 디코딩을 직렬화한다. 큰 활성 클립은 약한 참조로 두 화면이 공유하고 숨은 홈 미리보기는 해제한다.
4. 반복된 스프라이트 셀을 공유하고 사용하지 않는 atlas의 강한 참조를 제거한다.
5. 가져온 미디어의 검증 프레임을 재사용하고 썸네일·내보내기에 전체 GIF를 다시 디코딩하지 않는다.
6. 집중 회귀 검사 후 동일 네이티브 실행기의 변경 후 측정과 장시간 검증을 진행한다. 필요한 추가 개선은 실측 원인을 근거로 결정한다.
7. 전체 Release 검사·네이티브 진단·독립 코드 검토를 마치고 전후 수치와 적용/미검증 범위를 보고한다.

모든 임의의 외부 파일·모든 OS 환경에 대한 절대 메모리 상한은 이 측정만으로 보장하지 않는다.
GLB 모델의 큰 텍스처·공유 accessor/morph 팽창과 OS/native 할당은 별도로 위험을 평가한다.

정식 1차 최적화 실행에서 408.18MB가 관찰되어 GC 힙의 보관 비용도 개선 대상으로 확인했다.
제품에 `System.GC.ConserveMemory=7`을 적용하고 실행기의 호스트 정책도 동일하게 맞춘 후 전체 시간 측정을 다시 한다.
수집을 직접 강제하거나 힙 상한을 두지 않고 네이티브 동작·CPU·관리 힙·physical footprint를 함께 관찰한다.

Retina 2배 화면은 실제 창 배율을 확인하며 별도로 측정한다. 1배와 2배 실행을 같은 조건의 감소율로 섞지 않는다.
2배 빠른 전환에서 400MB 초과가 재현돼 그래픽 캐시를 4MiB로 낮춘 뒤 패키지 저장·열기의 중간 배열도 줄인다.
ZIP과 파일의 여러 전체 복사본 대신 검증된 비공개 파일 snapshot을 스트리밍으로 만들며 체크섬·크기·원자적 게시·설치 revision 검사를 유지한다.
격리된 `ConserveMemory=9` 실험은 초과를 해결하지 못해 제품 정책에 반영하지 않는다.

종료 상태: 사용자 요청으로 추가 3D 최적화를 마무리하고 현재까지의 변경·검증을 보고했다.
Retina 빠른 전환의 400MB 초과가 남아 있으며 최종 전체 시간 재측정·30분 검증은 수행하지 않았다.
소프트웨어 합성 실험도 목표를 해결하지 못해 기존 macOS OpenGL 우선 설정으로 복원했다.
