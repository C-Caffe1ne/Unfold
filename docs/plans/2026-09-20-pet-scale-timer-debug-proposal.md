# 펫 크기·타이머 중지·알림 디버그 개선안

## 목표

홈 화면에서 펫 크기를 바로 조절하고, 중지된 타이머의 다음 시작 시간을 명확하게 보여준다. 말풍선은 알림 상태가 끝날 때만 닫히도록 단순화하고, 설정 화면에서 기다리지 않고 각 알림 상태를 확인할 수 있게 한다.

## 확정 시안 기준

### 1. 펫 크기

- 홈의 `함께하는 펫` 카드에서 펫 선택 드롭다운 바로 위에 `펫 크기` 슬라이더를 배치한다.
- 범위는 `50~150%`, 단위는 `10%`, 기본값은 `100%`로 한다.
- 현재 값을 슬라이더 오른쪽에 퍼센트로 표시한다.
- 슬라이더 아래에 별도의 `축소 / 기본 / 확대` 눈금 텍스트는 표시하지 않는다.
- 슬라이더를 움직이면 홈 미리보기와 바탕화면 펫 크기가 함께 바뀌고, 선택한 값은 설정에 저장한다.
- 구현 후속 보정으로 홈 미리보기와 바탕화면 펫에 같은 96/192/288 논리 픽셀을 직접 적용한다.
- 말풍선 너비와 글자 크기는 유지하고 펫과 말풍선 사이 간격만 새 펫 크기에 맞춰 계산한다.
- 펫의 화면 기준 위치를 유지한 채 크기를 바꾸고, 화면 밖으로 나가면 현재 모니터 작업 영역 안으로 보정한다.

### 2. 중지된 타이머

- `중지`를 누르면 남은 시간을 `00:00`으로 바꾸지 않고 설정한 스트레칭 간격으로 되돌린다.
- 상태는 `중지됨`, 설명은 `재생하면 45:00부터 시작`처럼 현재 설정값을 포함해 표시한다.
- 홈, 트레이 상태, 다음 재생 시작값이 같은 시간을 사용하도록 `StretchClock`의 중지 상태 계약을 수정한다.

### 3. 펫 우클릭

- 펫 우클릭 메뉴에서 `말풍선 접기/펼치기`를 제거하고 `설정`만 남긴다.
- 저장된 `BubbleCollapsed` 값과 접힌 알림 복구용 트레이 항목·배지를 더 이상 사용하지 않는다.
- 이전 설정 파일에 `bubbleCollapsed`가 있어도 불러오기는 계속 가능하며 해당 값은 무시한다.
- 말풍선은 5분 전 알림, 스트레칭 알림, 휴식 진행, 완료 알림의 기존 상태 전환에 따라 표시·종료한다.

### 4. 디버그 도구

- 설정 탭 하단에 `디버그 도구` 섹션을 추가한다.
- `디버그 도구 사용`을 켜면 `5분 전 알림`, `스트레칭 알림`, `휴식 진행`, `완료 알림`, `미리보기 종료` 버튼을 표시한다.
- 선택한 상태는 실제 `PetSpeechBubble`과 같은 표현을 사용해 바탕화면 펫에서 즉시 미리본다.
- 미리보기는 실제 작업 타이머, 휴식 기록, 다시 알림 예약을 변경하지 않는다.
- 디버그 도구 사용 여부만 저장하고, 미리보기 상태는 앱을 다시 실행할 때 초기화한다.

## 구현 경계

1. `AppSettings`에 펫 크기와 디버그 도구 사용 여부를 추가하고 값 범위를 검증한다.
2. `StretchClock.Stop`과 중지 상태 예약 동작이 `Interval`을 유지하도록 수정한다.
3. `PetBubbleLayout`에 펫 논리 크기를 전달해 상·하·좌·우 말풍선 배치를 같은 기준으로 계산한다.
4. `PetWindow`에서 접기 메뉴와 접힌 상태 분기를 제거하고, 별도 미리보기 상태를 우선 렌더링한다.
5. `AppRuntime`에 기록·타이머를 건드리지 않는 알림 미리보기 전용 상태와 명령을 추가한다.
6. 홈 슬라이더와 설정 디버그 섹션을 현재 오트 라떼 디자인 토큰과 40px 제어 높이에 맞춘다.

## 검증 항목

- 50%, 100%, 150%에서 홈 미리보기·바탕화면 펫·말풍선 네 방향의 배치와 화면 경계 보정을 확인한다.
- 중지 직후, 설정 시간 변경 후, 다시 재생 후의 표시값과 실제 `Remaining` 값이 일치하는지 확인한다.
- 이전 `bubbleCollapsed: true` 설정을 불러와도 알림이 보이고 우클릭 메뉴에는 `설정`만 있는지 확인한다.
- 디버그 네 상태를 차례로 열고 닫아도 타이머, 휴식 기록, 다시 알림 예약이 변하지 않는지 확인한다.
- 집중 테스트, 전체 Release 테스트, macOS 자동 스모크 캡처를 실행한다. Windows 실제 포인터·다중 모니터·배율 동작은 Windows 환경에서 별도로 확인한다.
