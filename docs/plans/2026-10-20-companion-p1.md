## S1 — 펫별 크기와 즐겨찾기

시작 소스의 `AppSettings.PetScalePercent`는 전역 값이다. 펫 A를 80%, B를 130%로 바꾸고
A로 돌아왔을 때 80%가 복원되도록 캐릭터 ID별 선호를 사용자 설정에 저장한다.
즐겨찾기는 같은 ID를 기준으로 저장하며 펫 팩 원본과 분리한다.

- 소유 모듈: [AppSettings.Pets](../../src/Unfold.Core/AppSettings.Pets.cs)·[PetPreference](../../src/Unfold.Core/PetPreference.cs)·[설정 복구](../../src/Unfold.Core/AppSettings.Recovery.cs)의 저장 계약, [AppRuntime](../../src/Unfold.Desktop/AppRuntime.cs)의 선택·설정 반영, [SettingsWindow](../../src/Unfold.Desktop/SettingsWindow.cs)의 크기 입력과 관련 집중검사.
- 선행 확인: 기존 JSON, 설정 복구·유효성 검사, 펫 선택 실패 시 복원, 삭제·업데이트 뒤 선택 처리.
- 수용 기준: 50~150%·10% 단위의 기존 크기 범위 유지, A→B→A 및 앱 설정 재로딩 후 복원, 같은 ID의 팩 업데이트 후 선호 유지.
- 이전 설정 호환: 펫별 값이 없는 기존 설정은 기존 전역 크기를 초기값으로 사용한다. 손상되거나 범위를 벗어난 개별 값은 안전한 값으로 복구하며 다른 설정을 잃지 않는다.
- 즐겨찾기 수용 기준: 재로딩 후 유지, 중복 ID 없이 저장, 존재하지 않는 펫 때문에 목록 로딩 실패 없음.
- 반영 결과: 삭제된 펫의 선호를 제거하며, 시작 시 선택 펫이 누락/손상되어 대체되는 경로도 실제 선택 ID와 대체 펫의 저장 크기를 복원한다.
- 집중검사: 구형 설정 복구, 정상 왕복 저장, 잘못된 개별 값, A/B 전환, 동일 ID 업데이트, 즐겨찾기 추가·해제와 미존재 ID 처리.
- 범위 밖: 펫별 위치, 펫별 행동·말풍선 설정, 다중 펫.

## S2 — 내 펫 라이브러리

펫 관리의 첫 화면에서 보유 펫을 정지 썸네일로 찾는다. **적용**은 현재 펫을 바꾸고,
**편집**은 기존 미디어/GLB 편집기로 이동한다. 파일 열기는 기존 가져오기 경로를 사용한다.

- 소유 모듈: [PetLibraryView](../../src/Unfold.Desktop/PetLibraryView.cs), [PetManagementView](../../src/Unfold.Desktop/PetManagementView.cs), [PetBuilderView](../../src/Unfold.Desktop/PetBuilderView.cs), [SettingsWindow.Layout](../../src/Unfold.Desktop/SettingsWindow.Layout.cs), [CharacterLibrary](../../src/Unfold.Core/CharacterLibrary.cs)의 목록·미리보기 연결 및 관련 집중검사.
- 선행조건: S1의 캐릭터 ID별 선호와 기존 편집 초안 보호.
- 표시 정보: 썸네일, 이름, 2D/3D 형식, 현재 사용 상태, 즐겨찾기. 기본 펫의 편집 버튼은 숨기며 기본/사용자 구분 배지는 추가하지 않는다.
- 탐색: 이름 검색, 전체/즐겨찾기/2D/3D 필터. 결과가 없으면 검색·필터 조건을 이해하고 해제할 수 있다.
- 수용 기준: 카드 적용과 편집을 혼동하지 않음, 기본 펫에 편집 동작을 제공하지 않음, 저장·삭제 후 목록과 현재 선택이 동기화됨.
- 초안 보호: **목록으로**는 확인창 없이 편집 초안을 보존하고 목록을 연다. 다시 편집으로 돌아오면 해당 초안을 이어간다. **새로 만들기**에서 저장하지 않은 초안이 있으면 폐기를 확인하며, **계속 편집**을 선택하면 초안을 유지한다.
- 썸네일: 패키지를 읽을 때 검증한 `CharacterPackage.StillImage`를 사용한다. 카드마다 애니메이션을 실행하거나 GLB 모델을 디코딩하지 않으며, 목록 재구성·종료 때 카드 비트맵을 해제한다. 별도 불량 썸네일 대체 기능은 추가하지 않았다.
- 집중검사: 검색/필터 조합, 현재 사용·즐겨찾기 표시, 2D/GLB 적용 및 편집 분기, 파일 가져오기·저장·삭제 동기화, 초안 유지/취소, 정지 썸네일 사용·해제.
- 시각 기준: 기존 네 테마·12/14/18/24 글자 단계·8/12/20 간격을 재사용한다. 기본 1120×800 및 최소 860×800에서 주요 작업을 가리지 않는다. 네 언어·긴 이름도 포함한다.

## S3 — 선택형 CPU·메모리 정보

기본은 **off**다. 사용자가 켠 경우 CPU와 메모리 정보를 기존 미니바 아래 두 줄에,
호버할 때만 표시한다. 5초 간격으로 수집하며 휴식 안내·카운트다운·재생/일시정지·중지의 우선순위를 유지한다.

- 소유 모듈: [SystemResourceMonitor](../../src/Unfold.Desktop/SystemResourceMonitor.cs)·[NativeSystemResourceSource](../../src/Unfold.Desktop/NativeSystemResourceSource.cs)의 수집, [AppSettings](../../src/Unfold.Core/AppSettings.cs)의 선택 저장, [PetTimerWindow](../../src/Unfold.Desktop/PetTimerWindow.cs)의 서비스 수명·표시, [SettingsWindow.Preferences](../../src/Unfold.Desktop/SettingsWindow.Preferences.cs)·[Notifications](../../src/Unfold.Desktop/SettingsWindow.Notifications.cs)의 자동 저장 및 관련 집중검사.
- 선행조건: S2 완료 후 진행. CPU는 시스템 전체 누적 카운터의 표본 간 차이로 계산한다. 첫 표본의 CPU는 준비 상태이며 다음 표본부터 표시한다.
- 메모리 정의: macOS는 물리 메모리 총량에서 free 페이지를 뺀 점유량으로 파일 캐시를 포함한다. Windows는 물리 총량에서 즉시 사용 가능한 메모리를 뺀 값이다. 사용/총량을 십진 GB로 표시하고 설정 툴팁에서 플랫폼별 정의를 설명한다.
- 수용 기준: 초기·해제·숨김 상태에서는 수집하지 않음, 호버 활성 세션은 첫 표본 뒤 5초 간격으로 수집, 중첩 수집과 종료 후 갱신 없음.
- 실패 처리: 준비 전·미지원·수집 실패를 0%로 표시하지 않는다. 실패 때문에 타이머·펫·알림을 중지하지 않는다.
- 화면: 숫자 갱신으로 폭이 흔들리지 않으며 숨은 호버 영역이 입력을 가로채지 않는다. 수집은 UI 스레드에 긴 작업을 만들지 않는다.
- 집중검사: 기본값·설정 왕복 저장, 켜기/끄기, 5초 주기와 중복 억제, 실패·미지원·종료 처리, 표시 형식·레이아웃 상태, 기존 타이머 동작.
- 실제 OS 경계: macOS native 두 샘플 프로브에서 CPU 차분·RAM 범위와 Mach 호출을 확인했다. Windows native 실행, 잠자기·재개, 장시간 전력·메모리 비용은 미검증이다.
- 범위 밖: 상시 표시, 경고·반복 알림, GPU·디스크·네트워크 지표, 자원 상태에 따른 펫 행동 변경.

## S4 — 기존 미니바 빠른 메뉴

기존 호버 미니바의 작은 메뉴에서 **내 펫**으로 라이브러리를 열고,
**알림 소리 켜기/끄기**, **설정**을 실행한다. 기존 재생/일시정지·중지와 펫 우클릭의 숨기기를 유지한다.

- 소유 모듈: [PetTimerWindow](../../src/Unfold.Desktop/PetTimerWindow.cs)의 메뉴·입력·배치, [PetTimerReveal](../../src/Unfold.Desktop/PetTimerReveal.cs)의 표시 수명, [AppRuntime](../../src/Unfold.Desktop/AppRuntime.cs)의 기존 동작 연결과 관련 집중검사.
- 선행조건: S2의 내 펫 라이브러리 진입과 S3의 호버 정보 배치.
- 수용 기준: 라이브러리 열기가 S2 목록을 열고, 소리 토글은 기존 설정과 동기화되며 저장됨. 설정 열기는 기존 창을 재사용함. 열린 메뉴 또는 키보드 포커스 때문에 필요한 조작이 도중에 사라지지 않음.
- 입력 보호: 드래그·누름 반응·투명 영역 클릭 통과를 유지하고, 메뉴 조작이 펫 클릭 반응이나 타이머 동작으로 중복 전달되지 않음.
- 집중검사: 메뉴 열기·닫기·실행, 설정 동기화, 키보드 포커스/호버 수명, 들기·숨기기·타이머 일시정지/중지 회귀, 화면 가장자리 배치 계산.

- 범위 밖: 크기 조절 메뉴의 중복 추가, 우클릭 숨기기의 이동, 독립 도구바 생성.
