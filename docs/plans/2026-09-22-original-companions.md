# 보리·Mochi 상호작용 팩

## 승인된 범위

- 단순한 동물 선화로 Mochi(고양이), 보리(토끼)를 재제작한다. 사용자 참고 이미지는 스타일 참고로만 사용한다.
- 평상시 20~40초 간격으로 잠자기, 두리번거리기, 하품 중 하나를 재생한다. 같은 행동이 연속되지 않는다.
- 누르면 스퀴시, 놓으면 짧게 튀어오른 뒤 놀라서 두리번거린다. 드래그는 클릭 반응을 발생시키지 않는다.
- 세 번째 연속 미루기에서 삐진 모습을 한 번 재생한다. 휴식 시작·완료·타이머 중지 시 횟수를 초기화한다.
- 실제 휴식 중에는 스트레칭을 한 번 완료한 뒤 현재 모니터 작업 영역 안을 천천히 걷는다.
  말풍선을 포함한 창이 화면을 벗어나지 않게 하고 포인터가 펫 또는 말풍선 위에 있거나 드래그/메뉴 중이면 이동을 멈춘다.
  완료·중지·숨김·캐릭터 변경 시 이동을 끝낸다. 자동 이동은 저장된 수동 배치 좌표를 덮어쓰지 않는다.
- 기존 커스텀 제작의 idle/attention/stretch/celebrate/click 5개 슬롯과 재생 규칙은 유지한다.

## 계약과 소유 파일

- manifest v1에 선택적 `behaviorProfile: unfold-original-v1`을 추가한다. 이 프로필과 추가 클립을 가진 제작 팩만 새 행동을 사용한다.
  프로필은 동작 구성 정보이며 구매 권한이나 저작권 인증이 아니다. 커스텀 팩 생성기는 이 프로필을 쓰지 않는다.
- `CharacterLibrary`, `PetReminder`, `AppRuntime`, `PetWindow`, `AnimationView`와 관련 검사에 상태 연결을 구현한다.
- `Assets/Characters/default-cat`, `Assets/Characters/bori-rabbit`에 실행 원본을 두고 두 팩을 기본 선택 목록에 포함한다.
  기존 동일 ID 설치 파일은 보존하고 기본 팩과 중복 표시하지 않는다.
- `Art/Characters/original-companions-v2`에 생성 원본·프롬프트·제작 원장을 보존하고 `.unfoldpet` 두 개를 만든다.
  기존 보리 후보 원본은 보존한다.

## 수용 기준

- 두 팩의 모든 클립이 투명 배경·동일 셀 크기로 디코딩되고 패키지 해시 검증을 통과한다.
- 미루기 횟수, 원본 팩/커스텀 팩 분기, 클릭과 드래그 구별, 숨김·종료·중지 중 비동기 작업 취소를 회귀 검사한다.
- 화면 경계·배율·음수 좌표 모니터를 포함해 이동 범위를 검사한다.
- Release 빌드, 전체 테스트, 새 데이터 UI 진단과 리소스 캡처를 수행한다.
- 실제 OS 입력 검증, 자동 진단, 아트 자연스러움의 사람 검수를 구별한다.
