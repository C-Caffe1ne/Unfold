# 던지기·배경 지우기·행동별 여러 파일 계획

기준: `codex/pet-overlay-hover` `9d01b7d` / `1.2.1`에서 만든 `codex/pet-throw-media`.
[기능 적용 시안](https://claude.ai/artifact/8dz33We6A7wJ9BQcoCjWLF) 중 두 펫 동시 표시와 교차 페이드는 제외한다.
2026-10-05에 제거한 찌그러짐·바운스 캔버스 효과는 다시 넣지 않는다.

## 1. 던지기·착지

- 드래그 중 창은 과감쇠 스프링(k=200, c=30)으로 포인터 목표를 따른다.
- 놓기 직전 150ms 포인터 속도가 500 논리 px/s 이상이면 현재 화면 배치 영역 안에서 중력 1400, 반발 0.78, 바닥 마찰 2.5로 날아가 작업 영역 아래에 착지한다. 속도 상한은 3600에 점근한다.
- 착지 후 위치를 저장한다. 느리게 놓으면 지금처럼 그 자리에 둔다.
- 기본 펫은 비행 중 `held`, 착지 때 `land`를 재생한다. 미디어 펫은 기존 `pointerUp` 반응을 유지한다.
- OS 동작 줄이기와 진단 모드에서는 스프링·비행 없이 기존 직접 이동을 유지한다.

## 2. 배경 지우기·발 위치 맞춤

- 파일마다 켜고 끈다. 배경색은 첫 프레임 가장자리의 가장 흔한 색으로 정하고, 허용 범위 0–100(기본 40)의 색차 안 픽셀을 투명하게 한다.
- 발 위치 맞춤은 모든 프레임의 불투명 영역을 기준으로 발 아래선을 정사각형 캔버스 하단 여백에, 몸 중심을 가로 중앙에 둔다. 크기는 바꾸지 않는다.
- 처리는 Core 순수 함수로 하고, 움직이는 파일은 FFmpeg로 GIF를 다시 만든다. 정지 이미지는 PNG로 저장한다.
- 설정은 편집 초안에만 있고 팩에는 처리된 결과가 들어간다.

## 3. 행동별 여러 파일

- `AnimationDefinition.Variants`(중첩 없음)와 `Order`(`random`·`sequence`)를 선택 필드로 추가한다. 이전 앱은 첫 파일만 재생한다.
- 행동마다 최대 4개, 팩 파일 32개 제한을 유지한다. 반응을 시작할 때 무작위(직전과 다른 파일) 또는 차례대로 고른다.
- 편집 화면의 행동 카드에 파일 목록·추가·삭제와 재생 순서를 둔다.
