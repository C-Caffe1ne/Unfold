## 시안과 유지할 동작

대화 시안에서 날짜 행을 눌러 상세를 펼치고, 기간 이동과 빈 상태를 확인할 수 있다.
시안 옵션은 기본/최소 폭, 완료 예시/빈 기록/읽기 오류, 행 높이 44/40px다.
추천은 44px 행과 20px 카드 간격·패딩이다. 큰 페이지 헤더는 추가하지 않는다.

기록 9회·27분 40초·5일은 배치 확인용 예시이며 실제 사용자 기록이 아니다.
CSV 버튼은 안내만 표시하며 파일을 저장하지 않는다. 내비게이션은 배치 확인용이다.
시안은 대화 안에서 상세 전체를 읽도록 높이가 늘어난다. 제품의 860×680 고정 창에서는
기존 본문 스크롤과 고정 하단 계약을 유지해야 하며, 이는 코드 적용 후 네이티브에서 검증한다.
좁은 대화 화면의 세로 재배치는 제품의 최소 창 크기를 변경하는 제안이 아니다.

7일 단위·77일 이전까지의 이동, 날짜/기록 집계, 실제 시간이 없는 기존 기록의 목표 시간 합산,
로컬 저장, CSV 내용·대상 기간, 날짜 펼침 동작을 유지한다. 필터·목표·통계 기능을 추가하지 않는다.
날짜별 상세의 휴식 이름은 표시하지 않는다. 완료 시각과 실제 휴식 시간을 표시하며,
실제 시간이 없는 구형 기록은 상세에 “실제 휴식 시간 미기록”으로 표시한다.
기존 이름·목표 시간 데이터와 CSV 저장 계약은 유지한다.

## 시안 확인 결과

- 브라우저에서 날짜 상세 펼침, 이전 주의 빈 상태, 현재 주로 복귀, CSV 안내와 빈 상태의 이동 안내 확인.
- 기본 시안 폭 1120px에서 본문 폭 760px 확인. 최소 폭 시안과 좁은 대화 폭 313px에서도 가로 넘침 없음.
- 1차 시안에서 긴 이름·읽기 오류 조합의 줄바꿈과 브라우저 오류 로그 0을 확인했다.
  2차 시안은 휴식 이름과 관련 시안 옵션을 제거하고 첫 날짜를 펼쳐 변경점을 보여준다.
- 2차 시안의 각 상세에 완료 시각·실제 휴식 시간 두 값만 남는지 확인했다. 구형 기록의 미기록 표시,
  상세 펼침, 폭 313px에서 가로 넘침 없음, 브라우저 오류 로그 0을 확인했다.
- HTML/브라우저 시안 결과이며, Avalonia 적용·Windows 실기·OS 배율 검증을 대신하지 않는다.

## 승인 후 구현 — 완료

1. `BreakReviewWindow.cs`의 `BreakReviewView` 배치·텍스트·날짜 행만 수정. 집계·내보내기 모델 유지.
2. 필요한 경우 기록 전용 크기 토큰 추가. 홈·설정·펫 탭의 기존 입력 스타일 유지.
3. 현재 7일/과거 7일, 빈 기록, 오류, 구형 기록의 미기록 표시, 이름 숨김, 상세 펼침과 CSV 스냅샷 회귀 확인.
4. 1120×800·860×680 탭과 620×650 호환 창에서 하단 고정·세로 스크롤·가로 넘침 검증.
5. 기록 화면 적용을 마친 뒤 말풍선 UI 시안을 별도로 작성했다. 타이머/휴식 흐름 등 UX 확장은 UI 정리 이후에 다룬다.
