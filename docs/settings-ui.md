# 설정 대시보드

2026-09-14 · 사용자가 제공한 참고 이미지의 세로 아이콘 막대, 큰 중심 카드,
오른쪽 보조 카드와 둥근 외곽 프레임을 현재 Unfold 설정 화면에 적용했다.

## 화면 구성

- 왼쪽 바로가기: 타이머로 포커스 이동, 내 루틴·업무 프로필, 기록·내보내기,
  펫 팩 설치, 앱 종료. 아이콘에는 한국어 접근성 이름과 도구 설명이 있다.
- 가운데 위: 선택한 펫의 큰 미리보기, 펫 선택, 팩 설치, 바탕화면 표시와 로그인 시 자동 실행.
- 가운데 아래: 남은 시간, 타이머 상태, 일시정지·계속·정지·초기화 아이콘.
- 오른쪽: 알림 간격·자리 비움 기준, 휴식 루틴과 적용 버튼, 오늘의 완료 기록.

차콜 바탕과 명도가 다른 카드, 크림색 강조, 22~64의 둥근 모서리를 사용한다.
이 시각 규칙은 [디자인 시스템](design-system.md)을 통해 루틴·프로필·기록·펫 팩과 중첩 창에도 적용한다.
실제 펫 파일은 기존 런타임에서 읽으며 새 이미지를 추가하지 않는다.

기본 창은 1120×800, 최소 창은 860×680 논리 픽셀이다. 창이 작아져도 가운데 펫과
타이머, 왼쪽 바로가기는 남고 오른쪽 카드만 세로로 스크롤한다. 펫 미리보기는 남은 공간에
맞춰 축소한다. 창 크기를 바꿀 때 컨트롤을 재생성하지 않아 입력 중인 설정을 보존한다.

## 기존 동작

알림 간격은 유효한 분 단위 값을 입력하면 즉시 저장된다. 자리 비움 기준과 선택한 루틴은
‘알림 설정 적용’으로 저장한다. 초기화는 설정 간격으로 돌아간 뒤 일시정지하고,
정지는 00:00을 유지한다. ‘지금 스트레칭’ 버튼을 다시 추가하지 않는다.

루틴·프로필·기록·펫 팩 바로가기는 기존 창을 연다. 펫 선택과 표시 설정은 같은 저장 경로를
사용하며, 저장 실패 시 원래 상태로 돌아간다. 창을 닫으면 트레이에서 계속 실행되고
왼쪽 아래 종료 아이콘으로 앱을 종료한다. 한글 UI와 기존 사용자 데이터 형식은 유지한다.

레이아웃은 `SettingsWindow.Layout.cs`, 설정 저장과 런타임 동기화는 `SettingsWindow.cs`에서
관리한다. 공통 색상과 컨트롤 스타일은 `DesignSystem.cs`, 팝업 페이지 틀은 `Ui.cs`에서 관리한다.
설정 저장소는 기존 경로를 사용한다.

검증 결과와 화면은 [설정 대시보드 검증](validation/2026-09-14-settings-dashboard.md)에 기록한다.
