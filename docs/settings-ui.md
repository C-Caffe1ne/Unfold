# 설정 대시보드

2026-09-14 · 사용자가 제공한 참고 이미지의 세로 아이콘 막대, 큰 중심 카드,
오른쪽 보조 카드와 둥근 외곽 프레임을 현재 Unfold 설정 화면에 적용했다.

## 화면 구성

- 왼쪽 탭: 타이머, 설정, 기록·내보내기, 펫 추가, 앱 종료. 화면 탭을 누르면
  설정 창 안의 본문만 바뀌며 새 창을 열지 않는다. 아이콘에는 한국어 접근성 이름과
  도구 설명이 있고 현재 탭은 크림색으로 표시한다. 펫 추가도 같은 창 안에서 열린다.
- 가운데 위: 높이 196px의 타이머. 남은 시간, 상태명 배지, 재생/일시정지와 정지 아이콘.
- 가운데 아래: 바탕화면과 같은 논리 크기를 사용하는 펫 미리보기, 50~150% 펫 크기 슬라이더와
  200×40px 펫 선택. `펫 크기`는 슬라이더 위, 현재 퍼센트는 슬라이더 아래에 표시한다.
- 타이머 탭 오른쪽: 스트레칭 시간·휴식 시간 카드와 오늘의 완료 기록.
- 설정 탭: **알림 설정**, **타이머 설정**, **앱 동작**, **디버그 도구** 섹션. 알림 설정은 말풍선 위치와
  스트레칭·완료 알림 효과음을, 타이머 설정은 자리 비움 시간·다시 알림 시간을 관리한다.
  앱 동작은 바탕화면 펫 표시와 로그인 시 자동 실행을 관리하며 선택 즉시 반영한다.
  디버그 도구는 실제 타이머·기록을 바꾸지 않고 네 가지 알림 상태를 미리본다.

차콜 바탕과 명도가 다른 카드, 크림색 강조를 사용한다. 2026-09-20 승인 시안에 따라
홈 네 카드의 모서리는 24px, 패딩과 카드 간격은 20px로 맞췄다. 외곽 프레임·내비게이션은 유지한다.
이 시각 규칙은 [디자인 시스템](design-system.md)을 통해 기록·펫 팩과 중첩 창에도 적용한다.
실제 펫 파일은 기존 런타임에서 읽으며 새 이미지를 추가하지 않는다.

기본 창은 1120×800, 최소 창은 860×680 논리 픽셀이다. 창이 작아져도 가운데 펫과
타이머, 왼쪽 바로가기는 남고 오른쪽 카드만 세로로 스크롤한다. 펫 미리보기와 바탕화면 펫은
같은 96/192/288 논리 픽셀을 사용한다. 최소 창의 150%에서만 펫 미리보기 영역을 세로로 확인하며
슬라이더·펫 선택은 고정한다. 창 크기를 바꿀 때 컨트롤을 재생성하지 않아 입력 중인 설정을 보존한다.
펫 만들기처럼 본문이 긴 페이지는 세로 스크롤바 트랙과 8px 거터를 예약해 입력·버튼 위에
스크롤바가 그려지지 않게 한다. 기본·최소·중간 크기에서 같은 규칙을 사용한다.

## 타이머 동작

홈의 **스트레칭 알림 간격**은 작업 후 알림까지의 간격이며 5~240분 범위에서 1분 단위로 조절한다. 진행 중에는 입력을 잠그고,
사용자가 일시정지하거나 정지한 상태에서만 바꿀 수 있다. 그 아래 **휴식 시간**은 1~10분이며
다음에 시작하는 휴식부터 적용하므로 작업 타이머 진행 중에도 바꿀 수 있다. 홈 카드의 **적용**을 누르기 전에는 저장하지 않는다.
설정 탭은 알림·자리 비움·다시 알림 설정을 우측 최하단의 **저장**으로 함께 저장한다.
런타임도 진행 중 간격 변경을 거부한다.
홈 시간 카드는 편집 중 설명을 표시하지 않는다. 적용 성공·실패와 저장되지 않은 값 복원처럼
실제로 발생한 결과만 짧게 표시한다. 홈 숫자 입력은 160×40px, 우측 상단 적용 버튼은 80×40px다.
제목 18px, 본문 14px를 사용하며 타이머 숫자는 64px, 오늘 완료 횟수는 40px다.
진행·일시정지·중지·자리 비움·휴식 대기·휴식 중은 상태명만 표시한다.
활동 감지 오류는 `상태 확인 필요`로 표시하고 세부 오류는 상태 배지 툴팁에서 확인한다.
[홈 UI 구현 검증](validation/2026-09-20-home-ui-implementation.md)에 기본·최소 창과 오류 배치 근거가 있다.

재생/일시정지 버튼은 남은 시간을 유지하며 전환하고, 정지 버튼은 저장된 전체 간격을 표시한다.
정지 후 재생하면 화면에 표시된 전체 간격으로 시작한다. 초기화와 ‘지금 스트레칭’ 버튼은 표시하지 않는다.

기록과 펫 추가는 설정 창 안에서 탭으로 전환한다. **펫 추가** 페이지에는
**펫 팩 열기**와 **펫 팩 만들기** 탭이 있다. 탭이나 내비게이션을 오가도 열린 팩과
작성 중인 이름·동작 파일은 유지된다. 창을 숨겼다가 다시 열어도 유지된다.
사이드바·트레이로 앱을 종료할 때 변경된 펫 초안이 있으면 저장·버리기·취소를 확인한다.
이름이나 필수 동작이 부족하면 계속 작성할 수 있고, 저장 창 취소·실패는 종료를 취소한다.
팩 생성 후 열기 탭으로 전환해 미리보고 설치한다.
사이드바의 타이머·설정·기록·펫 추가 페이지에는 `UNFOLD / …` 경로, 큰 제목과 설명으로
구성된 별도 상단 헤더를 표시하지 않는다. 각 페이지는 탭 또는 첫 카드부터 시작한다.
만들기 탭은 상단의 짧은 이름 입력, 중앙 미리보기, 하단의 다섯 행동 카드, 오른쪽 하단 만들기
버튼 순서로 배치한다. 파일은 각 행동 카드의 **＋** 버튼에서 직접 선택하며, 일반 설정
창에서는 행동 카드 다섯 개를 한 줄로 비교할 수 있다.
설정 최소 창 860×680에서도 다섯 카드가 한 줄에 보이며, 더 좁은 별도 진단 창에서는 줄바꿈하고 세로로만 스크롤한다.
창 높이가 740px 미만이면 미리보기 높이를 줄여 파일 추가 버튼을 표시한다. 현재 미리보기 행동을 표시하며,
다른 행동의 파일을 제거해도 현재 미리보기는 유지된다.
열기 탭의 미리보기 영역은 최대 520px, 동작 미리보기 선택 상자는 200px로 제한해 빈 공간을
과도하게 채우지 않는다.
루틴·업무 프로필 설정과 편집 진입점은 일반 UI에서 제거했다. 기존 `settings.json`의
루틴·프로필 데이터는 업그레이드 과정에서 삭제하지 않으며, 완료 기록의 당시 이름도 유지한다.
펫 선택과 표시 설정은 같은
저장 경로를 사용하며, 저장 실패 시 원래 상태로 돌아간다. 창을 닫으면 트레이에서 계속 실행되고
왼쪽 아래 종료 아이콘으로 앱을 종료한다.
종료 아이콘 바로 위 **테마 선택** 버튼에서 오트 라떼·세이지·미드나이트 블루·플럼을 선택한다.
기본은 오트 라떼이며, 선택 즉시 앱 전체에 반영하고 재실행 때 복원한다. 설정 탭의 저장 버튼과 독립적이다.
설정·홈 시간·펫 만들기의 미저장 초안과 현재 페이지, 타이머 상태는 유지한다.
테마를 저장하지 못하면 기존 색을 유지하고 메뉴에서 다시 선택할 수 있다. 한글 UI와 기존 사용자 데이터 형식은 유지한다.

레이아웃은 `SettingsWindow.Layout.cs`, 홈 저장과 런타임 동기화는 `SettingsWindow.cs`,
설정 탭의 통합 저장·취소는 `SettingsWindow.Preferences.cs`에서
관리한다. 테마 메뉴는 `SettingsWindow.Themes.cs`, 색상은 `DesignSystem.Themes.cs`,
컨트롤 스타일은 `DesignSystem.cs`, 팝업 페이지 틀은 `Ui.cs`에서 관리한다.
설정 저장소는 기존 경로를 사용한다.

기존 레이아웃 검증은 [설정 대시보드 검증](validation/2026-09-14-settings-dashboard.md),
현재 타이머 변경 결과는 [타이머 피드백 검증](validation/2026-09-15-timer-feedback.md)에 기록한다.

펫 페이지 탭 변경과 검증 결과는 [펫 탭 검증](validation/2026-09-16-pet-tabs.md)에 기록한다.

말풍선 위치와 스트레칭·완료 효과음은 설정 탭의 **알림 설정**에서 관리한다.
다시 알림 시간은 같은 페이지의 **타이머 설정**에서 자리 비움 시간과 함께 편집한다.
카드별 적용 버튼은 없고 **취소·저장**이 본문 스크롤 밖의 우측 하단에 있다.
저장된 값과 다를 때만 저장이 활성화되고, 원래 값으로 되돌리거나 저장하면 비활성화된다.
저장 유도 문구는 표시하지 않는다. **취소**는 현재 탭을 유지하며 마지막 저장값으로 복원한다.
입력 오류나 저장 실패는 하단에 표시하고 초안을 유지한다. 가져오기/저장 중에는 중복 작업을 막는다.
설정 저장은 작업 타이머를 초기화하지 않는다. WAV 파일 선택·기본 복원도 저장을 눌러야 설정에 반영된다.
**알림 효과음 사용** 체크박스는 완료 알림 아래에 있다.
설정 본문 최대 폭은 760px, 말풍선 위치는 200px, 숫자 입력은 160px이며 입력·버튼은 40px 높이로 맞췄다.
섹션 제목은 18px, 항목명은 14px, 파일명은 12px다. 긴 파일명은 말줄임하며 버튼 폭을 바꾸지 않는다.
가져온 파일명을 표시하며 미리듣기·정지를 제공한다. 다른 소리를 미리듣거나 페이지를 나가면 이전 미리듣기를 중지한다.
자세한 흐름은 [스트레칭 말풍선 알림](stretch-notifications.md)을 참고한다.

기록 탭을 새로고침하거나 다시 열면 현재 날짜를 확인한다. 최신 기간을 보고 있었다면
새 날짜를 따라가고, 과거 기간을 보고 있었다면 조회 위치를 유지한다.
사이드바 접근성 이름에는 선택된 탭을 표시하며, 탭 이동 후 해당 페이지의 첫 조작 요소로 포커스를 옮긴다.

루틴·프로필 UI 제거와 호환성 검증은 [검증 기록](validation/2026-09-17-remove-routine-profiles.md)에 기록한다.
홈 시간 카드와 휴식 시간 동작은 [검증 기록](validation/2026-09-17-home-break-time.md)에 기록한다.
펫 추가 탭은 본문 최대 760px, 미리보기 최대 520px, 요소 간격 20px를 사용한다.
만들기의 이름 입력은 320×40px이고 다섯 행동 카드는 최소 창에서도 한 줄로 표시한다.
파일이 있는 카드를 누르면 해당 동작을 미리보며, 추가·제거 아이콘은 독립적으로 동작한다.
열기의 동작 선택은 200px, 배경·크기 선택은 148px다. 하단 상태와 설치·생성 버튼은 고정한다.
필드명·현재 값·파일 메타데이터·작업 결과만 표시하며 사용법을 설명하는 고정 문장은 표시하지 않는다.
현재 배치와 검증 결과는 [펫 추가 UI 구현 기록](validation/2026-09-18-pet-tabs-ui.md)에 기록한다.
설정의 각 탭에서 상단 헤더를 제거한 결과는 [검증 기록](validation/2026-09-17-tab-header-removal.md)에 기록한다.
