# 설정 대시보드

2026년 10월 8일 · **Beta v1.1.2** (`1.1.2-beta`, 배포 소스 `ce86c7b`).
최신 공개 배포는 **Beta v1.1.2**다. 아래는 현재 코드의 사용 안내이며, OS별 실제 검증 결과는
[검증 안내](verification.md)에서 확인한다.

## 화면 구성

- 사이드바 순서는 **타이머 → 펫 관리 → 기록 → 설정**이다. 같은 창의 본문을 전환하며 별도 페이지 헤더를 표시하지 않는다.
- 하단에는 현재 빌드 버전, 테마 선택, **Unfold 종료**가 있다. 버전 표시는 `Beta v1.1.2`다.
- 홈 왼쪽에는 타이머와 펫 미리보기, 오른쪽에는 시간 설정과 오늘의 완료 기록을 배치한다.
- 펫 선택기는 200px이며 기본 펫 5종과 유효한 설치 펫을 표시한다. 크기는 50~150%, 10% 단위로 조절한다.
- 설정은 **알림 설정·타이머 설정·앱 동작·앱 정보·계정·디버그 도구**로 구성한다.

기본 창은 1120×800, 최소 창은 640×560 논리 픽셀이다. 너비 860px 이상에서는 홈 두 열을 유지하고,
그보다 좁으면 한 열로 바꾸어 세로 스크롤한다. 펫 미리보기와 바탕화면 펫은 96/192/288 논리 픽셀을 사용한다.
창 크기·페이지 변경 시 입력 컨트롤을 다시 만들지 않아 초안을 보존한다. 긴 본문은 세로로 스크롤한다.

## 타이머와 홈 시간 저장

**스트레칭 알림 간격**은 1~240분, 1분 단위다. 일시정지 또는 정지 상태에서만 바꾼다.
**휴식 시간**은 1~10분이며 작업 중에도 바꿀 수 있고 다음 휴식에 적용한다. 이미 열린 휴식 시간은 유지한다.
홈 시간 카드의 **저장**을 눌러야 두 값을 저장한다. 변경이 없으면 버튼은 투명·비활성 상태이며 자리는 유지한다.
잘못된 입력은 저장하지 않고, 저장 실패 시 결과를 표시하며 입력을 보존한다.

재생/일시정지는 남은 시간을 유지한다. **중지**는 확인 후 저장된 전체 간격을 표시하며 열린 알림을 완료 기록 없이 취소한다.
다시 재생하면 전체 간격부터 시작한다. 간격이 5분 이하면 사전 알림을 생략한다.
상태 배지는 진행 중·일시정지·정지·자리 비움·휴식 대기·휴식 중을 구분한다. 활동 감지 오류의 세부 내용은 툴팁에서 확인한다.

## 설정의 자동 저장

알림·자리 비움·다시 알림 설정은 변경 즉시 저장한다. 설정 페이지에는 **취소·저장** 버튼이나 페이지 이동 시 저장 확인 창이 없다.
홈 시간 카드의 **저장**과 펫 초안의 저장은 별도다. 설정 저장으로 작업 타이머를 초기화하지 않는다.
잘못된 입력이나 저장 실패는 페이지 하단에 표시한다. 유효한 저장값은 유지하며 수정 후 다시 저장을 시도한다.

- **말풍선 불투명도**: 0~100%. 펫 몸의 불투명도는 바꾸지 않는다.
- **펫 대사**: 사전 알림·휴식 초대·휴식 중·휴식 시간 초과·휴식 완료의 5종, 각 1~120자.
  공백만 입력하면 오류를 표시하고 해당 입력을 저장하지 않는다. **기본 대사로 복원**은 5종을 기본값으로 돌리고 저장한다.
  기존 JSON에 잘못된 대사가 있으면 로드할 때 기본 문구로 복구한다.
- 말풍선은 펫 위치와 화면 작업 영역에 따라 자동 배치한다. 별도 위치 선택기는 없다.
- **알림 효과음 사용**, **전체 소리·스트레칭 알림·완료 알림**은 즉시 저장한다. 각 음량은 0~100%이며 실제 음량은 전체 값 × 해당 개별 값이다.
- 효과음은 WAV·MP3·OGG를 **파일 가져오기**로 선택하거나 **기본**으로 복원한다. 가져오기·복원 성공 시 바로 반영한다.
  각 소리의 재생/중지 아이콘으로 미리들을 수 있고 페이지 이동·창 숨김 시 미리듣기를 종료한다.
- **자리 비움 시간·다시 알림 시간**은 각각 1~60분이다.
- **바탕화면 펫 표시·로그인 시 자동 실행**과 테마 선택도 즉시 반영·저장한다.

세 음량 슬라이더 왼쪽에 음량 아이콘, 오른쪽에 **0~100%** 값을 표시하며 개별 알림만 미리듣기 버튼을 제공한다.
재생 중 볼륨을 조절해도 미리듣기는 기존 크기로 끝까지 재생한다. 바꾼 크기는 다음 미리듣기·알림부터 적용한다.
파일명은 말줄임으로 표시한다. 가져오기 중에는 설정 입력을 잠가 중복 작업을 막는다.
효과음 형식·길이·원본 보존 계약은 [말풍선·효과음 안내](stretch-notifications.md)를 따른다.

## 펫 관리와 초안

**펫 관리 → 파일 열기…**에서 확장자에 따라 기존 팩 확인 창, 이미지/영상 편집 또는 GLB 편집을 연다.
열기/만들기 하위 탭과 형식 선택 탭은 없다. 펫 이름 아래 **행동 연결 → 상황**에서 한 행동을 골라
썸네일·동작 파일·재생 방식을 편집한다. 파일명은 말줄임과 전체 이름 툴팁을 제공한다.

미디어는 **한 번 / 반복 / 핑퐁**, GLB는 애니메이션·방향·속도·**한 번 / 반복**을 지정한다.
**펫 팩 만들기…**로 파일을 내보낸 뒤 확인 창의 **저장**으로 설치하며, GLB는 **저장하고 적용**도 제공한다.
페이지·형식을 바꾸거나 창을 숨겨도 두 초안은 유지한다. 저장 취소·실패도 초안을 보존한다.
종료할 때 미저장 펫이 있으면 저장·버리기·취소를 확인한다. 픽셀 그림 편집기는 제거했다.

GLB의 **3D 파일** 휴지통은 모델 초안만 비운다. 설치된 펫은 **펫 삭제**에서 별도로 확인 후 삭제한다.
**펫 선택**은 설치한 3D·이미지·영상 펫을 모두 표시하며, 선택하면 기존 설정을 편집한다.
**편집**으로 저장된 내용을 다시 불러오고 **저장하고 적용**으로 같은 펫을 갱신한다. 기본 제공 펫은 제외한다.
사용 중인 커스텀 펫 삭제 시 기본 펫으로 전환하고, 다른 펫과 원본 파일은 유지한다.
루틴·업무 프로필·내 휴식 만들기 진입점은 없으며 이전 설정과 완료 기록의 이름은 보존한다.
자세한 계약은 [펫 팩](pet-packs.md), [GLB 펫](glb-pets.md), [기존 데이터 호환](personalization.md)을 따른다.

## 계정·업데이트·테마·기록

**설정 → 앱 정보 → 업데이트 확인**은 다운로드·재시작 적용 창을 연다. 소스 실행은 설치된 업데이트 대상이 아니다.

업데이트 가능한 새 버전이 있으면 앱 시작 시 로그인 복원이 끝난 뒤 변경내용을 모달로 한 번 안내한다.
백그라운드 자동 실행에서는 앱 화면을 열 때 안내한다. 최신 버전이거나 조회에 실패하면 시작 안내를 띄우지 않는다.
다운로드·재시작은 사용자가 선택하며, 닫아도 메뉴의 업데이트 확인에서 다시 열 수 있다.
**계정**에는 Google 이메일과 **로그아웃**이 있다. 로그아웃은 이용 기능을 멈추고 OS에 보관한 로그인 정보를 삭제한다.
재실행은 저장된 세션과 권한을 먼저 복원한다. 복원 성공 시 로그인 창을 표시하지 않는다.
[계정 안내](account-screen.md), [배포·업데이트 검증](validation/2026-10-08-beta-v1.1.2-release.md)을 참고한다.

기본 테마는 **유연한 라일락**이다. 선택 목록은 라일락·다정한 오트·숨 고르는 숲·밤의 버터 순서며 밤의 버터만 어두운 테마다.
테마 변경은 홈 시간·펫 초안·현재 페이지·타이머 상태를 보존한다.
기록은 7일 단위로 조회·CSV 내보내기하며, 최신 기간은 날짜 변경을 따라가고 과거 기간은 유지한다.
사이드바에는 한국어 접근성 이름과 선택 상태를 표시하고 이동 후 페이지의 조작 요소로 포커스를 옮긴다.
디버그 미리보기는 실제 타이머·세션·완료 기록을 바꾸지 않는다.
