# 설정 대시보드

2026-09-14 · 사용자가 제공한 참고 이미지의 세로 아이콘 막대, 큰 중심 카드,
오른쪽 보조 카드와 둥근 외곽 프레임을 현재 Unfold 설정 화면에 적용했다.

## 화면 구성

- 왼쪽 탭: 타이머, 내 루틴·업무 프로필, 기록·내보내기, 펫 추가, 앱 종료. 화면 탭을 누르면
  설정 창 안의 본문만 바뀌며 새 창을 열지 않는다. 아이콘에는 한국어 접근성 이름과
  도구 설명이 있고 현재 탭은 크림색으로 표시한다. 펫 추가도 같은 창 안에서 열린다.
- 가운데 위: 선택한 펫의 큰 미리보기, 너비 200px의 펫 선택, 바탕화면 표시와 로그인 시 자동 실행.
- 가운데 아래: 남은 시간, 색상·문구로 구분한 진행·일시정지·정지 상태, 재생/일시정지와 정지 아이콘.
- 오른쪽: 우측 상단 적용 버튼이 있는 알림 간격·자리 비움 기준 카드, 휴식 루틴, 말풍선 알림 설정, 오늘의 완료 기록.

차콜 바탕과 명도가 다른 카드, 크림색 강조, 22~64의 둥근 모서리를 사용한다.
이 시각 규칙은 [디자인 시스템](design-system.md)을 통해 루틴·프로필·기록·펫 팩과 중첩 창에도 적용한다.
실제 펫 파일은 기존 런타임에서 읽으며 새 이미지를 추가하지 않는다.

기본 창은 1120×800, 최소 창은 860×680 논리 픽셀이다. 창이 작아져도 가운데 펫과
타이머, 왼쪽 바로가기는 남고 오른쪽 카드만 세로로 스크롤한다. 펫 미리보기는 남은 공간에
맞춰 축소한다. 창 크기를 바꿀 때 컨트롤을 재생성하지 않아 입력 중인 설정을 보존한다.

## 타이머 동작

알림 간격은 5~240분 범위에서 1분 단위로 조절한다. 진행 중에는 입력을 잠그고,
사용자가 일시정지하거나 정지한 상태에서만 바꿀 수 있다. 숫자를 바꿔도 즉시 저장하지 않으며
알림 설정 카드 우측 상단의 **적용**을 눌러 간격·자리 비움 기준·루틴을 함께 저장한다.
런타임도 진행 중 간격 변경을 거부하므로 업무 프로필로 우회해 바꿀 수 없다.

재생/일시정지 버튼은 남은 시간을 유지하며 전환하고, 정지 버튼은 00:00을 유지한다.
정지 후 재생하면 저장된 전체 간격으로 시작한다. 초기화와 ‘지금 스트레칭’ 버튼은 표시하지 않는다.

루틴·프로필과 기록, 펫 추가는 설정 창 안에서 탭으로 전환한다. **펫 추가** 페이지에는
**펫 팩 열기**와 **펫 팩 만들기** 탭이 있다. 탭이나 내비게이션을 오가도 열린 팩과
작성 중인 이름·동작 파일은 유지된다. 창을 숨겼다가 다시 열어도 유지되며, 앱을 종료하면
저장하지 않은 초안은 사라진다. 팩 생성 후 열기 탭으로 전환해 미리보고 설치한다.
루틴·프로필의 생성·편집은 대화상자를 연다. 펫 선택과 표시 설정은 같은
저장 경로를 사용하며, 저장 실패 시 원래 상태로 돌아간다. 창을 닫으면 트레이에서 계속 실행되고
왼쪽 아래 종료 아이콘으로 앱을 종료한다. 한글 UI와 기존 사용자 데이터 형식은 유지한다.

레이아웃은 `SettingsWindow.Layout.cs`, 설정 저장과 런타임 동기화는 `SettingsWindow.cs`에서
관리한다. 공통 색상과 컨트롤 스타일은 `DesignSystem.cs`, 팝업 페이지 틀은 `Ui.cs`에서 관리한다.
설정 저장소는 기존 경로를 사용한다.

기존 레이아웃 검증은 [설정 대시보드 검증](validation/2026-09-14-settings-dashboard.md),
현재 타이머 변경 결과는 [타이머 피드백 검증](validation/2026-09-15-timer-feedback.md)에 기록한다.

펫 페이지 탭 변경과 검증 결과는 [펫 탭 검증](validation/2026-09-16-pet-tabs.md)에 기록한다.

말풍선 위치·다시 알릴 시간·효과음은 **말풍선 알림** 카드에서 설정한다.
해당 카드의 적용 버튼은 작업 타이머를 초기화하지 않는다. WAV 파일 가져오기와 기본 효과음 복원은 즉시 저장한다.
자세한 흐름은 [스트레칭 말풍선 알림](stretch-notifications.md)을 참고한다.
