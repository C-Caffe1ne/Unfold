# GLB 펫

Beta v1.0.4 개발본의 **펫 추가 → 펫 팩 만들기 → 파일 열기…**에서 모델을 가져온다.
이 기능의 검증 대상과 실행 경로는 [Beta GLB 통합 기록](validation/2026-10-04-beta-glb-pets.md)에 있다.

1. **파일 열기…**로 GLB 모델을 가져온다. 파일 형식은 자동 전환된다. 기존 펫은 파일 형식 **GLB**에서 저장한 펫 선택 목록으로 연다.
2. 펫 이름을 입력하고 **행동 연결 → 상황**에서 편집할 행동을 고른다.
3. 선택한 상황의 **애니메이션**, **재생 방식**, **속도**를 지정하고 옆의 미리보기로 확인한다.
4. **펫 팩 만들기…**로 `.unfoldpet` 파일을 저장한다. **펫 팩 열기** 탭에서 확인 후 **저장**을 누르면 설치·적용된다.
5. 바로 설치하려면 **저장하고 적용**을 사용한다. 변경 후 활성화되며 빈 이름은 저장할 수 없다.

넓은 창은 미리보기와 행동 설정을 나란히 배치한다. 좁은 창은 작은 미리보기와 설정을 세로로 배치하며 필요한 부분으로 스크롤한다. 표시 각도와 루트 뼈대는 **표시 방향 · 고급 설정**에서 바꾼다.

기본 대기, 마우스 올리기, 클릭, 들어 올리기, 드래그 중, 놓기, 휴식 알림·시작·완료,
화면 위 걷기, 잠자기, 두리번거리기, 하품, 휴식 미루기의 14개 상황을 연결할 수 있다.
속도는 0.25~3배다. 모델에 없는 애니메이션을 새로 생성하지는 않는다.

| 상황 | 재생 방식 | 이유 |
|---|---|---|
| 기본 대기 | 항상 반복 | 다른 행동이 시작될 때까지 대기 |
| 드래그 중 | 항상 반복 | 잡고 있는 상태 유지 |
| 화면 위 걷기 | 항상 반복 | 휴식 중 걷는 상태 유지 |
| 들어 올리기 | 한 번으로 고정 | 드래그 중 상태로 전환 |
| 놓기 | 한 번으로 고정 | 기본 동작으로 복귀 |
| 나머지 상황 | 한 번 / 반복 선택 | 반복은 다른 행동이 시작될 때까지 지속 |

고정된 항목은 선택을 비활성화한다. 마우스 올리기의 반복은 마우스를 떼면 끝나며, 휴식 시작을 반복으로 설정하면 휴식 중 걷기로 자동 전환하지 않는다.
**연결 안 함**은 별도 애니메이션을 지정하지 않는다는 뜻이며 반복·속도는 비활성화된다. 들기·드래그·놓기 중 일부만 지정하면 저장 시 나머지는 기본 대기로 보완한다.

**한 번**은 마지막 자세에서 멈추며 실제 펫에서는 기본 동작으로 돌아간다. **처음부터 재생**은 일시정지를 해제하고 다시 시작한다. **일시정지 / 계속 재생**은 현재 위치를 유지한다. 미지정 상황을 선택하면 기본 대기를 미리 보여 준다. 미리보기에서 상황만 바꾸는 것은 저장 설정을 변경하지 않는다.

카메라와 전체 몸의 방향은 고정한다. 루트 이동·회전은 기본 대기의 첫 자세를 기준으로 잠그며,
하위 관절과 표정 모프는 재생한다. 기본값은 자동 루트 선택이며 필요한 경우 루트를 직접 선택할 수 있다.
**바라보는 방향**에서 최초 표시 각도를 바꿀 수 있다. 걷는 방향에 따라 캐릭터를 좌우 반전하지 않는다.
기존 클릭 판정, 창 드래그, 들어 올리기·착지와 말풍선 흐름을 사용한다.
마우스 반응에는 캔버스 변형을 추가하지 않는다. 놓으면 바운스 단계를 거치지 않고 지정한 `land` 클립을 바로 재생한다.

편집 화면에는 항목별 설명, 반복 규칙 해설, 클립 재생 요약, 삼각형·관절 통계를 표시하지 않는다.
파일 형식을 바꾸거나 탭을 이동해도 작성 중인 GLB·이미지/영상 초안은 각각 유지된다.

원본 GLB는 수정하지 않는다. 사용자 라이브러리에 모델 사본, 투명 썸네일과 행동 설정을 저장한다.
같은 펫을 다시 저장할 때 콘텐츠 버전을 증가시키고 기존 펫 팩 검증·원자적 설치 경로로 업데이트한다.

## 지원 범위

- 32 MiB 이하 GLB 2.0, 내장 PNG 텍스처, 비압축 삼각형 최대 10만 개.
- 정점당 최대 4개 관절 가중치, 뼈대 애니메이션·위치 모프, LINEAR/STEP/CUBICSPLINE 보간.
- OPAQUE/MASK 재질. JPEG, BLEND, 외부 파일 참조, 압축 메시, 필수 확장, sparse accessor는 오류로 안내한다.
- 표시 크기·화면 배율·미리보기 확대에 맞춘 투명 CPU 렌더링, 최대 20fps. Retina 2배 화면에서는 기본 크기 384px, 150% 크기 576px로 다시 그린다. 최대 출력은 1024×1024이며 2×2 샘플로 가장자리를 부드럽게 처리한다.
- 계산은 작업 스레드에서 수행한다. 첫 192px 프레임과 최근 렌더 한 장을 보관하고, 일시정지·완료 상태에서도 크기나 화면 배율이 바뀌면 현재 자세만 다시 그린다.

게임 전용 셀 셰이더·조명·그림자까지 재현하지는 않는다. 복잡한 모델의 성능과 표시 품질은 달라질 수 있다.
검증에 사용한 Kazusa 모델은 저장소와 배포물에 포함하지 않는다.
