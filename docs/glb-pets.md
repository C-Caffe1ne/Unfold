# GLB 펫

2026-10-06 확인한 Beta v1.1.0 개발본의 **펫 관리 → 파일 열기…**에서 모델을 가져온다.
이 기능의 검증 대상과 실행 경로는 [Beta GLB 통합 기록](validation/2026-10-04-beta-glb-pets.md)에 있다.

1. 펫 이름 오른쪽의 **파일 열기…**로 GLB·GIF·MP4·이미지 또는 기존 `.unfoldpet`을 가져온다. 확장자로 편집 화면을 자동 선택하며 파일 형식 드롭다운은 없다. 미리보기 재생 버튼 아래 **펫 선택** 목록으로 설치된 GLB 모델을 다시 열 수 있다.
2. 펫 이름을 입력하고 **행동 연결 → 상황**에서 편집할 행동을 고른다.
3. 선택한 상황의 **애니메이션**, 그 아래의 **바라보는 방향**, **재생 방식**, **속도**를 지정하고 옆의 미리보기로 확인한다. 방향은 상황별로 각각 저장한다.
4. **펫 팩 만들기…**로 `.unfoldpet` 파일을 저장한다. 열리는 **펫 팩 확인** 창에서 확인 후 **저장**을 누르면 설치·적용된다.
5. 바로 설치하려면 **저장하고 적용**을 사용한다. 변경 후 활성화되며 빈 이름은 저장할 수 없다.
6. 미리보기 아래 **3D 파일** 행의 **휴지통**으로 넣은 GLB를 바로 비운다. 확인 창 없이 현재 파일·행동 연결·미리보기만 비우며, 펫 이름·원본 GLB·앱에 저장된 펫은 유지한다. **＋** 또는 **파일 열기…**로 다시 넣을 수 있다.
7. 앱에 저장한 펫 자체를 제거하려면 해당 펫을 열고 **펫 선택** 아래의 **펫 삭제**를 사용한다. 확인 후 앱 목록에서 제거하며, 사용 중인 펫이면 기본 펫으로 전환한다.

넓은 창은 미리보기와 행동 설정을 나란히 배치한다. 좁은 창은 작은 미리보기와 설정을 세로로 배치하며 필요한 부분으로 스크롤한다. 기준 뼈대는 자동으로 선택하며 별도 뼈대 입력과 고급 설정 영역은 없다.

기본 대기, 마우스 올리기, 클릭, 들어 올리기, 드래그 중, 놓기, 휴식 알림·시작·완료,
화면 위 걷기, 잠자기, 두리번거리기, 하품, 휴식 미루기의 14개 상황을 연결할 수 있다.
속도는 0.25~3배다. 모델에 없는 애니메이션을 새로 생성하지는 않는다.

기본 대기는 항상 반복한다. 나머지 모든 상황은 **한 번 / 반복**을 선택할 수 있다.
반복은 다음 상호작용이나 상황 전환까지 지속된다. 마우스 올리기의 반복은 마우스를 떼면 끝난다.
들어 올리기를 반복하면 놓을 때까지 해당 동작을 유지하고, 한 번이면 완료 후 드래그 중 동작으로 전환한다.
드래그 중을 한 번으로 지정하면 마지막 자세를 놓을 때까지 유지한다.
놓기를 반복해도 다음 클릭·드래그·알림을 가로막지 않는다.
걷기를 한 번으로 지정하면 한 차례 재생 후 이동을 멈추고 기본 대기로 돌아간다.
휴식 시작을 반복으로 설정하면 휴식 중 걷기로 자동 전환하지 않는다.
**연결 안 함**은 별도 애니메이션을 지정하지 않는다는 뜻이며 방향·반복·속도는 비활성화된다. 들기·드래그·놓기 중 일부만 지정하면 저장 시 나머지는 기본 대기로 보완한다.

미리보기의 **한 번**은 마지막 자세에서 멈추며 실제 펫의 일반 반응은 완료 후 기본 동작으로 돌아간다. **처음부터 재생**은 일시정지를 해제하고 다시 시작한다. **일시정지 / 계속 재생**은 현재 위치를 유지한다. 미지정 상황을 선택하면 기본 대기를 미리 보여 준다. 미리보기에서 상황만 바꾸는 것은 저장 설정을 변경하지 않는다.

카메라와 전체 몸의 방향은 고정한다. 루트 이동·회전은 기본 대기의 첫 자세를 기준으로 잠그며,
하위 관절과 표정 모프는 재생한다. 새 모델은 자동 루트 선택을 사용한다. 이전 저장본에 수동 기준 뼈대가 있으면 호환을 위해 유지한다.
**바라보는 방향**에서 행동마다 표시 각도를 바꿀 수 있다. 이전 팩의 공통 방향은 행동별 값을 지정하기 전까지 유지한다. 걷는 방향에 따라 캐릭터를 좌우 반전하지 않는다.
기존 클릭 판정, 창 드래그, 들어 올리기·착지와 말풍선 흐름을 사용한다.
마우스 반응에는 캔버스 변형을 추가하지 않는다. 놓으면 바운스 단계를 거치지 않고 지정한 `land` 클립을 바로 재생한다.

편집 화면에는 항목별 설명, 반복 규칙 해설, 클립 재생 요약, 삼각형·관절 통계를 표시하지 않는다.
다른 형식의 파일을 열거나 사이드바로 이동해도 GLB·이미지/영상 초안은 각각 유지된다.

원본 GLB는 수정하지 않는다. 사용자 라이브러리에 모델 사본, 투명 썸네일과 행동 설정을 저장한다.
같은 펫을 다시 저장할 때 콘텐츠 버전을 증가시키고 기존 펫 팩 검증·복구 가능한 설치 경로로 업데이트한다.
기존 팩은 설치된 콘텐츠 버전보다 낮거나 같은 버전의 내용이 달라도 다시 적용할 수 있다. 원본 팩의 행동 설정을 그대로 설치하며 파일 무결성 검사는 유지한다.

## 지원 범위

아래 BLEND·중복 동작 이름 지원은 [2026-10-06 로컬 호환성 수정](validation/2026-10-06-glb-compatibility.md) 기준이며 공개 Beta v1.1.0에는 아직 포함되지 않았다.

- 32 MiB 이하 GLB 2.0, 내장 PNG 텍스처, 비압축 삼각형 최대 10만 개.
- 정점당 최대 4개 관절 가중치, 뼈대 애니메이션·위치 모프, LINEAR/STEP/CUBICSPLINE 보간.
- OPAQUE/MASK/BLEND 재질. 반투명 면은 불투명 면 뒤에 깊이 순서로 합성한다. 서로 관통하는 투명 면의 정렬은 제한적이다. JPEG, 외부 파일 참조, 압축 메시, 필수 확장, sparse accessor는 오류로 안내한다.
- 중복 애니메이션 이름은 원본을 수정하지 않고 `(2)`, `(3)` 등으로 구분한다. 시간 키의 중복·역순과 120초 초과는 해당 동작명을 포함해 오류로 안내한다.
- 표시 크기·화면 배율·미리보기 확대에 맞춘 투명 CPU 렌더링, 최대 20fps. Retina 2배 화면에서는 기본 크기 384px, 150% 크기 576px로 다시 그린다. 최대 출력은 1024×1024이며 2×2 샘플로 가장자리를 부드럽게 처리한다.
- 계산은 작업 스레드에서 수행한다. 클립의 첫 192px 프레임을 보관하고, 실제 재생에서는 뷰가 소유한 두 픽셀 버퍼와 비트맵을 재사용한다. 일시정지·완료 상태에서도 크기나 화면 배율이 바뀌면 현재 자세만 다시 그린다.

게임 전용 셀 셰이더·조명·그림자까지 재현하지는 않는다. 복잡한 모델의 성능과 표시 품질은 달라질 수 있다.
검증에 사용한 Kazusa 모델은 저장소와 배포물에 포함하지 않는다.

## 로딩·메모리 관리

[2026-10-06 공통 파이프라인 개선](validation/2026-10-06-glb-pipeline-memory.md)은 특정 캐릭터 설정 없이 모든 지원 GLB에 적용한다. 펫 목록에서는 메타데이터만 읽고 사용할 때 모델을 디코딩한다. 내용이 같은 파일은 디코딩 모델을 공유하며, 목록과 캐시가 사용하지 않는 모델을 계속 붙잡지 않도록 약한 참조를 사용한다. 키프레임·자세 계산·재생 출력의 할당을 줄이며 해상도와 안티앨리어싱은 유지한다. 편집 초안은 화면을 떠나도 유지되므로 편집 중인 모델을 소유할 수 있다. 이 변경은 로컬 개발본에 반영했으며 Windows 실기 RAM 감소량과 공개 배포는 아직 확인하지 않았다.
