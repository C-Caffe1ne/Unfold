# Unfold 제품 방향

2026-09-13 · 현재 사용자의 경쟁력·유료 가치 개발 요청을 기준으로 정한 방향.
2026-09-22 · 상품 구성을 **단일 유료 앱 + 3일 무료 체험**으로 변경했다.
구현 상태는 [MVP 범위](mvp.md), 작업 순서는 [개발 계획](development-plan.md)을 따른다.

## 제품과 고객

**작업 흐름에 맞는 짧은 휴식과 나만의 펫을 함께 제공하는 데스크톱 동료.**
PC에서 오래 일하고, 반복 알림은 쉽게 끄지만 시각적 동료와 개인 루틴은 좋아하는
개발자·디자이너·창작자를 초기 고객으로 삼는다. “Mochi와 잠깐 쉬고, 내 리듬으로
돌아오세요”를 첫 가치 제안으로 사용한다.

고객이 얻는 가치는 알림을 받고 끝나는 것이 아니라, 지금 할 수 있는 짧은 휴식을
선택하고, 미루거나 완료하고, 자신이 쉬어 간 흔적을 확인하는 것이다. 펫은 이
진행에 반응한다. 관리하지 않았다고 아프거나 죽는 벌칙과 연속 기록의 압박은 두지 않는다.

## 경쟁 판단과 지불 이유

2026-09-13 공식 페이지를 확인했다. 기능·표시 가격은 사업자의 설명이며 Unfold의
전환율·매출·지불 의사를 입증하지 않는다.

| 비교 대상 | 확인한 제안 | Unfold의 선택 |
|---|---|---|
| [Stretchly](https://github.com/hovancik/stretchly) | 무료 휴식 알림, 유휴 및 방해 금지 대응 | 타이머 정확성·미루기·기본 제어를 무료 품질 기준으로 제공 |
| [Viraam](https://www.viraam.app/) | 여러 휴식 유형·회의 감지·사용 추이, $49.99 일회성 또는 구독 | 개인 일정에 맞는 실용성은 유료 후보지만 기능 단독의 독창성을 주장하지 않음 |
| [MicroJoyz](https://microjoyz.com/overview) | macOS 펫·리마인더·상호작용, 기본 앱 $9.99 일회성 | ‘펫+알림’ 자체는 이미 경쟁이 존재. 휴식 진행과 펫의 일관된 연결에 집중 |
| [Desktop Mate DLC](https://store.steampowered.com/app/3359730/Desktop_Mate__DLC/) | 라이선스 캐릭터를 별도 판매, 해당 DLC $14.99 | 캐릭터 팩 판매는 가능성이 있는 방식. 알려진 IP의 팬덤·가격을 오리지널 펫에 전이하지 않음 |

차별화 가설은 **Windows/macOS에서 일관된 휴식 경험, 직접 조절하는 루틴,
상황에 맞는 펫 반응, 로컬 기록**의 결합이다. 최초 검증 대상은 기존 알림을 끄던
사람이 Unfold는 계속 켜 두고 실제로 짧은 휴식을 선택하는가다. 이 조합만으로
경쟁 우위가 확정되지는 않는다.

## 상품 구성안

기능으로 무료·유료를 나누던 Free/Plus 구성을 폐기하고 **단일 유료 앱 + 3일 무료 체험**으로
정했다. 이전의 Free / Plus / 펫 팩 / 개인 펫 제작 4분할은 더 이상 쓰지 않는다.

| 상품 | 제공할 가치 | 가격·개발 상태 |
|---|---|---|
| 무료 체험 | 설치 후 **3일간 전체 기능** | 계정 가입 필요. 체험 시작 시각은 서버에서 고정해 재설치로 초기화되지 않게 한다. **미구현** |
| Unfold | 타이머, 휴식 루틴, 말풍선 알림, 펫 표시·크기, 테마 4종, 기록·7일 회고·CSV 내보내기, 펫 팩 설치, 커스텀 펫 제작 | 일회성 **$12.99 / $14.99** 비교 가설. Lemon Squeezy 결제. 계정·체험·권한 판정 모두 **미구현** |
| 펫 팩 | 고유한 외형·개성·상황별 애니메이션 | 후순위. 판매 승인된 아트가 아직 없다 |

**기능으로 과금 경계를 나누지 않는다.** 체험이 끝나면 결제 안내를 표시하고, 기존 설정·완료
기록·설치된 펫 파일은 지우지 않고 보존한다. 결제 확인 실패나 오프라인이 앱 실행을 막지 않게 한다.

### 구성 변경 근거

- 원래 Plus의 네 축 가운데 루틴 라이브러리와 업무 프로필은 2026-09-17에 UI를 제거했고,
  방해 상황별 제어는 미구현이다. 남은 회고·내보내기 하나만으로는 단독 상품이 되지 않는다.
  [호환 안내](personalization.md)
- 펫 팩 판매는 판매 승인된 아트가 0종이라 당장 열 수 없다.
- 커스텀 펫 제작은 계획 단계 없이 2026-09-16에 구현됐다. 단일 상품 구성에서는 이 기능을
  유료 경계로 삼지 않고 제품 기능으로 포함한다.

가격은 시험값이다. 2026-09-14 조사에서 확인한 유료 경쟁 제품은 모두 macOS 전용이었고
$9.99~$49.99대였다. 이 사실이 Unfold의 지불 의사나 적정 가격을 증명하지 않는다.
Stretchly·BreakTimer·Stretch 같은 무료 오픈소스 대안이 같은 기능 범위를 다룬다.
[경쟁 분석](competitive-analysis.md)
매달 신규 기능·콘텐츠를 약속하는 구독은 두지 않는다.
현재 개발 빌드에는 계정·체험·결제가 없고 모든 기능을 로그인 없이 쓸 수 있다.

## 개발 원칙과 검증

첫 단계는 휴식 세션, 내 루틴 편집과 리소스 규격을 완성했다. 다음 단계의 개인화 데모는
여러 루틴·수동 프로필·회고를 연결한다. 실제 사용 결과에서 가장 큰 이탈 이유를 확인한다. OS별
회의·전체화면 감지는 별도 실기 검증이 필요한 기능이며 현재 지원한다고 홍보하지 않는다.

초기 20명 안팎의 **3일 체험**에서 첫 알림 이해, 자발적 재실행, 완료·미루기·건너뛰기,
알림을 끈 이유를 조사한다. 체험이 3일이므로 7일 시점의 재사용은 체험 기간 안에서
측정할 수 없다. 7일·30일 재사용은 결제한 사용자를 대상으로 따로 관찰한다.
앱의 완료 기록은 버튼으로 확인한 기록이며 실제 신체 활동 측정이 아니다.
체험 중의 구매 의사 표시는 약한 증거이고, 실제 결제·환불·지원 비용까지 확인해야
가격과 BM을 채택한다. 시장 규모와 CAC는 아직 미확인이다.

최초 유입은 실제 동작 영상과 개발·디자인 커뮤니티, 소개 페이지에서 얻는다.
외부 게시·유료 광고·결제 서비스 계약은 별도 실행 결정이 필요하다. 이번 작업은
제품과 로컬 문서·도구를 만든다.
