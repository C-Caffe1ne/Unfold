# Unfold 제품 방향

2026-09-13 · 현재 사용자의 경쟁력·유료 가치 개발 요청을 기준으로 정한 방향.
구현 상태는 [MVP 범위](mvp.md), 작업 순서는 [개발 계획](development-plan.md)을 따른다.

## 제품과 고객

**작업 흐름에 맞는 짧은 휴식과 나만의 펫을 함께 제공하는 데스크톱 동료.**
PC에서 오래 일하고, 반복 알림은 쉽게 끄지만 시각적 동료와 개인 루틴은 좋아하는
개발자·디자이너·창작자를 초기 고객으로 삼는다. “Mochi와 잠깐 쉬고, 내 리듬으로
돌아오세요”를 첫 가치 제안으로 사용한다.

고객이 얻는 가치는 알림을 받고 끝나는 것이 아니라, 지금 할 수 있는 짧은 휴식을
선택하고, 미루거나 완료하고, 자신이 쉬어 간 흔적을 확인하는 것이다. 펫은 이
진행에 반응한다. 관리하지 않았다고 아프거나 죽는 벌칙과 연속 기록의 압박은 두지 않는다.

## 경쟁 판단과 지불 이유

2026-09-13 공식 페이지를 확인했다. 기능·표시 가격은 사업자의 설명이며 Unfold의
전환율·매출·지불 의사를 입증하지 않는다.

| 비교 대상 | 확인한 제안 | Unfold의 선택 |
|---|---|---|
| [Stretchly](https://github.com/hovancik/stretchly) | 무료 휴식 알림, 유휴 및 방해 금지 대응 | 타이머 정확성·미루기·기본 제어를 무료 품질 기준으로 제공 |
| [Viraam](https://www.viraam.app/) | 여러 휴식 유형·회의 감지·사용 추이, $49.99 일회성 또는 구독 | 개인 일정에 맞는 실용성은 유료 후보지만 기능 단독의 독창성을 주장하지 않음 |
| [MicroJoyz](https://microjoyz.com/overview) | macOS 펫·리마인더·상호작용, 기본 앱 $9.99 일회성 | ‘펫+알림’ 자체는 이미 경쟁이 존재. 휴식 진행과 펫의 일관된 연결에 집중 |
| [Desktop Mate DLC](https://store.steampowered.com/app/3359730/Desktop_Mate__DLC/) | 라이선스 캐릭터를 별도 판매, 해당 DLC $14.99 | 캐릭터 팩 판매는 가능성이 있는 방식. 알려진 IP의 팬덤·가격을 오리지널 펫에 전이하지 않음 |

차별화 가설은 **Windows/macOS에서 일관된 휴식 경험, 직접 조절하는 루틴,
상황에 맞는 펫 반응, 로컬 기록**의 결합이다. 최초 검증 대상은 기존 알림을 끄던
사람이 Unfold는 계속 켜 두고 실제로 짧은 휴식을 선택하는가다. 이 조합만으로
경쟁 우위가 확정되지는 않는다.

## 상품 구성안

| 상품 | 제공할 가치 | 가격·개발 상태 |
|---|---|---|
| Free | Mochi, 기본 루틴과 직접 편집하는 내 루틴 1개, 휴식 시작·미루기·건너뛰기·완료, 오늘의 로컬 기록, 기본 알림 설정 | 무료. 1차 구현 범위 |
| Plus | 여러 사용자 루틴과 업무·시간대 프로필, 주간 회고와 내보내기, 방해 상황별 알림 제어 | 일회성 $14.99 / $19.99 비교 가설. 루틴·수동 업무 프로필·회고/내보내기 데모 구현. 시간대 자동 전환·상황 감지·결제는 미구현 |
| Pet packs | 고유한 외형·개성·상황별 애니메이션과 완성된 설치·복원 경험 | 팩당 $4.99 / $7.99 가설. 색상만 바꾼 복제 팩은 상품 기준에 미달 |
| 개인 펫 제작 | 자신의 반려동물을 바탕으로 사람이 검수한 맞춤 펫 | 추후 수동 제작 견적 실험. 원가와 수요 확인 전 자동 생성 서비스로 확장하지 않음 |

Plus는 개인화 편의에 대한 과금이고 기본 휴식 제어·접근성·안정성은 무료에 둔다.
위 가격은 서로 다른 상품의 시험값이다. 기본 앱 $9.99인 경쟁 제품도 있으므로,
완성된 Plus 데모와 실제 구매로 검증하기 전 확정 가격이나 매출 전망으로 쓰지 않는다.
매달 신규 기능·콘텐츠를 약속하는 구독과 무기한 미래 콘텐츠 제공 약속은 두지 않는다.
현재 개발 빌드에서는 2차 개인화 데모를 결제 없이 사용할 수 있다. 위 표는 출시 상품의
가설이며, 개발 빌드에 해당 권한 구분을 적용했다는 뜻이 아니다. [사용 안내](personalization.md)

## 개발 원칙과 검증

첫 단계는 휴식 세션, 내 루틴 편집과 리소스 규격을 완성했다. 다음 단계의 개인화 데모는
여러 루틴·수동 프로필·회고를 연결한다. 실제 사용 결과에서 가장 큰 이탈 이유를 확인한다. OS별
회의·전체화면 감지는 별도 실기 검증이 필요한 기능이며 현재 지원한다고 홍보하지 않는다.

초기 20명 안팎의 7일 사용에서 첫 알림 이해, 자발적 재사용, 완료·미루기·건너뛰기,
알림을 끈 이유를 조사한다. 앱의 완료 기록은 버튼으로 확인한 기록이며 실제 신체
활동 측정이 아니다. Plus/팩 미리보기의 가격별 관심 등록은 약한 증거이고, 실제
결제·환불·지원 비용까지 확인해야 BM을 채택한다. 시장 규모와 CAC는 아직 미확인이다.

최초 유입은 실제 동작 영상과 개발·디자인 커뮤니티, 소개 페이지에서 얻는다.
외부 게시·유료 광고·결제 서비스 계약은 별도 실행 결정이 필요하다. 이번 작업은
제품과 로컬 문서·도구를 만든다.
