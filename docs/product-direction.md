# Unfold 제품 방향

2026-09-13 · 현재 사용자의 경쟁력·유료 가치 개발 요청을 기준으로 정한 방향.
2026-09-27 · **무료 다운로드·무료 체험 없음·일회성 유료 사용**으로 변경했다.
구현 상태는 [MVP 범위](mvp.md), 작업 순서는 [개발 계획](development-plan.md)을 따른다.

2026년 10월 8일 현재 개발은 **Beta v1.1.2** (`2715fd1`), 최신 공개 배포는 **Beta v1.1.1**이다.
아래 경쟁 서비스 가격과 비교는 2026-09-13 조사 기록이다.

## 제품과 고객

**작업 흐름에 맞는 짧은 휴식과 나만의 펫을 함께 제공하는 데스크톱 동료.**
PC에서 오래 일하고, 반복 알림은 쉽게 끄지만 시각적 동료와 자신의 휴식 리듬은 좋아하는
개발자·디자이너·창작자를 초기 고객으로 삼는다. “Mochi와 잠깐 쉬고, 내 리듬으로
돌아오세요”를 첫 가치 제안으로 사용한다.

고객이 얻는 가치는 알림을 받고 끝나는 것이 아니라, 지금 할 수 있는 짧은 휴식을
선택하고, 미루거나 완료하고, 자신이 쉬어 간 흔적을 확인하는 것이다. 펫은 이
진행에 반응한다. 관리하지 않았다고 아프거나 죽는 벌칙과 연속 기록의 압박은 두지 않는다.

## 경쟁 판단과 지불 이유

2026-09-13 공식 페이지를 확인했다. 기능·표시 가격은 사업자의 설명이며 Unfold의
전환율·매출·지불 의사를 입증하지 않는다.

| 비교 대상 | 확인한 제안 | Unfold의 선택 |
|---|---|---|
| [Stretchly](https://github.com/hovancik/stretchly) | 무료 휴식 알림, 유휴 및 방해 금지 대응 | 타이머 정확성·미루기·기본 제어를 제품의 기본 품질로 확보 |
| [Viraam](https://www.viraam.app/) | 여러 휴식 유형·회의 감지·사용 추이, $49.99 일회성 또는 구독 | 개인 일정에 맞는 실용성은 유료 후보지만 기능 단독의 독창성을 주장하지 않음 |
| [MicroJoyz](https://microjoyz.com/overview) | macOS 펫·리마인더·상호작용, 기본 앱 $9.99 일회성 | ‘펫+알림’ 자체는 이미 경쟁이 존재. 휴식 진행과 펫의 일관된 연결에 집중 |
| [Desktop Mate DLC](https://store.steampowered.com/app/3359730/Desktop_Mate__DLC/) | 라이선스 캐릭터를 별도 판매, 해당 DLC $14.99 | 캐릭터 팩 판매는 가능성이 있는 방식. 알려진 IP의 팬덤·가격을 오리지널 펫에 전이하지 않음 |

차별화 가설은 **Windows/macOS에서 일관된 휴식 경험, 작업·휴식 시간 설정,
커스텀 펫과 상황에 맞는 반응, 로컬 기록**의 결합이다.
일반 UI의 루틴·업무 프로필 편집과 수동 즉시 휴식은 현재 상품 설명에 포함하지 않는다. 최초 검증 대상은 기존 알림을 끄던
사람이 Unfold는 계속 켜 두고 실제로 짧은 휴식을 선택하는가다. 이 조합만으로
경쟁 우위가 확정되지는 않는다.

## 상품 구성

**국내 4,900원 / 해외 US$3.99, 일회성 구매. 무료 체험은 없다.**
무료 다운로드 → 앱 실행 → Google 로그인 → 구매 권한 확인 → 미구매자 결제 → 사용 순서다.
같은 계정의 구매자는 재설치 후 구매를 복원한다. 구독·Free/Plus 등급은 만들지 않는다.

타이머·말풍선·기본 펫 5종·상호작용·크기·테마·로컬 기록·CSV·커스텀 팩을 한 상품에 포함한다.
펫 팩을 별도로 판매하는 상점과 클라우드 동기화는 후순위다. 기본 펫의 제작 원본과 적용 기준은
[펫 생성 가이드](pet-generation-guide.md)를 따른다.

계정과 구매 권한은 Supabase에 저장하고 휴식 기록·설정·커스텀 파일은 기기에 둔다.
현재 결제 서버의 공급자는 Lemon Squeezy다. 실제 원화 청구 경로·세금 포함 표시·기기 수·
업데이트 제공 범위·오프라인 정책은 운영 결정과 검증이 남아 있다.
구매 확인 실패를 미구매로 간주하거나 로컬 데이터를 지우지 않는다.

## 개발 원칙과 검증

화면 시안 확인 후 UI를 구현한다. 현재 `1.1.2-beta` 일반 시작 경로에는 Google 로그인·
구매 권한 gate가 연결되어 있고, 내부 진단 모드는 이를 명시적으로 우회한다.
클라이언트 연결과 로컬 진단 통과가 운영 OAuth·실거래·구매 복원 완료를 뜻하지 않는다.
실제 구현·미검증 범위는 [MVP 범위](mvp.md)와 [계정 안내](account-screen.md)에서 확인한다.
로그인 세션은 OS 보안 저장소에서 복원하고 권한 확인 후 앱을 시작한다.
공개 1.1.1의 서명·공증과 설치 업데이트 결과는 [배포 검증](validation/2026-10-07-beta-v1.1.1-release.md)에 기록했다.

사전 무료 체험 사용자 모집·전환율 확보를 착수 조건으로 두지 않는다.
가격은 사용자가 정한 판매 정책이며, 수요·유지율·경쟁 우위가 입증됐다는 뜻은 아니다.
앱 완료 기록은 완료 버튼을 누른 기록이며 실제 신체 활동을 측정하지 않는다.
공개 전에는 로그인·구매·복원·환불과 실제 Mac/Windows 설치 경로를 검증한다.
