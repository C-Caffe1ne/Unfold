# GLB 펫 구현·검증 — 2026-10-04

## 원인과 기준

기존 `CharacterLibrary`는 PNG/GIF만 읽으며, `AnimationView`는 모든 프레임을 미리 업로드한다.
GLB를 그대로 가져오려면 뼈대·모프 애니메이션 재생, 투명 렌더링과 동작 매핑 저장이 필요했다.

작업 체크아웃은 `release/mvp`, 시작 HEAD는 `c93e168c43b2e4f356d81e7250d957b7e281a388`이다.
프로젝트 버전은 `0.2.2`; 별도로 확인한 `/Applications/Unfold.app` 번들은 `1.0.2 / 1000002`였다.
이번 수정·검증은 현재 체크아웃을 빌드한 파일에만 해당한다. 설치 앱을 교체하거나 배포하지 않았다.
기존 validation 문서 변경과 미추적 기록은 보존했다.

## 변경

- 펫 추가 → **GLB 펫** → **GLB 파일 열기…**에서 파일 분석·미리보기.
- 기본 대기, 마우스 올리기, 클릭, 들어 올리기, 드래그 중, 놓기, 휴식 알림·시작·완료,
  화면 위 걷기, 잠자기, 두리번거리기, 하품, 휴식 미루기의 클립·반복·속도 지정.
- 기본 대기·드래그 중·걷기는 반복, 들어 올리기·놓기는 한 번으로 고정해 입력 수명주기를 유지한다.
- **저장하고 적용**으로 기존 라이브러리의 검증·원자적 설치 경로를 사용한다.
  **저장한 GLB 펫 편집**에서 설정을 재열고 저장하며, 콘텐츠 버전은 저장할 때 증가한다.
- GLB 원본은 수정하지 않는다. 라이브러리에는 모델, 투명 미리보기 PNG, manifest와 체크섬을 저장한다.
- 고정 카메라와 루트의 이동·회전 잠금. 기본 대기의 첫 자세를 기준으로 삼는다.
  큰 스킨의 가장 상위 애니메이션 관절을 자동 선택하며, 필요하면 사용자가 루트를 지정한다.
  이동 방향에 따른 이미지 좌우 반전도 GLB 재생에서는 적용하지 않는다.
  하위 관절의 고개·팔다리·몸 기울임과 입 모프는 재생한다.
- 기존 펫 창, 투명 픽셀 클릭 판정, 드래그 좌표, 말풍선과 숨김 처리를 재사용한다.
- CPU 기반 텍스처 렌더링, 192×192 투명 이미지, 최대 20fps. 프레임 계산은 작업 스레드에서 수행하며
  클립당 최근 이미지 두 장과 표시 중인 비트맵만 유지한다. 이미지 애니메이션으로 미리 변환하지 않는다.

PNG 내장 텍스처, 비압축 삼각형, 최대 네 관절 가중치, LINEAR/STEP/CUBICSPLINE,
뼈대 및 위치 모프, OPAQUE/MASK 재질을 지원한다. 파일은 32 MiB 이하, 삼각형 10만 개 이하이다.
JPEG, BLEND, 압축 메시, 필수 확장, sparse accessor 등은 명시적인 오류로 거부한다.
현재 렌더러는 기본 색 텍스처를 사용하며 게임의 전용 셀 셰이더·조명·그림자를 재현하지 않는다.

## 검증

- 변경 전 전체 검사 시도는 sandbox의 로컬 소켓 제한으로 테스트 시작 전 중단됐다.
  따라서 변경 전 통과 수치는 기록하지 않는다.
- 집중 검사 60개 통과. 루트 이동·회전 고정, 모프 재생, 손상된 파일 거부,
  매핑 저장·업데이트·재열기, 원본 보존, 투명 클릭 판정, 미러링 차단,
  GLB 설정 화면의 버튼·드롭다운 저장, 클릭과 드래그의 수명주기, 숨김 유지 등을 확인했다.
- 최종 경계 검증 보완 후 GLB 검사 7개 통과.
- 전체 Release 검사 430개 통과, 실패·건너뜀 0.
- Release 빌드 경고·오류 0; `git diff --check` 통과.
- 실제 Kazusa GLB: 24개 클립, 삼각형 11,466개. 샘플 이미지에서 본체·헤일로·입 표정 표시 확인.
  원시 샘플 렌더링은 최초 30ms, 이후 대부분 4~13ms였다. 장기 성능 결과로 해석하지 않는다.
- macOS 네이티브 Avalonia 진단에서 파일 선택 경로를 주입하고 실제 화면의 버튼 이벤트로 가져오기·저장.
  6개 클립의 실시간 재생, 일시정지, 완료 이벤트 한 번, 숨김 유지와 디스크 재열기 통과.
  480×560 및 860×680의 실제 ClientSize와 가로 넘침 없음 확인.
  진단 프로세스 정상 종료 코드 0.

transparent/empty 통계는 그 샘플에 대한 값이며 모든 프레임의 시각 검증을 뜻하지 않는다.

## 미검증·위험

별도 격리 앱의 실제 macOS 화면에서 Kazusa의 표시와 홈 미리보기를 확인했다.
마우스 자동화는 창 상태 변경을 감지해 입력 전에 중단되므로 실제 OS 클릭·드래그 통과로 기록하지 않는다.
Headless 입력 검사와 네이티브 off-screen 재생은 실제 창 드래그 검증을 대신하지 않는다.
Windows 실기, 다중 모니터·DPI, 장시간 CPU/메모리, 모든 클립·모든 GLB 파일은 미검증이다.
복잡한 모델은 CPU 렌더링 속도가 낮아질 수 있다. 모델에 없는 동작은 생성하지 않는다.
Kazusa 원본 파일과 사용 허가 정보는 저장소·배포물에 추가하지 않았다.
