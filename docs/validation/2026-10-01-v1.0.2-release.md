## 자동 검사

- Release 전체 검사 **526개 통과**, 실패·건너뜀 0.
- 최초 전체 검사에서는 강아지 착지 타이밍 검사 하나가 실패했다. 단독 재검사에서 5종 모두 통과했으며, 수동 `AdvanceCompanion`과 실제 `hitTimer`가 섞이는 테스트 문제를 확인했다. 해당 테스트에서 실제 포즈 타이머를 멈춰 시간을 직접 제어하도록 보완한 뒤 전체 검사 526개가 통과했다. 제품의 펫 동작 코드는 변경하지 않았다.
- Windows 설치 파일 컴파일 성공. 전체 추출 후 앱 파일 **262개**의 해시가 게시 입력과 일치했다. ZIP CRC 및 내부 EXE 해시도 일치했다.
- Mac DMG 두 개의 무결성·아키텍처·버전·Applications 링크 확인. 각각 번들 파일 **255개**의 해시가 후보와 일치했다. ad-hoc 서명 검증 통과.
- 세 플랫폼 모두 브랜드 ICO·트레이 PNG·두 로고 PNG **4개**가 승인된 원본 바이트 그대로 어셈블리에 포함됐다. Mochi PNG와 빈 왼쪽 문구 설정, 기본 펫 5종도 확인했다.
- 빌드 동안 기록한 제품 입력 **216개**의 해시가 변경되지 않았다.
- 웹 테스트 **44개**, 로컬 HTTP·파일·다운로드 규칙 검사 **81개** 통과. 정적 링크 검사 및 Cloudflare dry run 성공(`public/` 54개 파일).
- Python 구문 검사와 앱·웹 `git diff --check` 통과.

Windows 추출 검사의 첫 실행은 NSIS의 `app/` 경로를 빠뜨린 검증 스크립트 오류로 중단됐다. 실제 설치 파일 구조와 매칭하도록 스크립트를 고친 뒤 262개 파일의 해시를 확인했다. 제품 설치 파일 오류는 아니었다.

## 실제 macOS에서 실행한 진단

- Apple Silicon DMG에서 앱을 별도 검증 폴더로 복사하고 마운트를 해제한 뒤 `--version`과 `--smoke-test`를 실행했다.
- 게시 앱의 통합 진단 종료 코드 0, `success: true`, PNG **93장**.
- DMG에서 복사한 앱 어셈블리와 동일한 해시의 바이너리로 브랜드 진단을 실행했다. 네이티브 트레이 출력 픽셀이 브랜드 PNG와 일치했다.
- 기본 940×620·최소 640×560·어두운 테마의 계정 화면 3장을 확인했다. 왼쪽은 Mochi 이미지만 포함하며, 열린 창의 테마 변경으로 밝은 로고가 적용됐다. 국내 가격 `4,900원`은 유지했다.
- 새 임시 `UNFOLD_DATA_DIR`와 가짜 로컬 계정 서비스를 사용했다. 진단 창은 화면 밖에 배치했다.

## 범위와 남은 검증

실제 Windows 설치·제거·재부팅, Intel Mac 실행, 실제 Google 인증·결제와 재부팅 후 로그인 복원은 이번 작업에서 검증하지 않았다. Windows 코드 서명과 macOS Developer ID 서명·공증은 미완료 상태를 유지한다.

앱 저장소의 기존 미커밋 변경을 보존했고 전체 변경을 커밋·푸시하지 않았다. 릴리스 태그는 기존 기준 커밋 `37c6de354ceb390500d4bcb586bde1a74d16e205`을 가리킨다. 자동 생성 Source code 아카이브와 실제 작업본 바이너리가 다르다는 안내를 공개 릴리스에 명시했다. 이전 릴리스 파일·URL은 보존했다.

근거는 `artifacts/validation/2026-10-01-v1.0.2-release/`에 있다. 주요 파일은 `release.trx`, `package-verification.json`, `packaged-smoke.json`, `packaged-brand/native-result.json`, `web-checks.json`, `web-routes.log`, `release-draft.json`, `public-verification.json`, `windows-browser-download.json`이다.
