# P2 설정·펫 오류 복구 구현

2026-09-23 · `release/mvp` · 기준 커밋 `d9267bc`

## 범위와 원인

[프로젝트 감사](2026-09-23-project-audit.md)의 AUD-01과 AUD-02를 구현했다.
패치노트 설명 수정은 사용자 요청에 따라 제외했다. P3 미사용 효과음 정리는 이번 P2 작업에 포함하지 않았다.

- **AUD-01:** 설정 전체 역직렬화와 루틴·프로필 검증이 하나의 실패 경로여서 일부 손상에도 정상 설정을 잃었다.
- **AUD-02:** 클립 캐시에 실패한 Task가 남았고, 반응 실패 시 `reacting`과 기본 동작 복귀를 처리하지 않았다.

## 변경

### 설정 복구

- 유효한 JSON 객체는 필드별로 자료형을 검사한다. 잘못된 필드는 기본값으로 복구하고 정상 필드는 유지한다.
- 기존 대소문자 구분 없는 필드명과 문자열 숫자 읽기, 범위 검증, 파일 크기·JSON 깊이 제한을 유지했다.
- 루틴·프로필은 항목별로 검증한다. 손상·중복·초과 항목과 유효한 루틴을 참조하지 않는 프로필만 제외한다. 유효한 항목과 선택은 유지하며 끊어진 선택은 복구한다.
- 전체 로드를 실패시키던 자료형·목록 오류를 부분 복구하면 런타임이 원본을 `.invalid-*`로 백업한다. 로드 자체는 원본 설정 파일을 덮어쓰지 않는다. 전체 JSON 구문 오류의 기존 기본값·백업 경로도 유지했다.
- 기존 단순 범위 초과 값의 필드별 복구 방식과 정상 파일의 무백업 로드는 유지했다. 편집·저장 시 유효성 검사를 완화하지 않았다.

### 펫 재생 복구

- 진행 중이거나 성공한 클립 요청은 공유한다. 실패·취소된 요청은 다음 호출에서 다시 읽는다.
- 클립 실패 후 현재 반응만 종료하고 기본 동작으로 복귀한다. 실패한 스트레칭을 즉시 반복 호출하지 않으며, 걷기가 실패하면 idle로 복귀한다. 휴식 세션과 타이머는 취소하지 않는다.
- idle도 읽지 못할 때는 제한된 복구 시도 후 화면을 비우며 무한 재시도를 막는다. 파일 복구 후 다음 반응에서 다시 읽을 수 있다.
- 세대 번호와 창 표시 상태를 확인해 오래된 실패·idle 복구가 새 반응, 교체한 펫, 숨김·종료 상태를 덮어쓰지 않도록 했다.

핵심 회귀 검사는 다음 조건을 다룬다.

- 잘못된 자료형·null·숫자 초과에서도 정상 간격 37분·자리 비움 9분 유지.
- 잘못된 루틴 앞뒤의 정상 항목 보존, 중복·한도·참조 관계 복구, 정상 설정 전체 왕복.
- 부분 복구 후 원본 바이트 백업과 이후 저장 시 백업 보존.
- 실제 손상 GIF 실패→복구→재시도와 랜덤 idle 행동 재개.
- 진행 중 요청 공유, 실패·취소 요청의 재시도, 새로운 캐시 항목 보존.
- 스트레칭·걷기·idle 로딩 실패 시 복구 횟수 제한과 휴식 세션 유지.
- 늦은 실패와 늦은 idle 복구, 펫 교체·숨김·종료 이후 상태 보호.

처음 제한된 실행 환경에서는 MSBuild의 로컬 소켓 생성이 거부되어 테스트가 시작되지 않았다.
중단된 해당 프로세스를 정리하고 로컬 소켓이 허용된 실행 환경에서 새 임시 데이터로 다시 실행했다.
이는 테스트 assertion 실패와 구분한다. 늦은 idle 복구 검사의 대기 조건을 보강한 뒤 최종 전체 검사를 다시 통과했다.

재현 명령:

```sh
# 각 테스트·진단 실행에 새 임시 UNFOLD_DATA_DIR 사용
dotnet test Tests/Unfold.Tests/Unfold.Tests.csproj -c Release --no-restore \
  --filter 'FullyQualifiedName~SettingsRecoveryTests|FullyQualifiedName~SettingsReliabilityTests|FullyQualifiedName~PersonalizationTests|FullyQualifiedName~PetPlaybackRecoveryTests|FullyQualifiedName~OriginalCompanionTests|FullyQualifiedName~AnimationLifecycleTests'
dotnet test Unfold.slnx -c Release --no-restore
dotnet build Unfold.slnx -c Release --no-restore
dotnet src/Unfold.Desktop/bin/Release/net10.0/Unfold.dll --review-original-pets
```

## 실제 OS·미검증·위험

현재 Mac에서 네이티브 런타임의 실시간 재생과 상태 전환을 검사했다. 창은 화면 밖에 배치했고
사람의 마우스 입력이나 실제 바탕화면 이동은 수행하지 않았다. 115장은 자동 캡처 수이며
모든 프레임을 사람이 시각 검수했다는 뜻은 아니다.

Windows·Intel Mac 실기, 다중 모니터/DPI·장시간 사용·물리 입력은 이번 작업에서 미검증이다.
GIF 오류는 별도 시험용 자산에 주입했으며 사용자의 설정·기록·펫 파일은 건드리지 않았다.
배포 ZIP을 다시 생성하거나 외부에 게시하지 않았다.

다음 코드 정리 후보는 감사의 **AUD-03 미사용 효과음 파일 관리**다. AUD-04 패치노트 수정은 제외 상태다.
