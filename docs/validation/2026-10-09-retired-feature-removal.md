## 구현과 데이터 계약

| 대상 | 제거·변경 | 유지 |
|---|---|---|
| 루틴·업무 프로필 | 설정 모델·검증·선택·런타임 적용과 과거 작성 API 제거. 시작 시 폐기된 설정 필드 5개를 원본 백업 없이 재저장하여 제거 | 현재 타이머 간격·휴식 시간·자리 비움·다시 알림, 펫 위치·크기·선택, 소리·테마·말풍선 설정 |
| 기존 기록 | 새 휴식은 현재 기본 안내와 설정된 휴식 시간을 사용 | 과거 기록의 루틴·프로필 ID·이름, 계획·실제 시간, 기존 CSV 열과 내보내기 |
| 타이머 펫 미리보기 | 홈 AnimationView·비동기 로드·재시도·창 표시/숨김 수명 관리 제거. 빈 미리보기 공간을 남기지 않도록 카드 높이 조정 | 펫 선택·크기 조절, 실제 데스크톱 펫, 가져오기·편집·GLB 미리보기 |
| Piskel | 픽셀 원본 모델·코덱·원본 열기/저장/복사 제거. 라이브러리 로드 시 패키지 및 모든 재생 행동 검증 후 `source.piskel`만 백업 없이 삭제 | 설치한 펫 ID, PNG/GIF/GLB·manifest·애니메이션, 현재 편집·삭제, 충돌·최신 수정 보호 |

설정 로더는 파일을 변경하지 않는다. 실제 시작 경로가 폐기된 필드를 감지하여 한 번 이전하고, 재시작 시 같은 파일을 다시 쓰지 않는다. 현재 설정 자체가 손상된 경우의 기존 복구·오류 원본 보호 정책은 유지한다.

손상된 재생 자산, 접근 불가 원본, 외부 파일을 가리키는 링크는 원본 삭제를 보류한다. 해당 경고를 기록하며 외부 링크 대상은 삭제하지 않는다. 이는 폐기된 편집기 지원을 남기는 것이 아니라 검증 전 데이터 삭제를 막는 경계다.
