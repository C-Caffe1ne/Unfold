# 펫 호버 시간 말풍선 — 2026-09-23

이 문서는 최초 구현의 검증 기록이다. 누르기·드래그 중 숨김 동작은 이후
[연속 클릭 수정](2026-09-23-hover-click.md)에서 말풍선 유지로 변경했다.

## 변경

- 펫의 보이는 영역에 포인터가 올라오면 240×96px 말풍선 표시.
- 위: 로컬 현재 시각 `HH:mm:ss`. 아래: 다음 스트레칭까지 `mm:ss`와 일시정지·중지·자리 비움 상태.
- 기존 작업 타이머 갱신을 사용한다. 중지는 설정한 전체 간격을 표시하며, 호버가 타이머·알림 예약·기록·효과음을 만들지 않는다.
- 포인터 이탈·펫 숨김 시 닫고, 누르기·드래그·우클릭 메뉴 중에는 잠시 숨긴다.
- 기존 사전 알림·휴식 초대·진행 중 휴식·완료·디버그 미리보기가 항상 우선한다.
- 설정한 방향을 우선하고 화면 끝에서는 방향 또는 가로·세로 정렬을 조정해 펫 위치를 유지한다.
- Windows 투명 픽셀 클릭 통과 중에도 기존 포인터 검사에서 호버를 갱신한다. 정보 말풍선에는 입력을 받는 버튼을 넣지 않는다.

변경 코드: `PetWindow.cs`, `PetSpeechBubble.cs`, `DesignSystem.cs`.
이전 P2 복구와 macOS 전체화면 변경은 보존했다.
