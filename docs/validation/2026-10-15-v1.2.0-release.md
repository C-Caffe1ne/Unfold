# Unfold v1.2.0 정식 배포 검증

2026-10-15 · 진행 중. 최종 공개 파일·소스·검사 결과는 배포 후 갱신한다.

## 범위

직전 공개 `v1.1.4-beta` (`4c64bfc`) 이후 휴식 숫자 전환, 네 언어와 첫 로그인 언어 선택,
US$2.99 결제 설정, GLB 1% 요소별 외곽선, 말풍선 접합부 수정과 미커밋 문서·검증 자료를 모두 포함한다.
기존 베타에서 정식 버전으로 전환하도록 동일한 서명 패키지의 호환 파일명·피드를 함께 생성한다.
패키지 내부 버전과 채널, 새 앱 표시와 업데이트 채널은 `1.2.0`·stable이다.

## 사전 검사에서 수정한 사항

- 설치 ZIP·DMG·구형 Windows 패키저의 베타 전용 버전 제한과 설치 안내를 정식 버전에 맞췄다.
- 언어를 전역으로 바꾸는 LocalizationTests를 기존 직렬 컬렉션으로 옮겨 병렬 MP4 오류 문구 검사와 충돌하지 않도록 했다.
- 네이티브 화면 진단의 펫 선택 상자 폭 200px 고정 가정을 반응형 범위·행 내부 잘림 검사로 바꾸고 네 언어·세 폭의 회귀 검사를 추가했다.

기존 검증 기록은 당시 결과로 보존한다. 사용자 데이터·설치 앱·운영 서버는 빌드 과정에서 변경하지 않는다.
Google 로그인 브랜딩과 추가 3D 메모리 최적화는 보류를 유지한다.

## 로컬 결과

격리 소스에서 Release 전체 1,049개 통과(실패·건너뜀 0), 패키징 Python 8개,
결제 Node/PGlite 44개 통과. 실제 FFmpeg를 준비해 MP4 변환 검사도 포함했다.
최신 소스의 macOS 네이티브 `--smoke-test`는 성공·109장·표시 버전 `v1.2.0`이다.
베타 메타데이터를 가진 설치 상태에서 정식 내부 채널 패키지를 호환 피드로 내려받고,
재시작 전 준비 상태를 복원하는 실제 Velopack SDK 회귀 검사도 통과했다.
