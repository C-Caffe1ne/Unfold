## 사전 검사에서 수정한 사항

- 설치 ZIP·DMG·구형 Windows 패키저의 베타 전용 버전 제한과 설치 안내를 정식 버전에 맞췄다.
- 전역 언어를 바꾸는 LocalizationTests를 기존 직렬 컬렉션으로 옮겼다. 첫 전체 검사에서 병렬 MP4 문구 검사 1건이 실패했고 수정 후 전체를 다시 통과했다.
- 화면 진단의 펫 선택 상자 폭 200px 고정 가정을 반응형 범위·행 내부 잘림 검사로 바꿨다. 네 언어·세 폭의 회귀 검사를 추가했다.
- 기존 베타가 검증하는 파일명·피드를 유지하면서 내부 버전·채널은 정식인 동일 바이트 패키지를 제공한다. 새 앱은 stable 채널을 확인한다.

## 설치 ZIP과 업데이트

설치 ZIP 3개·통합 체크섬·정식 업데이트 3쌍·베타 전환 호환 업데이트 3쌍, 총 16개를 게시했다.
호환 파일명에만 beta가 있으며 패키지 내부 버전은 1.2.0, 채널은 stable이다.

## 실제 베타 → 정식 전환

Mac ARM64는 공개 1.1.4 설치 ZIP의 해시를 검증해 앱을 임시 폴더로 복사했다.
당시 배포된 AppUpdates 코드와 실제 UpdateMac을 사용하고 설치·캐시·프로필을 격리했다.
이번 실제 정식 패키지의 로컬 호환 피드에서 내려받아 교체·재시작했다.
재시작 진단 성공·109장, 내부 버전 1.2.0·채널 osx-arm64-stable, 기존 데이터 표식 보존을 확인했다.
[Windows 공개 업데이트 검사](https://github.com/C-Caffe1ne/Unfold/actions/runs/38747405968)도 최종 통과했다.
실제 공개 1.1.4 설치본과 당시 배포된 AppUpdates 코드, 실제 Update.exe로 공개 정식 패키지를 내려받아 교체·재시작했다.
재시작 진단 성공·109장, 버전 1.2.0·채널 win-x64-stable, 기존 데이터 표식 보존을 확인했다.

## 운영 결제와 공개 범위

사용자가 운영 DB의 US$2.99 전환을 별도로 승인했다. `lemon_usd_price`를 적용한 실제 원격 이력은 20261015134723이다.
로컬 마이그레이션 파일과 회귀 검사 참조도 같은 버전으로 정합화했다.
GLOBAL·USD·299·Live 활성, KRW Live 비활성, 동일 Live variant 이동과 Test 매핑 유지를 운영 DB에서 조회했다.
기존 KRW 영수증은 남아 있다. 실제 결제·웹훅·고객 앱 구매 복원은 새로 실행하지 않았다. Edge Function 재배포도 없다.

최초 익명 파일 검사에서 저장소가 비공개여서 404였다. 사용자에게 범위를 확인한 뒤 전체 소스 공개 전환을 명시적으로 승인받아 적용했다.
공개 후 인증 없는 API·다운로드를 다시 통과했다. 첫 Windows 공개 검사는 비공개 상태의 404로 실패했고 공개 전환 후 실패 작업만 재실행했다.
