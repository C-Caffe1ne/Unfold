## 오류와 검증 한계

- 최초 ARM64 진단 1회는 “Applying the interval started the paused timer or ignored the new interval.” 검사에서 실패했다. 동일한 서명 바이너리를 새 격리 프로필로 재실행한 결과는 전체 성공이었다. **원인은 미확정**이며 최초 실패 로그와 프로필 경로를 보존했다. 일시정지·시간 변경의 물리 입력 재현 확인이 남아 있다.
- 제한된 실행 환경의 Developer ID 검사 1회가 invalid signature를 반환했다. 실제 macOS 보안 서비스에 접근하는 환경에서 원본·사본의 모든 파일·링크 바이트 일치와 strict 서명 검사 통과를 확인했다.
- **Windows 실기기 설치·제거·업데이트·재부팅과 코드 서명은 미검증**이다. 앱 소스를 원격에 푸시하지 않아 최신 소스의 Windows CI도 실행하지 않았다.
- 실제 Intel Mac, 새 컴퓨터의 브라우저 다운로드부터 첫 실행까지 전체 UI, 실제 Google 로그인·결제·물리적 포인터·효과음 청취는 검증하지 않았다.
- HTTPS 업데이트 검사는 업데이트 가능한 앱의 버전 메타데이터를 1.0.2로 설정한 격리 사본이다. 업데이트 기능이 없는 실제 과거 v1.0.2 앱의 자동 전환 검사는 아니다. 이전 사용자는 v1.0.3 설치본을 한 번 직접 설치해야 한다.

## 공개 파일과 근거

Mac 공증 설치 ZIP 두 개, Windows 설치 ZIP, ZIP 체크섬, OS별 피드 3개와 전체 업데이트 패키지 3개를 게시했다. 이전 릴리스와 웹 다운로드 주소 15개를 유지하고 새 주소 4개를 추가했다. Worker·DNS·Custom Domain 구성은 그대로 사용했다.

최종 파일은 `artifacts/releases/v1.0.3-beta/`에 있으며, 검증 자료는 `artifacts/validation/2026-10-03-beta-v1.0.3-release/`에 있다. 주요 근거는 `final-result.json`, `release-public.json`, `public-downloads-verification.json`, `public-website-verification.json`, `https-update-result.json`, `packages-final.json`, `arm-smoke/`, `intel-smoke/`와 빌드·검사 로그다. 내부 자료는 공개 Release에 업로드하지 않았다.
