# 최상위 유지·디스플레이 변경·동작 줄이기 검증

2026-10-19 · `codex/pet-overlay-hover`, 시작 HEAD `8e2ad2c`, 프로젝트 `1.2.0`. 계획: [dsh-pet 비교 후속](../plans/2026-10-19-dsh-pet-adoption.md).

## 변경

- Windows: 보이는 펫·말풍선·타이머 창에 5초 간격으로 `HWND_TOPMOST`를 다시 적용한다. 이동·크기·활성화는 바꾸지 않고, 누름·드래그·메뉴·소유 대화상자가 열린 동안은 건너뛴다.
- 실행 중 디스플레이 구성이 바뀌면 펫을 현재 작업 영역 안으로 보정하고 말풍선을 다시 배치한다. 저장된 수동 위치는 바꾸지 않으며 숨김·드래그·진단 모드에서는 실행하지 않는다.
- OS 동작 줄이기가 켜져 있으면 `AnimatedCountdown`의 숫자 굴림 없이 새 값을 표시한다. 테스트와 진단 모드는 호스트 설정과 무관하게 기존 전환을 검사한다.
- [펫 관리](../pet-packs.md)에 행동별 MP4 원본을 맞추는 규칙 3줄을 추가했다. 앱 안 문구는 바꾸지 않았다.
- 기존 `DesignSystemTests`의 펫 제작 화면 크기를 10/18 최소 창 860×800에 맞췄다. 변경 전 `8e2ad2c` 별도 작업트리에서도 같은 740/800 불일치로 실패했다.

새 `UNFOLD_DATA_DIR`, .NET SDK 10.0.401, Release 빌드(경고·오류 0).

- 전체 `dotnet test Unfold.slnx`: **1,096개 통과**, 실패·건너뜀 0.
- macOS 실제 창의 `--smoke-test`: `success: true`, `timerDigitMotionVerified: true`.
- `git diff --check` 통과.

## 검증 경계

Windows Z 순서 복구, 실제 모니터 분리·배율 변경, macOS·Windows의 동작 줄이기 설정 전환은 실제 OS에서 관찰하지 않았다.
