## 사용 및 유지

기존 대화에 전달된 스킬 목록은 남을 수 있다. Codex와 Claude Code를 다시 시작하고 새 대화에서 사용한다.

- Codex: `$gstack-review`, `$gstack-spec`, `$superpowers-brainstorming` 등으로 명시 호출한다.
- Claude: `/superpowers-brainstorming` 등 로컬 공유 스킬을 명시 호출한다.
- 개인 정적 웹 QA의 새 이름은 `web-qa-static`이다.
- gstack은 `~/.agents/skills/gstack`의 원본 템플릿·생성기를 유지한다. 생성된 `SKILL.md`를
  직접 고치면 다음 생성에서 사라진다. 상위 버전 업데이트 시 로컬 생성기 수정도 함께 비교해야 한다.
- Superpowers 원본 캐시는 보존돼 있으며, 로컬 관리본의 업스트림 업데이트는 자동으로 합쳐지지 않는다.
