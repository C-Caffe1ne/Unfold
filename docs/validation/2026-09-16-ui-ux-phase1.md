# UI/UX 1단계 동작 정확성 검증

2026년 09월 16일 · `release/mvp` `7e81f77` 기반 현재 작업 트리 · C#/.NET 10 Avalonia.

## 구현 결과

UI/UX 감사의 1단계인 UI-01~UI-03을 구현했다.

- 설정 대시보드의 루틴 편집은 드롭다운에서 선택한 사용자 루틴의 ID와 내용을 편집기로 전달한다.
  기본 제공 루틴은 직접 편집하지 못하며 버튼과 접근성 도움말이 루틴·프로필 라이브러리로 안내한다.
- 업무 프로필 화면은 타이머가 진행 중일 때 **프로필 적용**을 미리 비활성화하고 제한 이유를
  같은 화면과 접근성 도움말에 표시한다. 일시정지 또는 중지하면 현재 선택을 유지한 채 다시
  적용할 수 있다. 독립 실행되는 루틴·프로필 창의 기존 적용 동작은 유지한다.
- 커스텀 펫 만들기에서 이미 채운 동작에 파일을 넣으면 기존 파일명과 새 파일명을 확인한 뒤
  교체한다. 취소, 제목 표시줄 닫기, 파일 검사 실패에서는 기존 클립과 가져온 파일을 보존한다.
  성공하면 아직 비어 있는 다음 동작으로 이동하고, 모든 동작이 채워졌으면 현재 선택을 유지한다.
