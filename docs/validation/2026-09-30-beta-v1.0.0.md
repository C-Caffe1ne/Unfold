# Beta v1.0.0 판매용 후보 구현·검증

2026-09-30 · C#/.NET 10·Avalonia · macOS arm64 호스트.

이 문서는 무료 이용 코드 추가 **이전** 후보의 검증 기록이다. 이후 테스터 요청에 따라 계정별 코드 권한과 ZIP을 갱신했다. 현재 결과는 [무료 이용 코드 검증](2026-09-30-access-codes.md)을 참고한다. 이 문서의 기존 ZIP·해시·소스 입력 목록은 `artifacts/releases/v1.0.0-beta/before-access-codes/`에 보존했다.
기준 커밋은 `37c6de354ceb390500d4bcb586bde1a74d16e205`이며, 사용자의 기존 미커밋 작업과 이번 변경을 포함한 체크아웃에서 빌드했다. 커밋만으로 배포물 소스를 재현했다고 주장하지 않는다.

## 결과와 판매 경계

판매용 구매 잠금과 Live 결제 서버 코드를 구현하고 Apple Silicon·Intel Mac·Windows x64 후보를 생성했다. **실제 판매 준비는 아직 완료되지 않았다.** 운영자가 Test 모드만 설정했다고 확인했으며, 공개 가격표의 Live 활성화도 false였다. 후보 ZIP은 Live 설정 전에는 구매 권한을 확인하고 앱에 진입할 수 없다.

외부 게시, 실제 결제·환불, Supabase Live 전환, Developer ID 서명·공증은 수행하지 않았다.

## 구현

- 버전의 기준은 `Unfold.Desktop.csproj`의 `1.0.0-beta`다. CLI·창 제목은 `Beta v1.0.0`, macOS 숫자 버전은 `1.0.0`, 빌드 번호는 `6`이다.
- 기존 라일락 브랜드 ICO·ICNS를 배포 실행 파일·번들에 포함했다. 눈누 기초고딕의 저작권·공개 사용 조건과 Svg.Skia MIT 전문을 배포한다.
- 정상 실행은 Live 구매가 확인되기 전 홈·펫·타이머를 시작하지 않는다. 이전 안내 종료 파일, 창 닫기, 트레이, 백그라운드 자동실행으로 우회할 수 없다. 공통 `admin` 코드 처리는 제거했다.
- 구매 확인 후 타이머·펫을 시작한다. 로그아웃, 권한 취소·조회 실패는 실행을 멈추고 계정 화면으로 돌아간다. 5분마다 재확인하며 만료 토큰을 갱신한다. 늦게 도착한 응답이 로그아웃 상태를 되돌리지 않도록 세대 번호를 검사한다.
- 잠금 중에는 기존 미저장 초안을 메모리에 유지한다. 종료 시 필요한 확인은 계정 창에 붙이고 숨겨진 홈·에디터를 다시 보여주지 않는다. 시작 오류도 현재 계정 창을 소유자로 사용한다.
- `connection.json`은 `live`·`KR`이며 공개키만 포함한다. 데스크톱은 Test 환경 연결과 Test 권한 응답을 거부한다.
- 서버는 Test/Live 주문·상품·Checkout·웹훅·권한을 분리한다. Live API 키와 웹훅 Secret은 전용 이름을 사용하며 Test Secret으로 대체하지 않는다.
- 새 `202609300001_lemon_live.sql`은 환경별 예약 RPC와 Live 제약을 추가한다. Live 상품 등록이나 판매 활성화는 하지 않는다. 기존 Test 데이터와 서버 전용 권한 경계를 보존한다.
- Windows는 기존 PowerShell 게시 경로 외에 이미 게시된 `app/`을 패키징하는 Python 경로를 제공한다. .NET·미디어 도구·라이선스·설치 안내·릴리스 노트를 포함한다.

## 자동 검사

모든 진단·앱 테스트는 새 `UNFOLD_DATA_DIR`을 사용했다. 실제 사용자의 데이터와 실행 중 앱은 건드리지 않았다.

| 검사 | 결과 |
|---|---|
| `dotnet restore Unfold.slnx --locked-mode` | 성공 |
| 구매 잠금·계정 초기 집중 검사 | 25/25 통과 |
| 최종 펫·구매 잠금 집중 검사 | 46/46 통과 |
| 최종 전체 Release 검사 | 484/484 통과, 실패·건너뜀 0 |
| `cd supabase && npm ci --ignore-scripts && npm test` | 34/34 통과, 건너뜀 0 |
| Apple Silicon·Intel·Windows 자체 포함 게시 | 3종 게시 성공, 최종 파일 검사 별도 |
| 실제 배포 DLL 버전·정보 버전 | `1.0.0.0`, `1.0.0-beta` 확인 |
| ZIP 내부 교차 검사 | 169개 항목 통과; 최종 해시는 `artifact-audit.json` |
| `git diff --check`, Bash/Python 문법 | 통과 |

결제 서버 검사에는 실제 PGlite PostgreSQL의 마이그레이션·권한·RLS·Live 활성화 차단, 환경별 예약·구매·누적 부분 환불·전액 환불·중복/늦은 웹훅을 포함했다. Lemon API·Auth는 모의 응답이다. 운영 서버 성공을 뜻하지 않는다.

최종 검사 중 기존 펫 드래그 검사 한 건은 수동으로 애니메이션 시간을 진행하면서 실제 창 타이머도 실행해 포즈가 먼저 바뀌는 비결정적 실패를 보였다. 해당 검사만 진단 시작으로 타이머를 격리했고, 포즈 보존·착지·클릭 없음의 기존 단언은 유지했다. 제품 펫 동작 코드는 변경하지 않았다.

패키지 검사에서는 macOS 코드 서명으로 변경되는 FFmpeg 서명·Mach-O 헤더의 서명 크기 영역을 제외해 실행 데이터가 원본과 같은지 확인한다. 이를 파일 변조나 미디어 기능 실패로 보고하지 않는다. 기타 자산·Windows 도구는 원본 바이트와 비교한다.

## 실제 macOS와 자동 UI 진단

Apple Silicon ZIP을 새 폴더에 풀어 `codesign --verify --deep --strict`와 CLI 버전 확인을 수행했다. Intel ZIP도 호스트에서 서명 구조를 확인했다. ad hoc 서명의 무결성 검사가 Gatekeeper 신뢰·공증을 뜻하지 않는다.

Apple Silicon 게시 앱의 자동 네이티브 진단은 타이머·말풍선·홈·설정·펫 추가·기록·테마·모달을 검사한다. 최종 결과는 성공이며 캡처 93장을 생성했다. 릴리스 폴더의 `smoke.json`에 기록한다. 기본 자산 검사는 5종·65개 클립이며 오류가 없었다.

진단은 화면 밖 창, 모의 입력·시간·저장 대상과 진단용 접근을 사용한다. 실제 마우스 조작·Google 로그인·Lemon 결제·구매 잠금의 물리 입력 검증과 구별한다. 진단 로그인 화면에서는 코드 입력 버튼이 보이지 않는 것을 캡처에서 확인했다.

## 재현 자료

`artifacts/releases/v1.0.0-beta/`에 다음 자료가 있다.

- `tests/beta-final-release.trx`, `final-tests.log`: 최종 전체 검사.
- `tests/pet-gate-focused.trx`, `payment-tests.log`: 집중·서버 검사.
- `publish-osx-arm64.log`, `publish-osx-x64.log`, `publish-win-x64.log`: 게시 로그.
- `assembly-metadata.jsonl`, `artifact-audit.json`, `characters.json`, `smoke.json`: 실제 배포물·진단 결과.
- `source-inputs.json`: 코드·테스트·자산·서버·미디어·패키징 입력 248개 SHA-256. 빌드 후 다시 비교한다.
- `SHA256SUMS.txt`: ZIP·tar.gz 해시. 재서명·공증 후에는 갱신해야 한다.
- `remote-status.json`: 공개 API 읽기 결과와 판매 준비 차단 상태.
- `verify-artifacts.py`, `verify-source-inputs.py`, `metadata-check/`: 검사 재현 도구.

## 출시 전 남은 작업

1. Lemon Live 스토어 활성화, 한국 상품 게시와 실제 숫자 Store·Product·Variant ID 확인.
2. Supabase Live API 키·웹훅 Secret 등록, 새 마이그레이션·함수 배포, 운영 카탈로그·환경 활성화.
3. 실제 Google 로그인 → Live 결제 → 웹훅 → 구매 확인 → 사용, 재실행·로그아웃·전액 환불 검증.
4. macOS Developer ID 서명·공증 후 최종 압축·해시 갱신. 현재 호스트에는 Developer ID Application 인증서가 없다.
5. Intel Mac·Windows 실기에서 설치·실행·물리 입력·효과음·자동실행·전체화면·수면/복귀 확인. Windows 후보는 서명되지 않았다.
6. 검증된 최종 파일과 패치노트를 웹 다운로드에 게시.

현재 베타는 매 실행 온라인 로그인·구매 확인을 요구한다. OS 보안 저장소·자동 로그인·오프라인 라이선스·자동 업데이트는 미구현이다. 서버 조회 실패도 잠금을 유지한다.
