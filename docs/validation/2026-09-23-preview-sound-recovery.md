## 변경

### 홈 펫 미리보기

- 현재 선택과 실제 로딩 완료 상태를 구분한다. 새 파일을 읽는 동안 선택한 펫의 검증된 시트 첫 칸을 보여 준다. 이전 펫을 새 이름 아래 남기지 않는다.
- 로딩 실패 시 1초 간격으로 추가 2회, 최초 포함 최대 3회 시도한다. 실패가 계속되면 정지 이미지를 유지하고 요청을 멈춘다.
- 펫 변경·홈 재진입·창 다시 열기에서 재시도 기회를 갱신한다. 파일 복구 후 성공한 애니메이션을 표시 완료 상태로 기록한다.
- 탭 이동·숨김·종료는 재시도와 재생을 중단한다. 요청 세대를 확인해 오래된 비동기 로딩이 새 선택이나 종료 상태를 덮어쓰지 못하게 한다.
- 새 버튼이나 설명 문구는 추가하지 않았다.

### 효과음 사본 정리

- 저장된 스트레칭·완료 효과음 ID와 현재 편집 중인 두 ID를 모두 보존한다. 같은 사본을 두 알림이 공유하면 한쪽의 초기화만으로 삭제하지 않는다.
- 가져오기·교체·기본 복원·취소·저장·초안 폐기·앱 시작 시 미사용 사본을 정리한다. 탭 이동과 숨김은 초안을 버리지 않는다.
- 실제 오디오 작업이 종료될 때까지 해당 파일을 사용 중으로 등록한다. 취소 요청 직후 OS가 파일을 아직 사용 중인 구간도 보호한다. 미리듣기 종료 또는 다음 정리 때 해제된 파일을 다시 확인한다.
- 가져오기가 진행 중이면 정리를 미룬다. 종료 뒤 도착한 파일 선택 결과는 적용하지 않으며, 복사가 이미 진행 중이었다면 완료 후 미사용 사본으로 정리한다.
- 관리 폴더 바로 아래의 64자리 해시 이름 WAV만 대상으로 한다. 기본 효과음·일반 이름 파일·하위 폴더·심볼릭 링크는 보존한다.
- 삭제 권한·파일 잠금 오류는 로그에 남기고 나머지 정리를 계속한다. 설정 저장과 원래 선택 파일에는 영향을 주지 않는다.
- 정리 경로는 창 생성 시 고정해, 늦게 끝난 요청이 다른 테스트 프로필을 정리하지 않도록 한다.
