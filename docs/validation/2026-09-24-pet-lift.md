## macOS 렌더링

기존 `--review-original-pets` 진단에 들어 올림 유지·착지·기본 자세 복귀 및 창 배치 유지
검사를 추가했다. 최종 프로필 경로는 `artifacts/validation/2026-09-24-pet-lift/native-profile-final`이다.

화면 밖의 접힌 펫 창은 AppKit에서 크기 0으로 보고되어 초기 캡처가 실패했다.
진단은 실제 펫에서 읽은 포즈를 기존 `AnimationView` 미리보기에 전달해 캡처하도록 보완했다.
클립은 실제 dispatcher 시간으로 재생하고, 누름·착지 시간은 진단 코드가 진행한다.
캡처는 전체 데스크톱 스크린샷이나 실제 마우스 조작 녹화가 아니다.

최종 진단 종료 코드 **0**, `original-pets.json`의 `success: true`.
기본 펫 **5종 / 기존 50개 클립 / PNG 130장**을 확인했으며, 5종 모두
`heldAndLandingVerified: true`이다. 보리의 들어 올림·착지·복귀와 나머지 4종의
들어 올림, Mochi의 착지 캡처를 열어 모양·잘림·겹침을 확인했다.
이 확인은 선택한 정지 프레임에 한정된다.

## 검증 한계

Headless 입력과 화면 밖 macOS 렌더링은 실제 마우스 조작의 증거가 아니다.
