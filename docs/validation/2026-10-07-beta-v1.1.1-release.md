# Beta v1.1.1 배포·업데이트 검증

2026-10-07 · 내부 버전 `1.1.1-beta`

## 배포 기준과 결과

작업 시작 전 전체 worktree의 브랜치·HEAD·미커밋 변경·프로젝트 버전·실행 경로를 확인했다.
최신 구현은 `codex/remove-unused-features`의 기능 제거·로그인 복원·메모리 개선을 포함한 `34cbd584`였다.
릴리스 노트와 Windows 실행 진단 보완 후 실제 배포 빌드는 `887d0127e57e5145062d0d558fb71b113284542d`다.
해당 소스를 push했고 공개 태그 `v1.1.1-beta`가 이 빌드 커밋을 가리킨다.
다른 앱 worktree와 기존 웹 checkout의 로그인 관련 변경은 보존했다.

- [GitHub Beta_v1.1.1](https://github.com/C-Caffe1ne/Unfold/releases/tag/v1.1.1-beta): prerelease, 공개 파일 10개.
- [웹 다운로드](https://unfoldpet.dokhustudio.com/#install), [변경 이력](https://unfoldpet.dokhustudio.com/#changelog).
- 웹 배포 커밋: `c4baa082345e828ced8e977b75508573805d3f62`. 기존 main push → Cloudflare Workers 배포 경로를 사용했다.
- Mac 두 아키텍처의 앱·DMG는 Developer ID 서명, Apple 공증, stapler, Gatekeeper 검사 통과.
- Windows x64는 코드 서명이 없는 베타 설치 파일이다.

| 설치 ZIP | 크기 |
|---|---|
| Unfold-v1.1.1-beta-osx-arm64-notarized-installer.zip | 77,395,387 bytes (73.8 MiB) |
| Unfold-v1.1.1-beta-osx-x64-notarized-installer.zip | 81,568,346 bytes (77.8 MiB) |
| Unfold-v1.1.1-beta-win-x64-installer.zip | 86,647,476 bytes (82.6 MiB) |

설치 ZIP 3개·SHA-256 목록·OS별 full nupkg 3개·OS별 feed JSON 3개만 업로드했다.
ZIP CRC, 내부 설치 파일 해시, nupkg SHA-256/크기/PackageId/버전, 공개 후보의 소스·인증 파일 미포함을 검사했다.
GitHub의 10개 asset 크기·SHA-256 digest가 로컬 manifest와 일치한다.

## 빌드·실행 검증

[최신 소스 CI 37611505352](https://github.com/C-Caffe1ne/Unfold/actions/runs/37611505352) 두 OS job이 성공했다.

| 대상 | 검사 결과 |
|---|---|
| macOS CI | Release 763개 통과, 실패 0, 건너뜀 0 |
| Windows CI | Release 760개 통과, 실패 0, macOS 전용 3개 건너뜀 |
| 최종 로컬 Release 빌드 | 경고 0, 오류 0 |
| 서명된 Mac ARM64 앱 | 격리된 native 실행 진단 성공, PNG 100개, updater 포함·설정 진입 확인 |
| 공증된 Mac x64 앱 | Apple Silicon Rosetta 실행 진단 성공, PNG 100개 |
| Windows 설치 앱 | Windows CI native 실행 진단 성공, PNG 100개 |
| Windows 설치 프로그램 | silent 설치·payload/metadata·버전·시작프로그램 opt-out·재설치·제거·기존 데이터 보존 성공 |

Windows 진단의 기존 `ActualTransparencyLevel == None` 단정은 Windows의
`Transparent` 보고 때문에 실패했다. 먼저 layout 지표와 화면을 기록하고, Windows에 한해
이 합성 플래그를 허용하면서 불투명 배경(alpha 255), 투명 hint 부재, 전체 client frame,
모서리 PNG alpha 255 검사는 유지했다. 제품의 창 렌더링 설정은 변경하지 않았다.

## 앱 업데이트 검증

앱 메뉴·설정의 **업데이트 확인 → 다운로드 → 재시작하여 적용** 흐름이 있다.
자동 진단에서 설정 버튼으로 실제 업데이트 창을 열고 updater 설치 상태를 확인했다.
화면 상태 검사는 진단 fixture를 사용하며, 공개 서버 검사는 별도로 실제 `AppUpdates.cs`와
Velopack 1.2.0 backend를 연결한 격리된 probe로 수행했다.

| 대상 | 확인 범위 |
|---|---|
| `osx-arm64-beta` | 로컬·공개 GitHub feed에서 1.1.0 → 1.1.1 조회, 다운로드·해시·Ready 복원·최신 버전 Current 통과 |
| `osx-x64-beta` | 같은 조회·다운로드·해시·상태 복원·최신 버전 판정 통과 |
| `win-x64-beta` | 같은 조회·다운로드·해시·상태 복원·최신 버전 판정 통과 |
| 실제 Mac ARM64 교체 | 공개 1.1.0 signed app의 임시 복사본 → `PrepareApply()` → 실제 signed UpdateMac → 1.1.1 교체·자동 재시작·진단 성공 |
| 실제 Windows x64 교체 | 공개 1.1.0 설치본 → `PrepareApply()` → 실제 Update.exe → 1.1.1 교체·자동 재시작·진단 100개 캡처·기존 데이터 보존 성공 |

Mac 교체 검사에서는 production backend의 wait-for-exit/apply/restart 경로를 실행했다.
테스트 driver PID를 기다리도록 하고 재시작 인자에 `--smoke-test`만 추가해 사용자 데이터 접근을 방지했다.
교체 후 앱 버전·업데이트 manifest·서명·공증 티켓을 다시 검사했고 재시작 앱의 PNG 100개 진단이 통과했다.
사용자의 Applications 설치본과 설정·계정 데이터는 교체하지 않았다.
Beta v1.0.3 이상은 앱 업데이트를 사용할 수 있고 v1.0.2 이하는 수동 설치가 필요하다.

[공개 Windows 적용 CI 37616045930](https://github.com/C-Caffe1ne/Unfold/actions/runs/37616045930)에서도
같은 production backend를 사용해 실제 설치본을 업데이트하고 재시작 인자에 `--smoke-test`를 추가했다.
공개 1.1.0 설치 ZIP과 1.1.1 nupkg의 고정 SHA-256을 검사하고, 교체 후 manifest·앱 버전·실행 진단과
기존 데이터 sentinel 해시 보존을 확인했다. 이 검사는 일회용 Windows CI에만 설치한다.
공유 CI IP의 비인증 GitHub API 호출 제한으로 첫 조회가 실패해 임시 `contents:read` job 토큰을
검사 도구에만 제공했다. 배포 앱에는 토큰을 포함하지 않는다. 로컬 공개 3채널 조회·다운로드 검사는 비인증으로 통과했다.
검사 도구·workflow만 추가했으며 공개 배포 앱의 소스 커밋과 파일은 `887d0127` 기준 그대로다.

## 웹 검증

웹 테스트 71개, 정적 사이트 검사, Cloudflare 배포 dry-run, 로컬 HTTP route 검사 114개가 통과했다.
공개 HTTPS 검사 46개에서 네 경로의 HTML이 배포 커밋과 일치하고,
기존 31개·새 4개 다운로드 리디렉션의 정확한 목적지를 확인했다.
실제 웹에서 설치 ZIP 3개와 checksum을 다운로드해 SHA-256·크기 일치를 확인했다.
내부 docs/tools와 알 수 없는 경로의 404도 확인했다. 브라우저에서 공개 다운로드·변경 이력을 확인했다.

## 검증 경계

- Mac ARM64에서 실제 helper의 교체·재시작까지 검증했다. Intel은 Rosetta 실행 검증이며 물리 Intel 기기 검증은 수행하지 않았다.
- Windows는 native CI 설치·실행·공개 feed 다운로드 및 실제 updater 적용·자동 재시작을 검증했다. 물리 Windows 기기에서 사용자 입력·배율별 검사는 수행하지 않았다.
- 실제 사용자 입력·OS 보안 경고·기기/배율별 검사는 자동 진단과 구별한다. 실제 OAuth·결제는 이번 실행 진단에서 수행하지 않았다.
- 메모리 개선은 포함하지만 400 MB 이하를 보장하지 않는다. Retina 2배율의 짧은 검사에서 대표 구성 447.07 MB, GIF 406.93 MB였고 최종 장시간 검증은 남아 있다.
