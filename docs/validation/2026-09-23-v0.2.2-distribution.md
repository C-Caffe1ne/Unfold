## 포함한 수정과 빌드 입력

최근 macOS 전체화면·Space 펫 표시, 호버 시계, 연속 클릭 중 창 크기 유지,
설정·펫 재생 복구, 손상된 펫에서도 알림 유지, 홈 미리보기 재시도, 미사용 효과음 정리가 포함된다.
Mochi·보리·강아지·고슴도치·펭귄은 각각 열 개 행동을 유지한다.

이번 배포에서는 앱 버전과 macOS 빌드 번호, 버전에 맞는 배포 안내만 추가·수정했다.
`artifacts/releases/v0.2.2/source-inputs.json`에 빌드 입력 140개 해시를 기록했고,
패키징 전후 동일함을 확인했다. 이 검사는 기존 미커밋 소스를 누락한 HEAD만 게시하는 오류를 방지한다.

## 재현과 증거

```sh
dotnet restore Unfold.slnx --locked-mode
dotnet test Unfold.slnx -c Release --no-restore \
  --logger 'trx;LogFileName=release.trx' --results-directory artifacts/releases/v0.2.2/tests
bash artifacts/releases/v0.2.2/build-release.sh
python3 artifacts/releases/v0.2.2/package-windows.py
python3 artifacts/releases/v0.2.2/verify-archives.py
```

Windows PowerShell이 호스트에 없어 기존 스크립트와 같은 `dotnet publish` 인자로 게시했다.
실행기·README 문구는 현재 `publish-desktop.ps1`에서 읽어 Windows 줄바꿈으로 저장했다.
ZIP은 `win-x64/Unfold.cmd`, `README.txt`, `RELEASE-NOTES.md`, `app/` 구조다.

Apple Silicon ZIP을 `artifacts/releases/v0.2.2/verify-osx-arm64/`에 풀어 **압축 배포 실행 파일**로 검사했다.
통합·펫 진단은 각각 새 `artifacts/releases/v0.2.2/smoke-profile/`, `pets-profile/`을 사용했다.
사용자의 실제 설정·기록·펫 데이터와 실행 중인 개발 환경을 변경하지 않았다.

## 실제 OS 확인과 한계

Apple Silicon Mac에서는 실제 게시 실행 파일과 네이티브 렌더링을 사용했지만,
창은 화면 밖에 배치하고 입력 경로를 프로그램으로 호출했다. 대표 홈·펫 캡처를 확인했다.
모든 프레임의 잔상·자연스러움, 물리 마우스·키보드, 효과음 청취, 로그인 자동 실행,
다중 모니터·DPI, 장시간 사용의 검증은 아니다.

Intel Mac·Windows에서의 실제 실행은 미검증이다. 해당 파일은 빌드·버전·자산·압축 형식을 검사했다.
macOS Developer ID 서명·공증·stapling, Windows 코드 서명은 포함하지 않았다.
설치 프로그램과 자동 업데이트는 제공하지 않는다.

앱을 완전히 종료한 뒤 CPU·OS에 맞는 ZIP을 풀어 교체한다. macOS는 `Unfold.app`,
Windows는 `win-x64/Unfold.cmd`를 실행하며 `app` 폴더를 분리하지 않는다.
기존 사용자 데이터는 별도 데이터 폴더에 유지된다.
