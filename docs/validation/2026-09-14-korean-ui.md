# UI 한글화 검증

2026-09-14 · `release/mvp`, 기준 커밋 `d9ee699` 이후의 미커밋 작업 트리.
macOS 26.6.2 (25G83), arm64, .NET 런타임 10.0.12에서 확인했다.

## 변경과 범위

설정·휴식 안내·루틴·프로필·회고·펫 팩·트레이·펫 메뉴의 일반 UI를 한국어로 바꿨다.
기본 루틴 안내, 타이머 아이콘과 입력 항목의 접근성 이름, 오류 안내도 포함한다.
회고 요일은 `ko-KR`로 표시한다. 기존 이름, ID, 설치 동작 값, 저장 형식과 CSV 열은 유지한다.
자세한 범위는 [한글화 안내](../localization.md)에 있다.

보리 팩 완성도 작업은 사용자 요청에 따라 후순위로 미뤘다. 원본과 런타임 이미지는
SHA-256 `5558e3b0dff14addf559c083d5e0247cb32e08c5a2741e156cab23eb8a759623`,
`Bori-0.1.0.unfoldpet`은 `7c865178eef8f10c8599a87331d85335db471d1b149f6303bc9ceeed0a779a03`으로
기존 값과 같다. 이번 작업에서 아트나 팩 버전을 변경하지 않았다.

## 자동 검사

`AVALONIA_TELEMETRY_OPTOUT=1`, `DOTNET_CLI_TELEMETRY_OPTOUT=1`을 설정해 실행했다.

```sh
dotnet test Unfold.slnx -c Release --no-restore -m:1 -p:UseSharedCompilation=false
dotnet restore Unfold.slnx --locked-mode -p:RuntimeIdentifier=osx-arm64 -m:1 -p:UseSharedCompilation=false
dotnet publish src/Unfold.Desktop/Unfold.Desktop.csproj -c Release -r osx-arm64 \
  --self-contained true --no-restore -p:PublishReadyToRun=true -p:UseSharedCompilation=false \
  -o /tmp/unfold-ko-hHSVkC/publish
```

- Release 빌드 및 전체 테스트 **127개 통과, 실패 0, 건너뜀 0**. 기존 122개에 한글화 검사 5개를 추가했다.
- 영문 문화권에서도 한국어 요일을 표시하고 날짜·횟수 열이 겹치지 않는지 확인했다.
- 이전 영문 루틴의 완료 기록을 저장·재로드하고 같은 이름과 기존 열 형식으로 내보냈다.
- 한국어 텍스트 입력 후 Enter 저장, 루틴 ID와 기존 안내 문구 보존을 확인했다.
- 잘못된 팩·이전 버전·파일 변경 충돌에 한국어 복구 안내가 나오는지 검사했다.
- 기존 타이머 일시정지·정지·초기화·Space 조작, 입력 즉시 저장, 펫 팩 설치·업데이트·재설치 테스트가 통과했다.
- 한글 문구로 인해 200% 미리보기의 설치 버튼이 아래로 밀리는 회귀를 발견했다.
  설치 창 본문의 간격을 10으로 조정해 기존 배치 검사를 통과시켰다.
- 고정 패키지 복원과 macOS arm64 자체 포함 게시가 종료 코드 0으로 완료됐다.

샌드박스에서 응답하지 않던 첫 복원 실행은 중단하고 필요한 접근으로 다시 실행했다.
테스트 러너의 로컬 소켓과 네이티브 그래픽 접근도 허용된 실행 환경에서 검사했다.
패키지 잠금 파일을 변경하거나 보안 검사를 끄지 않았다.

## macOS 게시 앱 진단

```sh
UNFOLD_DATA_DIR=/tmp/unfold-ko-hHSVkC/profile \
  /tmp/unfold-ko-hHSVkC/publish/Unfold --smoke-test
```

새 데이터 폴더에서 실행했고 종료 코드 0, [진단 JSON](2026-09-14-korean-ui.json)의
`success: true`를 확인했다. PNG 19장, 사용자 루틴 2개, 프로필 1개, 완료 기록·CSV 1건을 생성했다.
초기화와 정지 후 각각 1.2초간 타이머 대기, 휴식 창 생성 취소,
팩 설치·업데이트·이미지 재설치 복원과 잘못된 파일 거부가 통과했다.

다음 10개 캡처에서 한글 글꼴, 문구 배치와 버튼 표시를 직접 확인하고 보존했다.
영문 `Writing pause`, 안내 문구, `Diagnostic companion`은 진단이 입력한 사용자 데이터다.
자동 번역하지 않는 기존 이름·안내 보존 범위에 해당한다.

## 확인하지 않은 항목

게시 앱의 실제 Avalonia 네이티브 백엔드에서 실행한 off-screen 진단이다. 버튼 이벤트,
세션 경과 시간, 파일 선택과 CSV 목적지는 진단 코드가 지정하고 OS 알림은 억제한다.
캡처는 실제 모니터에서 사람이 조작한 화면 녹화가 아니다.

Windows 실기, 실제 한글 IME 조합, 스크린리더 낭독, OS 알림 전달,
파일 선택 창의 OS 공통 버튼, 로그인·sleep/wake·다중 모니터·실제 고DPI는 미확인이다.
트레이·펫 메뉴의 한국어 문구는 코드로 확인했고 실제 메뉴를 열어 누르는 검사는 하지 않았다.
보리의 아트 완성도·상업적 권리 검수도 이번 한글화 결과에 포함하지 않는다.
