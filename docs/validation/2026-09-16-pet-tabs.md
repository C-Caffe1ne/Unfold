# 펫 추가 페이지와 탭 전환 검증

2026-09-16 · `release/mvp` 작업 트리, macOS arm64 / .NET 10.
기존 GIF·MP4 가져오기 구현 위에서 설정의 진입점과 페이지 구조를 변경했다.

## 변경

- 펫 선택 필드를 왼쪽 정렬, 너비 200 논리 픽셀로 축소하고 옆의 펫 추가 버튼 제거.
- 사이드바에 한국어 접근성 이름·도구 설명과 선택 표시가 있는 **펫 추가** 탭 추가.
- 같은 설정 창 안에서 **펫 팩 열기 / 펫 팩 만들기** 전환. 사용자 흐름에서 새 앱 창을 열지 않는다.
- 파일 가져오기·동작별 배정·생성은 만들기 탭에서 수행한다. 생성 후 열기 탭에 팩을 열고,
  사용자가 설치를 눌러야 라이브러리에 반영한다. 기존 팩의 설치·업데이트·재설치 흐름 유지.
- 페이지와 창을 숨겨도 이름·동작 파일·열린 팩·선택한 내부 탭 유지. 숨긴 미리보기는 중단.
- 생성할 때마다 새 팩 ID를 사용해 후속 생성이 기존 설치와 충돌하지 않게 했다.
  초안은 생성 후에도 편집할 수 있지만 앱 종료 후에는 저장한 팩 파일만 남는다.
- 진단용 창은 동일한 페이지 컨트롤을 사용한다. 종료 시 미리보기·가져오기 리소스를 정리한다.
