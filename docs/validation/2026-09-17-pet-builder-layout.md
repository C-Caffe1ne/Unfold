# 펫 추가 탭 레이아웃 검증

2026-09-17 · `release/mvp`의 C#·Avalonia **펫 팩 만들기** 탭을 참고 이미지의
정보 구조에 맞춰 다시 배치하고 **펫 팩 열기** 탭의 미리보기 밀도를 조정했다. 참고
이미지의 색상은 제품 색상으로 사용하지 않고 미리보기·버튼·행동 파일 영역을 구분하는
표시로 해석했다.

## 원인

기존 화면은 다섯 행동을 세로 카드로 쌓아 이름 입력, 미리보기와 행동 파일의 관계를 한눈에
보기 어려웠다. 설정 창 안에서 펫을 만들 때 행동 간 비교와 파일 교체를 위해 긴 세로 이동도
필요했다.

## 변경

- 펫 이름 입력은 페이지를 채우지 않는 320px 너비로 줄이고 왼쪽에 배치했다.
- 이름 옆의 **파일 가져오기** 버튼을 제거했다. 파일은 각 행동 카드의 **＋** 버튼에서
  직접 선택한다.
- 최대 너비 600px의 큰 미리보기 영역을 화면 가운데 배치하고, 파일이 없을 때 안내 문구를
  표시한다.
- 쉬는 모습, 휴식 안내, 스트레칭, 휴식 완료, 클릭 반응을 동일 폭 카드 5개로 한 줄에
  배치했다.
- 각 행동 카드의 재생, 파일 추가·교체, 삭제를 아이콘 버튼으로 바꾸고 접근성 이름과
  툴팁을 유지했다.
- **펫 팩 만들기…**를 고정 작업 영역의 오른쪽에 배치했다.
- 1120×800 설정 창에서는 다섯 카드와 조작 버튼을 한 화면에 표시한다. 860×680에서는
  세로 스크롤 후 한 줄 전체를 볼 수 있다. 폭이 더 좁은 독립 제작 창에서는 행동 행만
  가로 스크롤해 마지막 행동까지 접근한다.
- 행동별 파일 선택, 교체 확인, 미리보기, 제거, 팩 저장과 탭 전환 계약은 유지했다.
- **펫 팩 열기** 탭의 미리보기 영역은 최대 520px로 줄여 가운데 배치하고,
  **미리 볼 동작** 드롭다운은 260px 너비로 줄였다.
- 200% 미리보기의 384px 애니메이션과 최소 480px 독립 창의 세로 스크롤 계약은 유지했다.

## 미검증·위험

- macOS에서 off-screen Avalonia 렌더링과 자동 버튼 이벤트를 실행했다. 실제 포인터 조작,
  VoiceOver와 장시간 애니메이션 사용성 검수는 아니다.
- 실제 Windows의 글꼴 폭, DPI, 가로 스크롤 조작과 키보드 포커스 순서는 이번 변경에서
  실행하지 않았다.
