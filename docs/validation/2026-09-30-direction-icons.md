# 방향 SVG 아이콘 적용

## 원인과 범위

숫자 입력·드롭다운·스크롤바에는 Fluent 기본 꺾쇠가, 기록·호환성 픽셀 에디터에는 별도의 경로나 문자 화살표가 쓰였다.
2026-09-30 사용자가 전달한 위·아래·좌·우 SVG를 공통 적용했다.

## 변경

- `Assets/Icons/Directions/`: 사용자 SVG 4개를 24×24 원본 그대로 보존. 출처·Figma 노드·SHA-256 기록.
- `SvgIcon.cs`: 기존 내비게이션의 SVG 마스크 렌더러를 공통 사용. 원본의 투명도를 보존하고 컨트롤의 현재 테마 글자색으로 표시.
- `DirectionIcon.cs`: 네 방향과 펼침·접힘 상태의 방향 전환.
- `DesignSystem.Directions.cs`: 숫자 입력, 드롭다운, 가로·세로 스크롤바의 화살표만 교체. 버튼 템플릿과 입력 동작 유지. 이름이 겹치는 슬라이더 버튼은 제외.
- `BreakReviewWindow.cs`: 이전·다음과 날짜 펼침·접힘 아이콘. 기존 40×40 이동 버튼 유지.
- `EditorWindow.cs`: 프레임·레이어 이동 아이콘과 버튼 이름. 뒤집기·재생 아이콘은 유지.

초기 네이티브 캡처에서 Fluent `PathIcon`의 8×8 슬롯이 스크롤바 SVG를 잘라내는 현상을 발견했다.
교체한 화살표에 한해 `ClipToBounds=false`로 설정하고 기존 슬롯의 중심에 24×24 투명 SVG 영역을 배치했다.
드롭다운의 12×12 슬롯에서도 같은 잘림을 방지한다. 상위 버튼과 스크롤 컨테이너의 클리핑은 유지한다.

## macOS 렌더링

새 `UNFOLD_DATA_DIR=/tmp/unfold-directions-verified.nEE1SS`에서 Avalonia Native 렌더러로 진단 창을 구성했다.
테마 4개 × 탭 4개, 640×560 최소 창, 입력 비활성, 기록 접힘·펼침으로 총 20장을 생성했다.
라일락 설정·비활성·기록 펼침·최소 창과 어두운 테마 홈을 직접 검수해 화살표 잘림·중앙 배치·색을 확인했다.

최종 캡처와 진단 프로그램은 로컬 `artifacts/verification/direction-icons/`에 있다.
캡처는 `RenderTargetBitmap`으로 저장했으며 실제 사용자 프로필을 읽거나 결제·로그인을 호출하지 않았다.
