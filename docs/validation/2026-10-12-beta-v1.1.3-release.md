## 운영 결제와 검증 경계

`create-checkout` v34·`lemon-webhook` v19의 배포 소스와 커밋 소스가 일치했다. 한국 Live 상품 매핑은 KRW 4,900이며 웹 공개 설정은 Live·checkoutEnabled=true다. 이번에는 서버를 중복 배포하지 않았다. 적용된 보안·Live 통화 마이그레이션은 운영 DB에서 확인했고 비밀값은 읽거나 문서에 저장하지 않았다.

실결제 성공은 사용자 보고다. 이번 운영 DB 조회에는 Live pending 주문 1개, Test active 권한 3개만 있고 Live active 권한은 없었다. Live 웹훅 처리·앱 구매 복원은 완료로 표시하지 않는다. 보안 advisor의 서버 전용 RLS/no-policy INFO와 비밀번호 유출 방지 WARN은 별도로 남아 있다.

물리 Intel·Windows 사용자 입력·기기별 배율·실제 Windows 소리 청취, 운영 Google OAuth·Live 권한·구매 복원·환불은 이번 배포 진단 범위 밖이다. Google 로그인 Unfold 브랜딩은 사용자 요청으로 보류했고 저장하지 않았다. GLB 미리보기 회전의 끊김 개선도 후속 작업이다.
