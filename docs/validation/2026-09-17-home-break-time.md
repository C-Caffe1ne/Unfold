# 홈 스트레칭·휴식 시간 검증

2026-09-17 · `release/mvp`의 C#·Avalonia UI에서 스트레칭 간격을 설정 탭에서 홈으로
옮기고, 다음 휴식의 목표 시간을 함께 설정하도록 변경했다.

## 변경

- 홈 오른쪽 열에 **시간 설정** 카드를 추가했다.
- **스트레칭 시간**은 작업 후 알림까지의 기존 5~240분 간격이다. 실행 중에는 입력을
  잠그고 일시정지 또는 중지 상태에서 변경한다.
- **휴식 시간**은 1~10분이며 스트레칭 시간 바로 아래에 배치했다. 실행 중에도 변경할 수
  있지만 카드의 **적용**을 눌러야 저장되며 다음 휴식부터 적용한다.
- 설정 탭의 타이머 카드에는 **자리 비움 시간**과 **다시 알림 시간**만 남겼고, 별도
  **적용**으로 저장한다.
- 휴식 세션은 초대가 열릴 때 휴식 시간을 스냅샷으로 보관한다. 설정 변경이나 기존 루틴
  편집이 진행 중 세션을 바꾸지 않는다.
- 여러 단계 안내는 설정한 총 휴식 시간에 비례해 진행한다. 조기 완료, 초과 시간과
  +60:00 상한은 유지한다.
- 완료 기록의 `planned_seconds`에는 설정된 휴식 시간을 저장하고 `actual_seconds`에는
  실제 완료 시점을 저장한다.

## 검증 경계

- macOS arm64에서 off-screen Avalonia 렌더링과 자동 버튼 이벤트를 실행했다. 실제 포인터,
  VoiceOver, 장시간 사용성 검수는 아니다.
- 실제 Windows의 글꼴 배치, DPI, 키보드 포커스 순서는 이 변경에서 실행하지 않았다.
- 휴식 시간은 분 단위 1~10분이다. 초 단위 입력과 10분을 넘는 휴식은 현재 UI 범위가 아니다.
