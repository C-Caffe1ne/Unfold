# 펫 하단 타이머·호버 표시 검증

## 기준과 범위

2026-10-13의 최신 개발 소스 `codex/gif-glb-import-guidance`, `09853c7`,
`1.1.3-beta`를 기준으로 구현했다. `codex/remove-unused-features`의 `6f0a3dd`보다
제품 변경 5커밋이 앞선 소스다. 공개 `v1.1.3-beta`의 소스 `b1242ea`도 이 기준의 조상이다.
작업 경로는 `.worktrees/pet-overlay-hover`, 브랜치는 `codex/pet-overlay-hover`다.
기존 작업트리의 변경과 사용자 데이터는 이 작업에서 수정하지 않았다.

요청 범위는 하단 타이머, 오전·오후 현재 시각, 호버 표시·유지, 몸체 가까운 알림 배치다.
펫 재생과 입력, 알림 행동, 타이머 시작·일시정지·즉시 중지 계약을 보존한다.
버전 변경·커밋·배포는 수행하지 않았다.

구현 소유자는 제품 코드와 기존 테스트를 담당하고, 별도 테스트 워커는
`PetTimerHoverTests.cs`만 담당했다. 구조 검토 워커는 읽기 전용으로 검토했다.
Orca CLI가 없어 이 범위에 필요한 두 워커를 Codex 협업 도구로 실행했다.

## 동작과 구현

- `PetWindow`는 펫, `PetOverlayWindow`는 알림, `PetTimerWindow`는 시간·조작 바를 각각 그린다.
  호버나 알림 크기 변경으로 펫 창 크기·내부 배치를 변경하지 않는다.
- 타이머는 클릭 가능한 몸체 경계 하단에서 8px 떨어져 표시된다. 현재 시각은 위 행에
  `오전 12:05`, `오후 08:12` 같은 12시간 형식으로 표시한다.
- 펫 몸체에 진입하면 180ms 동안 나타나고 완전히 표시된 후 2초 유지한 뒤
  180ms 동안 사라진다. 펫 위에 계속 머물러 있어도 2초 후 사라지며, 재진입하면 다시 나타난다.
  타이머 위에서는 유지하고 벗어나면 2초 후 사라진다. 버튼 입력 캡처와 키보드 포커스도 유지한다.
- 완전히 숨은 창은 클릭을 통과시킨다. 표시 중에는 버튼이 입력을 받고 시간·빈 여백은 통과한다.
  투명한 창에도 동작하도록 기존 네이티브 커서 폴링으로 위치를 읽는다.
  표시 효과는 카드에만 적용하고, 숨겨진 숫자의 애니메이션은 중지한다.
- 알림 꼬리는 몸체 경계에서 4px 떨어진다. 2D 클립 전체의 불투명 영역·프레임 오프셋,
  여백·렌더 변환을 반영한다. GLB는 같은 행동 안에서 몸체 경계를 확장만 하여 프레임마다
  알림이 흔들리는 것을 줄인다. 기존 가운데 경계의 좌우 전환 완충 범위는 유지한다.
- Dock 아래에 공간이 없으면 타이머만 옆으로 이동한다. 양쪽도 부족한 좁은 화면에서는 위로 이동한다.
  알림과 타이머는 서로 겹치지 않도록 배치한다.

수정 후 새 프로필에서 약 56.9초의 진단을 완료했다.

알림·창 수명과 설정을 검사한다. 이 진단의 시뮬레이션 결과와 아래 실제 입력 결과는 구분한다.

## 실제 macOS 확인

현재 제품 DLL을 참조하는 외부 검증 호스트를 실행하여 실제 macOS 창을 확인했다.
새 `UNFOLD_DATA_DIR`을 사용했고, 시작·종료·입력은 해당 검증 앱에 한정했다.
제품의 렌더링 설정, 펫·알림·타이머 창, 커서 폴링과 버튼을 그대로 사용했다.
이 호스트는 진단 시작 후 네이티브 입력 검사를 허용하도록 진단 플래그를 전환한다.

CUA에는 커서를 이동만 하는 API가 없어, 검증 단축키로 창을 실제 커서 아래에 이동했다.
따라서 아래는 **실제 네이티브 커서 판독과 창 동작의 근거**이며, 사람이 마우스를 움직이는
수동 호버 시험과는 구분한다. 스크린샷은 배치를 확인하기 위해 표시 상태를 고정했다.

| 관찰 | 결과 |
|---|---|
| 펫 진입 후 표시 | 약 180ms 페이드, 완전 표시 후 약 2초 유지, 약 180ms 페이드 아웃 |
| 타이머 위의 커서 | 5,730개 샘플·약 94.6초 동안 불투명도 1 유지 |
| 타이머에서 벗어난 뒤 | 약 2.01초 후 페이드 시작, 약 2.20초 후 불투명도 0 |
| 위 호버 구간의 펫 | 창 288×288, 내부 원점 (0,0), 같은 네이티브 핸들·재생 세대 유지, 추가 재배치 없음 |
| 타이머 실제 버튼 클릭 | 시작 → 일시정지 → 계속 → 중지·60:00 초기화 확인, 재생 세대 유지 |
| 알림 실제 버튼 클릭·좌우 이동 | 미루기·휴식 시작·완료 확인, 알림 상태 전환 중 펫 크기·내부 재배치 증가 0 |

수동으로 지정한 좌우 창 이동은 위치 불변 검사의 대상에서 제외했다.
알림 행동에 따른 의도된 펫 행동·재생 전환도 별도로 취급한다.
[샘플 요약 JSON](2026-10-13-pet-timer-hover/native-evidence.json)에 시간과 계측 결과를 보관했다.
전체 샘플은 `/tmp/unfold-overlay-hover-20261013/profile/native-samples.jsonl`에 있다.

![실제 macOS의 펫 하단 시간·타이머와 가까운 알림](2026-10-13-pet-timer-hover/macos-bori-visible.png)

이 검사는 네이티브 배치·호버·실제 버튼 동작을 확인했다. 모든 화면 프레임에서 잔상이 없다는
판정은 연속 화면 영상 분석을 추가해야 한다. Windows 실기 입력, 여러 모니터의 혼합 배율,
Spaces 전환, VoiceOver와 장시간 사용은 이번 변경에서 확인하지 않았다.
