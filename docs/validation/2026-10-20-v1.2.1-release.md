## 웹

웹 `bc70a2d`·`e5d8220`을 `main`에 푸시해 Cloudflare 자동 배포로 반영했다. 변경 이력에는 사용자가 체감하는 변경 8개만 한국어·영어·일본어·중국어로 적었다.
다운로드 버튼·파일 크기·체크섬 링크를 v1.2.1로 바꾸고 새 다운로드 주소 4개를 추가했다. 기존 51개 주소는 유지한다.
웹 87개, 사이트·번역(356키)·비밀값·배포 dry-run, 로컬 HTTP 145개 통과. 공개 HTML·번역 파일 3개가 배포 커밋과 바이트 일치하고 새 주소 4개와 v1.2.0 주소가 302로 연결된다.
로컬에서 4개 언어 화면과 390px 폭을, 공개 사이트에서 일본어 변경 이력을 확인했다. 콘솔 오류는 없다.
