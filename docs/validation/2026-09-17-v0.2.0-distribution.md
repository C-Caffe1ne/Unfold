# v0.2.0 배포 검증

## 환경과 범위

- 기준 브랜치와 커밋: `release/mvp`, `2f02e8a`
- 배포 버전: `0.2.0`
- 빌드 호스트: macOS 26.6.2, arm64, .NET SDK 10.0.401
- 현재 작업 트리의 UI/UX 2단계 미커밋 변경을 보존해 배포물에 포함했다.
- 버전의 단일 기준인 `src/Unfold.Desktop/Unfold.Desktop.csproj`의 `<Version>`을
  `0.1.1`에서 `0.2.0`으로 변경했다.

## 실행한 명령과 결과

| 검사 | 결과 |
|---|---|
| `dotnet test Unfold.slnx -c Release --no-restore --disable-build-servers` | 175 통과, 실패·건너뜀 0 |
| `bash Scripts/make-macos-bundle.sh osx-arm64` | 성공, 자체 포함 `Unfold.app`과 ZIP·tar.gz 생성 |
| 게시된 arm64 `Unfold.app/Contents/MacOS/Unfold --smoke-test` | 종료 코드 0, `success: true`, PNG 42장 |
| `bash Scripts/make-macos-bundle.sh osx-x64` | 성공, 자체 포함 `Unfold.app`과 ZIP·tar.gz 생성 |
| `dotnet publish ... -r win-x64 --self-contained true -p:PublishReadyToRun=true` | 성공, portable app 생성 |
| ZIP `unzip -tq`, tar.gz `tar -tzf` | 다섯 압축 파일 모두 오류 없음 |
| macOS `codesign --verify --deep --strict` | arm64·x64 모두 통과 |

최초 테스트 실행은 제한된 샌드박스에서 MSBuild named pipe 생성이 거부되어
`SocketException (13): Permission denied`로 중단됐다. 같은 소스와 명령을 로컬 소켓이
허용된 환경에서 다시 실행해 175개가 통과했다. 코드 실패로 분류하지 않는다.

Windows PowerShell이 빌드 호스트에 없어 `publish-desktop.ps1`을 직접 실행하지 못했다.
대신 스크립트와 같은 `win-x64/app` 구조로 게시하고 `Unfold.cmd`, `README.txt`,
`cross-platform.md`, `THIRD-PARTY-NOTICES.md`를 포함한 뒤 ZIP을 생성했다.

## 경계면 교차 검증

- 세 게시물의 `Unfold.deps.json`이 각각 `osx-arm64`, `osx-x64`, `win-x64`와
  `Unfold/0.2.0`을 기록한다.
- 실행 파일 형식은 macOS arm64 Mach-O, macOS x86_64 Mach-O, Windows x86-64 PE다.
- 세 게시물 모두 기본 캐릭터 manifest와 이미지, FFmpeg, LGPL 라이선스를 포함한다.
- Windows ZIP은 최상위 `Unfold.cmd`와 `README.txt`, `app/Unfold.exe`, 인접 DLL,
  `Assets`, `Tools`, 설치 문서와 제3자 고지를 포함한다.
- macOS 두 ZIP의 `CFBundleShortVersionString`은 `0.2.0`이고 압축 해제 후 ad hoc 서명
  검증을 통과했다.

## 자동 검사·실제 OS·미검증

- 자동 검사: Release 테스트, 세 RID 게시, 압축 무결성, 파일 형식, 버전, 자산과
  라이선스 포함, macOS ad hoc 서명을 확인했다.
- 현재 macOS arm64: 게시된 arm64 실행 파일로 격리 진단을 실행했다. 이는 실제 macOS
  런타임에서 창과 상태 흐름을 자동으로 구동한 결과이며 사람의 마우스·키보드 검수는 아니다.
- macOS Intel: 빌드·구조·서명 검증만 통과했다. Intel Mac 실행은 미검증이다.
- Windows x64: 빌드·구조·압축 검증만 통과했다. 실제 Windows 실행, SmartScreen,
  트레이, 로그인 시작과 DPI는 미검증이다.
- 두 macOS 번들은 ad hoc 서명이다. Developer ID 서명, 공증과 stapling은 실행하지 않았다.
- Windows 코드 서명과 설치 프로그램, 자동 업데이트는 제공하지 않는다.

## 설치

- Apple Silicon Mac은 `Unfold-v0.2.0-osx-arm64.zip`, Intel Mac은
  `Unfold-v0.2.0-osx-x64.zip`을 풀고 `Unfold.app`을 실행한다. 다운로드 격리로 실행이
  막힌 경우 정확한 Gatekeeper 오류를 확인한 뒤 로컬 빌드에 한해
  `xattr -cr /path/to/Unfold.app`을 적용할 수 있다.
- Windows는 `Unfold-v0.2.0-win-x64.zip` 전체를 한 폴더에 풀고 `Unfold.cmd`를 실행한다.
  `app` 폴더의 DLL·`Assets`·`Tools`를 분리하거나 삭제하면 안 된다.
