# 펫 팩 만들기 통합 — 2026-10-05

## 원인

기존 GLB 편집기와 이미지·영상 편집기가 서로 다른 탭과 배치를 사용했다.
GLB 행동 설명, 반복 규칙 해설, 재생 요약, 삼각형·관절 정보는 사용자가 요청하지 않은 UI 설명이었다.
사용자 요청에 따라 해당 문구를 제거하고 설명 문구를 임의로 다시 추가하지 않는 기준을 적용했다.

작업 기준은 최신 `codex/beta-v1.0.4`, HEAD `717a63b`, 프로젝트 `1.0.4-beta`다.
작업 경로는 `/Users/hwanghyeonseong/.codex/worktrees/6bca/Unfold`다.
직전 GLB 메모리 최적화와 편집기 작업을 이어서 변경했다. 기존 Supabase·브랜드 22개 파일은 이전 SHA-256과 모두 일치한다.

## 변경

- 펫 추가는 **펫 팩 열기 / 펫 팩 만들기** 두 탭만 제공한다.
- 만들기의 **파일 열기…**가 GLB·GIF·MP4·정지 이미지를 받으며 형식을 자동 전환한다.
- 파일 형식 선택은 두 편집 초안을 보존한다. 탭·사이드바 이동, 숨김에도 유지한다.
- 공통 `PetEditorWorkspace`로 넓은 창은 미리보기·행동 설정을 나란히, 좁은 창은 위아래로 배치한다.
- GIF·MP4도 선택한 행동 하나를 편집하고 일시정지·처음부터 재생을 사용한다. 한 번/반복/핑퐁 계약은 보존한다.
- GLB 행동 설명, 반복 해설, 재생 요약, 모델 통계를 제거했다. 항목명, 파일명, 상태·오류 피드백은 유지한다.
- GLB `.unfoldpet` 내보내기 후 열기 탭에서 설치할 수 있다. 기존 저장하고 적용과 저장한 GLB 편집도 유지한다.
- GLB 팩을 성공적으로 내보내거나 설치하면 같은 ID의 콘텐츠 버전을 증가시킨다. 취소·실패는 초안과 기존 목적지를 보존한다.
- 기존 GLB 몸 방향 고정·마우스 동작·렌더링 메모리 최적화는 유지한다.

## 미검증·위험

- Windows 실제 화면·물리 마우스/키보드 조작은 이번 작업에서 미검증이다.
- macOS 캡처는 네이티브 Avalonia 진단에서 생성했다. UI 이벤트는 자동으로 주입했으며 물리 입력 검증을 뜻하지 않는다.
- GLB 팩과 GIF/MP4/이미지 팩은 각 형식 계약을 사용한다. 한 팩에 GLB와 2D 파일을 혼합하는 기능은 포함하지 않는다.
- 전체 스모크의 메모리 수치는 다수의 화면·팩·테스트 데이터를 사용한 진단 프로세스 값이며 실제 GLB 펫 대기 메모리 측정이 아니다.
- 이번 변경은 개발본에만 반영했다. 커밋·설치본 교체·공개 배포는 수행하지 않았다. 실행 중인 이전 프로세스는 재시작해야 변경이 보인다.
