# 기본 펫 공 모양·매달림·바운스 — 2026-09-24

## 적용한 동작

| 대상 | 포인터 다운·유지 | 포인터 업 |
|---|---|---|
| 고슴도치 | 몸을 말아 얼굴·귀·발이 숨겨진 공 모양 유지 | 공 상태로 한 번 튕김 → 최종 착지 → 몸 펴기 |
| Mochi·보리·강아지·펭귄 | 뒷목 쪽이 들리고 몸·발·귀/날개가 아래로 처진 매달림 | 한 번 튕김 → 최종 착지 → 기본 자세 |

이동하지 않고 놓은 경우, 자세 복귀를 마친 뒤 기존 놀람·두리번보기 `click` 클립을
재생한다. 드래그 후에는 클릭 반응을 재생하지 않는다. 빠른 클릭도 유지 자세로 튕긴 뒤
복귀하도록 처리한다. 숨김·펫 변경·입력 캡처 해제는 모션과 예약된 클릭을 취소한다.
착지 중 다시 누르면 새 누름으로 전환하며 이전 클릭을 중복 재생하지 않는다.

알림 UI는 누름 중에도 표시한다. 펫 반응은 착지가 끝날 때까지 보류하고, 세션이나 알림
상태가 바뀌어 유효하지 않은 반응은 재생하지 않는다. 휴식 중 누름을 반복해도 스트레칭 후
산책으로 이어지는 기존 흐름을 보존한다.

## 자산과 코드

- 내장 `image_gen`으로 기존 펫 PNG를 참조해 5종×8자세를 생성했다.
- 생성 원본, 기존 시트, 전체 프롬프트, 해시, 패킹 과정과 내용 버전은
  [포인터 제작 원장](../../Art/Characters/pointer-interactions-v1/README.md)에 있다.
- 기존 이미지 픽셀과 10개 행동 타임라인은 **5종 모두 동일**하다. 새 포즈는 시트 하단에
  추가하고 `pickup`, `held`, `land` 3개 선택 키로 연결했다.
- 새로운 포즈의 alpha 경계와 바운스 배율을 계산해 기존 캔버스 안에 남는 것을 확인했다.
- 3개 선택 키가 없거나 로딩에 실패하면 기존 포인터 동작을 사용한다. 일반 커스텀 펫의
  5개 행동과 제작 UI는 변경하지 않는다.
- `PetWindow.PointerArt.cs`에서 누름·유지·바운스·복귀 상태를 연결한다. 이동과 스케일은
  기존 `AnimationView.RenderTransform`으로 처리하며 네이티브 창 크기를 모션 때문에 바꾸지 않는다.

- 재누름 중 보류한 스트레칭을 유지하는 검사를 추가한 뒤 전체 Release 검사
  **360 통과 / 0 실패 / 0 건너뜀**.

  자산 감사·패키지 왕복 집중 검사 **9 통과 / 0 실패**.

- 누름 유지, 바닥 접촉 후 상승 구간 1회, 복귀 전 `held` 유지, 복귀 후 기존 클릭 연결 검사.
- 드래그·숨김·재누름·알림 취소와 기존 호버 창 배치 검사.
- 5종의 새 포즈·바운스·프레임 교체에 대해 이전 실루엣이 남는지 Headless 렌더링 비교.
- 자산 감사: **5종 / 65개 클립 / 오류 0 / 경고 0**.
- 모든 실행 데이터는 새 테스트 프로필을 사용한다.

결과 파일: `artifacts/validation/2026-09-24-pointer-art/`의 `tests/`,
`character-audit.json`, `asset-preservation.json`.

## macOS 재생 진단과 한계

`--review-original-pets`에 전용 유지 자세, 첫 접촉, 바운스 정점, 최종 착지 후 복귀 검사를
추가했다. 기존 클립은 dispatcher 시간으로 재생하고, 포인터 모션 시간은 진단에서 진행한다.
실제 펫 상태에서 읽은 포즈를 동일한 `AnimationView`로 렌더링한다.

격리된 macOS 프로필에서 진단을 실행해 **5종 모두 성공**, PNG **130개**를 생성했다.
기존 50개 행동 클립의 실제 시간 재생과 새 유지·접촉·바운스·복귀 상태를 검사했다.
5종의 유지 자세와 보리·고슴도치의 바운스·복귀 캡처를 눈으로 확인했다. 고슴도치는
유지·바운스 중 얼굴과 발이 보이지 않는 공 상태이며, 착지 후에만 몸을 편다.
결과는 `native-profile/verification/original-pets.json`과 같은 폴더의 PNG에 있다.

화면 밖 렌더링과 Headless 입력은 실제 마우스 조작이나 모든 중간 프레임의 영상 검수가 아니다.
Windows 실기, 전체화면·다중 모니터에서의 포인터 입력은 미검증이다.
앱 배포 버전과 압축 배포 파일은 변경하지 않았다.
