# 소리 아이콘 구현 보고서

## 원인

미리듣기 버튼은 재생 상태를 텍스트로 표시했고 세 볼륨 슬라이더는 오른쪽에 퍼센트를 표시했다.
사용자가 제공한 SVG로 재생·중지를 구분하고 각 슬라이더 왼쪽에 음량 단계를 표시하도록 변경했다.

## 변경

- 미리듣기 버튼은 40×40px, 제공된 재생·중지 SVG는 원본 16×16px다. 재생 중에 중지 아이콘으로 전환하며 다시 누르면 현재 재생을 취소한다.
- 자연 종료·취소·다른 소리 선택·재생 실패·창 숨김에 따라 재생 아이콘으로 복원한다. 이전 재생의 늦은 종료가 새 소리의 중지 아이콘을 바꾸지 않는다.
- 세 퍼센트 텍스트를 제거하고 각각의 슬라이더 왼쪽에 원본 24×24px 음량 아이콘을 배치했다. 값 0은 음소거, 1~49는 작은 소리, 50~100은 큰 소리다. 단계는 해당 슬라이더의 값으로 표시한다.
- 세 슬라이더의 폭을 맞추고 개별 슬라이더 오른쪽에만 미리듣기를 둔다. 기본·최소 창과 좁은 카드에서 가로 넘침 없이 배치한다.
- SVG 원본은 별도 자산으로 보관하며 공통 SVG 렌더러가 현재 테마 색을 적용한다. 버튼의 툴팁과 접근성 이름은 재생 상태에 맞춘다.
- 기존 전체·개별 음량 계산, 저장·취소, 알림 효과음 사용, 파일 가져오기·기본 복원은 유지했다. 기능 설명 문구를 추가하지 않았다.

## 미검증·위험

- 실제 OS의 마우스 입력, 사람의 청취 확인, Windows 실기 동작은 이번 작업에서 미검증이다. 화면 밖 진단과 프로그램 방식의 버튼 이벤트는 실제 입력 검증을 대신하지 않는다.
