# 색상 테마 구현·검증

2026-09-20 · 현재 C# / .NET 10 / Avalonia 12.1.2 · `release/mvp`

## 적용 결과

- 사이드바 종료 버튼 바로 위에 46×46px 팔레트 아이콘을 추가했다. 같은 창에서 선택 메뉴가 열린다.
- **오트 라떼(기본), 세이지, 미드나이트 블루, 플럼** 네 가지 테마를 제공한다. 색상 표본과 체크 표시로 현재 선택을 구분한다.
- 선택 즉시 홈·설정·기록·펫 추가·공통 대화상자·기존 펫 말풍선의 공통 색에 반영한다. OS가 그리는 파일 선택기·트레이 등은 운영체제 표현을 따른다.
- 설정 파일에 선택을 저장하고 다음 실행 때 복원한다. 테마가 없는 기존 설정이나 알 수 없는 숫자 ID는 오트 라떼로 읽으며 다른 설정은 보존한다.
- 페이지·컨트롤을 다시 만들지 않는다. 설정/홈 시간/펫 초안, 현재 탭, 타이머·휴식 상태를 유지한다. 테마 선택은 설정 탭의 저장·취소와 독립적이다.
- 저장 실패 시 기존 색과 설정을 유지하고 메뉴에서 다시 선택할 수 있다.
- 글자용 `Cream`과 버튼·선택 강조용 `Accent`를 분리했다. 진행 상태는 `Success` 색을 사용한다.
- 펫 미리보기의 첫 배경 선택은 현재 테마를 따르므로 명칭을 ‘테마 배경’으로 변경했다. 별도의 ‘밝은 배경’은 고정된 밝은 표면·어두운 안내 글자를 사용한다.

말풍선의 제목·여백·버튼 배치 개편은 포함하지 않았다. 기존 UI 구조에 테마 색만 반영했다.

## 검증 한계

네이티브 진단은 코드로 메뉴·버튼 이벤트를 실행하고 off-screen 창을 렌더링한다.
사용자가 실제 마우스로 macOS 메뉴를 선택하는 과정, Windows 실기기, DPI/다중 모니터,
OS 제목 표시줄·파일 선택기 색상까지 검증한 결과는 아니다.
일반 사용자 데이터, 배포 파일, Figma 원본은 변경하지 않았다.
