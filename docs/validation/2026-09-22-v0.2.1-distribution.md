# v0.2.1 배포 검증

2026-09-22 · `release/mvp` · 소스 기준 `a0dead4` · macOS arm64 빌드 호스트.
이번 작업에서 패키징 스크립트, 설치 안내와 패치노트를 추가·수정했다.

## 포함 내용

- 앱 버전은 `Unfold.Desktop.csproj`의 기존 `0.2.1`을 사용한다.
- Mochi(`default-cat`), 보리(`bori-rabbit`), 강아지(`puppy-dog`), 고슴도치(`hedgehog`),
  펭귄(`penguin`)의 다섯 기본 팩을 모든 플랫폼에 포함했다. 각 팩은 확장 행동 10개를 제공한다.
- 별도 펫 파일 설치 없이 새 앱의 홈에서 선택한다. 일반 커스텀 팩의 다섯 행동 슬롯은 유지한다.
- [사용자용 패치노트](../releases/v0.2.1.md)를 Windows 포터블 폴더의 `RELEASE-NOTES.md`와
  macOS `Unfold.app/Contents/Resources/RELEASE-NOTES.md`에 포함했다.
- macOS 표시 버전은 `0.2.1`, 빌드 번호는 이전 `3`에서 `4`로 올렸다.
  표시 버전과 빌드 번호는 별개다. [Apple 빌드 번호 설명](https://developer.apple.com/help/glossary/build-string/)

패치노트의 비교 기준은 [2026-09-17 v0.2.0 배포 기록](2026-09-17-v0.2.0-distribution.md)과
그 이후의 코드·검증 문서다. `mvp-cat-v0.2.0` Git 태그는 9월 11일의 별도 역사 스냅샷이므로
이번 변경 목록의 기준으로 쓰지 않았다. 웹 목업의 예시 변경 이력도 출시 근거로 쓰지 않았다.

macOS `ditto` ZIP의 `._` AppleDouble 메타데이터는 실행 자산 목록 비교에서 제외했다.
실제 펫 이미지·manifest의 바이트 비교와 ZIP CRC 검사는 생략하지 않았다.

Windows PowerShell은 호스트에 없어 `publish-desktop.ps1`을 직접 실행하지 못했다.
같은 설정으로 `dotnet publish`한 뒤 `win-x64/Unfold.cmd`, `README.txt`, `RELEASE-NOTES.md`,
`app/Unfold.exe`와 인접 DLL·Assets·Tools·문서를 포함하는 구조로 ZIP을 만들었다.
Windows 스크립트에도 동일한 패치노트 복사 단계를 추가했다.

## 재현 명령과 증거

```sh
dotnet restore Unfold.slnx --locked-mode
dotnet test Unfold.slnx -c Release --no-restore \
  --logger 'trx;LogFileName=release.trx' --results-directory artifacts/releases/v0.2.1/tests
bash Scripts/make-macos-bundle.sh osx-arm64
bash Scripts/make-macos-bundle.sh osx-x64
dotnet run --project tools/Unfold.MediaSetup -- win-x64 .
dotnet publish src/Unfold.Desktop/Unfold.Desktop.csproj -c Release -r win-x64 \
  --self-contained true -p:PublishReadyToRun=true -p:PublishSingleFile=false \
  -o artifacts/releases/v0.2.1/win-x64/app
```

arm64 ZIP을 `artifacts/releases/v0.2.1/verify-osx-arm64/`에 풀어 실제 배포 실행 파일로
진단했다. smoke와 펫 재생에는 각각 새 `/private/tmp/Unfold-v021-smoke-1790076087408`,
`/private/tmp/Unfold-v021-pets-1790076087408` 프로필을 사용했다. 사용자의 실행 중인
개발 앱과 실제 설정·기록을 종료하거나 변경하지 않았다.

- [배포 파일·해시·구조](2026-09-22-v0.2.1-artifacts.json)
- [게시 앱 전체 진단](2026-09-22-v0.2.1-smoke.json)
- [게시 앱 기본 펫 재생](2026-09-22-v0.2.1-pets.json)
- 상세 빌드 로그와 TRX, 자동 캡처: `artifacts/releases/v0.2.1/`

smoke 결과의 캐릭터 수 8은 진단 중 생성·설치한 시험용 팩을 포함한다.
깨끗한 배포 파일의 기본 목록은 다섯 종류이며 압축 내부와 별도 자산 진단으로 확인했다.
펫 진단은 10개 행동의 재생·idle 복귀, 눌림·해제 포즈, 세 번째 미루기, stretch → walk,
완료·숨김 중단을 검사했다.

## 실제 OS와 미검증

현재 Apple Silicon Mac에서 압축 해제한 앱으로 자동 진단을 실행했다. 화면 밖 창과 코드
호출을 이용한 검사이며, 사람의 마우스·키보드 조작이나 실사용 전체 통과를 뜻하지 않는다.
새 배포본의 물리 입력, 효과음 청취, 로그인 자동실행, 다중 모니터·DPI와 장시간 사용은 미검증이다.

Intel Mac과 Windows x64에서는 빌드·자산·압축·형식을 확인했지만 실제 대상 장비에서
실행하지 않았다. Windows의 과거 자동 진단 결과를 이번 배포본의 실기 통과로 대신하지 않는다.
macOS Developer ID 서명·공증·stapling과 Windows 코드 서명은 포함하지 않았다.
설치 프로그램과 자동 업데이트는 제공하지 않는다.

## 설치

앱을 완전히 종료하고 운영체제·CPU에 맞는 ZIP을 푼다. macOS는 `Unfold.app`을 최종 위치로
옮겨 실행하고, Windows는 `win-x64/Unfold.cmd`를 실행한다. Windows의 `app` 폴더는
분리하지 않는다. 사용자 설정·기록·커스텀 펫은 기존 데이터 폴더에 유지된다.
