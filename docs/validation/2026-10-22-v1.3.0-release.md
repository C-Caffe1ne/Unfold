## 공식 웹

웹 커밋 `6fe0330e6ce1ed3e595c0a7f226b82426fd91eaf`을 `main`에 푸시해 기존 Cloudflare 자동 배포로 반영했다.
다운로드 링크·ZIP 크기·체크섬을 갱신하고, 사용자 변경 8개를 한국어·영어·일본어·중국어로 적었다.
기존 다운로드 주소 55개를 보존하고 새 주소 4개를 추가했다.
웹 검사 87개, 정적 사이트·번역 366키·비밀값·배포 dry-run, 로컬 HTTP 149개를 통과했다.
브라우저에서 네 언어의 새 변경 이력을 확인했고 콘솔 오류는 없었다.
공개 HTML·번역 파일 3개가 배포 소스와 바이트 일치하며, 새 다운로드 주소 4개와 기존 v1.2.1 주소의 302 연결을 확인했다.
