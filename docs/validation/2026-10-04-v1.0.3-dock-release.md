## 실제 macOS

- Apple Silicon 앱과 Intel 앱·각 DMG의 Developer ID 서명, Apple 공증 Accepted, stapler, Gatekeeper 배포 정책 통과.
- 앱 권한은 기존 `com.apple.security.cs.allow-jit` 하나를 유지했다. Mac bundle build number는 내부 revision을 반영한 `100000301`이다.
- 최종 서명 앱 통합 진단: ARM64와 Intel Rosetta 각각 success, PNG 99개. 새 격리 `UNFOLD_DATA_DIR`을 사용했다.
- 실제 공개 `1.0.3-beta` 서명 앱의 격리 사본에서 공식 SDK의 GitHub HTTPS 피드로 `1.0.3-beta.1`을 다운로드했다. 실제 UpdateMac helper의 앱 교체·재시작 로그, 교체 앱 버전·서명·공증 티켓과 설정·기록·커스텀 펫 sentinel 보존을 확인했다. 사용자 설치 앱과 실제 사용자 데이터를 교체하는 검사가 아니다.
- Dock 보정의 실제 창 위치 72개 사례·자동 이동 및 4K 논리 좌표 검사는 [기능 수정 검증](2026-10-04-macos-dock-placement.md)에 기록되어 있다.

## 실제 Windows와 검증 한계

- Mac에서 Windows x64를 cross-publish하고 관리 설치 EXE·ZIP·업데이트 패키지를 만들었다.
- Windows 코드 서명, 실제 Windows 설치·제거·재부팅·업데이트·네이티브 UI는 미검증이다.
- 사용자 환경인 Mac mini + 27인치 4K의 물리적 재확인은 하지 않았다. 실제 Intel Mac도 검증하지 않았으며 Intel 실행은 Rosetta다.
- 새 컴퓨터의 브라우저 다운로드부터 로그인·첫 실행까지의 전체 사용자 흐름은 확인하지 않았다.

## 작업 중 오류와 보존

- 최초 병렬 Mac 패키징이 저장 공간 부족으로 중단됐다. 이번 작업의 중복 생성물만 정리하고 빌드·패키징·공증을 다시 완료했다. 이전 공개 산출물과 사용자 데이터는 보존했다.
- 로컬 웹 서버의 중복 포트 인자를 수정한 뒤 경로 92개가 통과했다.
- 공개 HTML의 엄격한 원본 비교는 Cloudflare 분석 스크립트 주입으로 차이가 있었다. 그 한 개만 구분한 최종 검사가 통과했으며 주입 설정은 변경하지 않았다.
- 앱의 기존 다른 작업 파일 22개는 시작 시점의 해시를 유지했다. 홈페이지 원본 작업 폴더에는 동시 작업으로 수정되는 계정 관련 파일이 있었고 이번 배포 변경을 그 폴더에 적용하지 않았다.
