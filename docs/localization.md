# UI 한글화

2026-09-14 · 보리 팩 완성도 작업보다 UI 한글화를 먼저 진행한다.

현재 일반 사용자 화면은 한국어를 기본으로 표시한다. 별도 언어 선택 설정은 없다.
설정, 휴식 안내, 루틴·업무 프로필 편집과 목록, 주간 회고, 펫 팩 설치·미리보기,
트레이와 펫 메뉴, 앱이 작성하는 OS 알림 문구를 한국어로 바꿨다.
타이머 아이콘과 입력 항목의 접근성 이름, 도구 설명, 확인·취소·오류 안내도 포함한다.

| 기존 표현 | 현재 표시 |
|---|---|
| Remind me every (min) | 알림 간격 (분) |
| Pause when away (min) | 자리 비움 (분) |
| Pause / Resume / Stop timer | 타이머 일시정지 / 계속 / 정지 |
| My routines & work profiles | 루틴 · 프로필 |
| In 5 minutes / Skip this break / I'm refreshed | 5분 뒤에 / 이번 휴식 건너뛰기 / 잘 쉬었어요 |
| Review & export / Export CSV | 기록 · 내보내기 / CSV 내보내기 |
| Install / Update / Reinstall | 설치 / 업데이트 / 재설치 |
| Quit Unfold | Unfold 종료 |

기본 루틴은 ‘잠깐의 여유’ 60초, ‘눈 쉬어 주기’ 20초, ‘몸 풀어 주기’ 90초다.
횟수와 기간은 회·일·분·초로 표시하고, 주간 회고의 요일은 기기의 언어가 영어여도
한국어로 표시한다. 타이머 상태는 진행 중·일시정지·정지·자리 비움·휴식 중으로 구분한다.
알림 간격은 일시정지·정지 상태에서 1분 단위로 바꾸고 **적용**으로 저장한다.
재생/일시정지·정지 아이콘의 키보드 조작은 유지한다.

## 저장 데이터와 호환성

- 기존 사용자 루틴·프로필 이름과 안내 문구를 자동 번역하거나 바꾸지 않는다.
- 완료 기록은 당시 이름을 보존한다. 이전 영문 기록은 그대로 내보낸다.
- `small-reset`, `look-away`, `room-to-move` 등 ID, 애니메이션 키, JSON 필드,
  설치 동작의 내부 값과 `.unfoldpet` 형식은 그대로 유지한다.
- CSV 열 이름과 날짜 형식, UTF-8 BOM, 수식 방어 처리는 유지한다. 표시 구간의
  기록만 내보내는 동작도 동일하다.
- 보리 원본·런타임 이미지·0.1.0 팩의 버전과 내용은 변경하지 않는다.

알 수 없는 파일·디코더 오류는 한국어 복구 안내로 표시하고 원래 오류는 로그에 남긴다.
이전 버전 설치, 같은 버전의 다른 내용, 파일 변경 충돌 등은 해당 이유를 따로 안내한다.
미리보기 참고 사항의 `idle`, `stretch` 등은 팩 제작자가 확인할 수 있도록 키를 유지한다.

## 적용 경계와 검증

진단 전용 픽셀 에디터와 기술 로그·CLI 식별자는 일반 화면 한글화 범위에 포함하지 않는다.
파일 선택 창의 앱 제목·필터는 한국어지만 운영체제가 제공하는 공통 버튼과 메뉴는
OS 언어 설정을 따른다. `Unfold`, 펫 이름, `CSV` 같은 고유 명칭도 유지한다.

자동 테스트는 한국어 입력·Enter 저장, 아이콘 조작·접근성 이름, 영문 언어 환경의
요일 표시와 기존 기록 내보내기, 최소 크기의 배치를 검사한다.
headless 텍스트 입력은 실제 한글 IME 조합이나 스크린리더 낭독 검증을 대신하지 않는다.
실행 결과와 OS 확인 한계는 [한글화 검증 기록](validation/2026-09-14-korean-ui.md)에 기록한다.
