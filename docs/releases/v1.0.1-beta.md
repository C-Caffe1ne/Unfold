# Unfold Beta v1.0.1

2026년 10월 1일 · 테스터용 베타

## 변경 사항

- Windows 설치 마법사 EXE를 제공합니다. 현재 사용자 계정에 설치하고 시작 메뉴와 앱 제거 항목을 등록합니다. 바탕화면 바로가기는 선택할 수 있습니다.
- Apple Silicon·Intel Mac용 DMG를 제공합니다. `Unfold.app`을 함께 표시되는 `Applications` 폴더에 드래그해 설치합니다.
- Google 로그인 정보를 OS 보안 저장소에 보관하고 앱 재실행 시 자동 복원합니다. 새 빌드에서 한 번 로그인하면 이후 Google 로그인과 무료 코드 재입력 없이 계정 이용 권한을 확인합니다.
- 갱신 토큰을 즉시 교체·저장하며 로그아웃·계정 변경 시 삭제합니다. 서버 통신 실패로 저장 정보가 사라지지 않습니다.
- 자동실행의 로그인 복원이 성공하면 설정 창을 열지 않습니다.

## 설치·업데이트

앱을 완전히 종료한 뒤 설치하세요. .NET을 별도로 설치할 필요가 없습니다.

- Windows x64: `Unfold-v1.0.1-beta-win-x64-setup.exe`를 실행합니다. 설치 위치는 `%LOCALAPPDATA%\Programs\Unfold`입니다. Windows 앱 제거 또는 시작 메뉴의 제거 프로그램으로 삭제할 수 있습니다.
- Apple Silicon: `Unfold-v1.0.1-beta-osx-arm64.dmg`를 열고 앱을 Applications로 옮깁니다.
- Intel Mac: `Unfold-v1.0.1-beta-osx-x64.dmg`를 열고 앱을 Applications로 옮깁니다.

기존 로컬 설정·휴식 기록·커스텀 펫은 별도 데이터 폴더에 보관하므로 유지됩니다. Windows 앱 제거도 이 데이터를 삭제하지 않습니다. 컴퓨터 자동실행을 이미 켰다면 Windows 설치 과정에서 새 실행 경로로 갱신합니다. Mac은 앱을 최종 위치로 옮긴 뒤 설정에서 자동실행을 다시 확인하세요.

## 이용 조건·베타 상태

앱에서 Google 로그인 후 전달받은 테스터 코드를 등록합니다. 무료 이용 권한은 계정에 저장됩니다. 서버의 유효한 이용 권한 확인이 필요하며 오프라인 이용은 제공하지 않습니다. 실제 판매 결제의 운영 전환은 별도 작업입니다.

이 설치 파일은 Windows 코드 서명과 macOS Developer ID 서명·공증을 완료하지 않았습니다. 운영체제 보안 경고가 나타날 수 있습니다. 설치 파일 형식 변경이 서명·공증 완료를 의미하지 않습니다. Windows 설치·제거·재부팅과 Intel Mac의 실제 실행 검증은 별도로 확인해야 합니다.
