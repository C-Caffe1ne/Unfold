# Unfold v1.3.0

2026-10-22 · 정식 버전

- 내 펫을 검색하고 즐겨찾기로 모아볼 수 있습니다. 펫마다 설정한 크기도 기억합니다.
- 펫을 드래그하다 놓으면 움직임에 따라 날아가고 착지합니다.
- 한 행동에 여러 파일을 넣어 무작위 또는 차례대로 재생할 수 있습니다.
- 펫 이미지의 배경을 지우고 발 위치를 맞출 수 있습니다.
- 움직이는 WebP·APNG와 MOV·M4V·WebM·MKV·AVI 영상을 펫으로 가져올 수 있습니다.
- 홈의 ‘펫 관리’ 버튼에서 현재 펫을 바로 편집할 수 있습니다.
- 펫 타이머에 CPU·메모리 사용량을 색상 막대로 표시할 수 있습니다.
- 즐겨찾기 별과 스크롤바를 다듬고, 스크롤바가 나타날 때 화면이 밀리지 않게 했습니다.
