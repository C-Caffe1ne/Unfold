# Unfold v0.2.2

2026년 9월 23일

- macOS의 다른 데스크톱과 전체화면에서도 펫이 표시되도록 개선했습니다.
- 펫에 커서를 올리면 현재 시각과 다음 스트레칭까지 남은 시간을 보여 줍니다.
- 시간 말풍선이 열린 상태에서 연속 클릭할 때 창 크기가 흔들리던 문제를 수정했습니다.
- 펫 애니메이션 파일을 읽지 못해도 정지 이미지와 휴식 알림·조작을 유지합니다.
- 홈 미리보기의 파일 로딩 실패 후 복구·재시도를 개선했습니다.
- 효과음을 취소·교체한 뒤 남는 미사용 사본을 정리하며, 설정·초안·재생에서 사용하는 파일은 보존합니다.
- 손상된 일부 설정값과 실패한 애니메이션 로딩의 복구 처리를 보강했습니다.

기본 펫 5종과 기존 설정·휴식 기록·커스텀 펫을 유지합니다.
앱을 완전히 종료한 뒤 새 배포 파일로 교체하세요. .NET 별도 설치는 필요하지 않습니다.
macOS는 ad hoc 서명이며 Developer ID 공증은 포함하지 않았습니다.
Windows는 코드 서명이 없는 x64 포터블 배포본입니다.
