# Unfold Beta v1.0.0

2026년 9월 30일 · 판매용 베타 후보

## 포함된 기능

- Mochi·보리·강아지·고슴도치·펭귄 기본 펫 다섯 종을 제공합니다.
- 랜덤 행동, 클릭 반응, 누름 유지·들어 올리기·착지, 세 번째 미루기 반응과 휴식 중 이동을 제공합니다. 고슴도치는 누름 유지 시 공 모양이 됩니다.
- 펫 크기 조절, 위치 저장, macOS 전체화면·다른 데스크톱 표시와 호버 시간 말풍선을 제공합니다.
- 작업·휴식 타이머, 자리 비움 감지, 일시정지·중지, 휴식 알림·미루기·완료와 날짜별 기록·CSV 내보내기를 제공합니다.
- 설정·테마·펫 추가·기록을 한 창에서 전환하고, 라일락을 기본으로 네 테마를 선택할 수 있습니다.
- 사용자 SVG 아이콘과 눈누 기초고딕을 적용했습니다. 배포 앱에는 라일락 브랜드 아이콘을 포함합니다.
- GIF·MP4와 PNG·JPG·JPEG·WEBP·BMP 이미지로 커스텀 펫을 만들고 `.unfoldpet` 팩을 열어 설치할 수 있습니다.
- WAV·MP3 효과음과 전체·스트레칭·완료 소리 크기를 각각 조절합니다. 음량 아이콘과 재생·중지 미리듣기 버튼을 제공합니다.
- 변경된 설정의 저장·저장 안 함·취소 확인, 계정 이메일 표시·로그아웃, 로그인·구매 화면과 창 이동을 제공합니다.

## 판매용 접근 제어

무료로 내려받고 Google 로그인 후 한국 가격 4,900원 일회성 구매로 이용하는 구성입니다. 세금은 결제 시 별도이며 무료 체험은 없습니다. 해외 판매는 아직 노출하지 않습니다.

앱은 Google 로그인 후 Live 구매 권한 또는 계정별 무료 이용 권한을 확인한 뒤 홈·펫·타이머를 시작합니다. 테스터는 우측 하단의 코드 입력에서 `admin`을 등록하면 결제 없이 이용할 수 있습니다. 권한은 해당 Google 계정에 저장돼 이후 로그인 시 복원됩니다. 기존 안내 종료 기록, 창 닫기, 트레이, 자동실행으로 잠금을 우회할 수 없습니다. Test 구매는 Live 사용 권한으로 인정하지 않습니다.

로그아웃 시 타이머·알림·펫을 멈춥니다. 실행 중 5분마다 권한을 재확인하고, 만료 토큰을 갱신합니다. 권한 취소나 통신 실패가 확인되면 로그인·구매 확인 화면으로 돌아갑니다. 로컬 설정·기록·커스텀 펫은 삭제하지 않습니다.

세션은 앱 실행 중 메모리에만 보관합니다. 매 실행 시 온라인 로그인·구매 확인이 필요합니다. 자동 로그인·OS 보안 저장소·오프라인 라이선스는 포함하지 않습니다.

## 설치·업데이트

앱을 완전히 종료하고 OS·CPU에 맞는 ZIP을 풀어 교체하세요. .NET을 별도로 설치할 필요가 없습니다.

- Apple Silicon Mac: `Unfold-v1.0.0-beta-osx-arm64.zip`의 `Unfold.app`.
- Intel Mac: `Unfold-v1.0.0-beta-osx-x64.zip`의 `Unfold.app`.
- Windows x64: `Unfold-v1.0.0-beta-win-x64.zip`의 `win-x64/Unfold.cmd`. `app` 폴더를 함께 유지하세요.

기존 로컬 설정·기록·커스텀 펫은 같은 데이터 폴더에서 읽습니다. 업데이트 전에 데이터 폴더를 복사해 두면 문제 발생 시 복구할 수 있습니다.

## 판매 시작 전 남은 조건

이 후보를 만든 시점에는 운영자가 Lemon Squeezy Test 모드만 설정했습니다. 원격 공개 가격표의 `live_enabled`도 false입니다. Live 상품·API 키·웹훅 Secret과 결제 서버 코드·마이그레이션이 운영 환경에 적용되기 전에는 실제 결제를 완료할 수 없습니다. 테스터의 계정별 무료 이용은 별도로 지원합니다. 이 후보 ZIP을 판매 완료본으로 게시하지 마세요.

macOS 후보는 ad hoc 서명입니다. 공개 배포 전에 Developer ID 서명과 공증이 필요합니다. Windows 후보는 서명 없는 포터블 배포본입니다. 실제 OS 설치·실결제·권한 복구·환불과 Intel Mac·Windows 실기 검증은 별도로 완료해야 합니다. 자동 업데이트는 포함하지 않습니다.

설정 순서는 저장소의 `docs/releases/beta-v1.0.0-launch.md`, 검사 결과는 `docs/validation/2026-09-30-beta-v1.0.0.md`에서 확인합니다.
