# Unfold Beta v1.1.3

2026년 10월 12일 · 내부 버전 `1.1.3-beta`.

## 변경내용

- 3D 펫 미리보기에서 방향을 조절하고 행동별로 저장합니다.
- 펫 옆 타이머에서 시작·일시정지·중지를 조작합니다.
- 말풍선 전환 시 펫의 표시 영역이 흔들리지 않도록 개선했습니다.
- 타이머를 즉시 중지하고 시간 변경을 자동 저장합니다.
- 클릭과 걷기 동작이 끝나면 기본 동작으로 돌아옵니다.
- 홈 미리보기를 유지하고 각 탭의 이름을 표시합니다.

## 웹사이트·결제

- Lemon Squeezy Live 결제를 연결하고 한국 구매 가격을 **부가세 포함 4,900원, 한 번 구매**로 안내합니다.
- 결제 모달과 가격 카드를 단순하게 정리했습니다. 핵심 기능 네 가지와 구매 버튼을 함께 배치하고 ‘이용 권한 다시 확인’ 버튼을 제거했습니다.

## 내부 관리

- 운영 데이터 조회에 계정별 접근 제한을 적용하고, 새 테이블·함수의 기본 공개 권한을 제한했습니다. 기존 초대 코드는 유지합니다.
- 웹 보안 헤더와 공개 파일의 비밀값 검사를 추가했습니다. 폐기한 편집·팩 미리보기 코드를 정리했습니다.

미리보기 회전의 끊김 개선은 후속 작업입니다. Google 로그인 브랜딩 설정은 사용자 요청으로 보류했습니다.
