# Unfold Beta v1.1.3

2026년 10월 12일 · 내부 버전 `1.1.3-beta`.

## 변경내용

- **3D 펫 미리보기 회전**: 드래그로 X·Y축, Shift+드래그로 Z축을 회전할 수 있습니다. 방향 키·각도 입력·초기화도 지원합니다.
- **미리보기 방향 적용**: 별도의 ‘바라보는 방향’ 설정을 제거하고 미리보기에서 정한 방향을 행동별로 저장합니다. 저장 후 다시 선택하거나 팩을 다시 열어도 유지합니다.
- **탭 이름 표시**: 내비게이션 아이콘 아래에 홈·펫 관리·기록·테마·설정·종료 이름을 표시합니다.
- **펫 호버 반응 제거**: 모든 펫의 호버 상태·모션·시간 말풍선을 제거했습니다. 포인터를 올려도 스트레칭과 걷기가 계속됩니다. 투명 배경은 뒤쪽 창으로 클릭을 통과시킵니다.
- **모션 종료 후 복귀 수정**: 한 번 걷기의 기본 대기 복귀, 클릭 모션이 없는 펫의 복귀, 새 모션을 읽는 중 이전 모션이 끝나는 경우를 수정했습니다.
- **펫 옆 타이머 조작**: 펫 옆에서 시작·일시정지·계속·중지를 할 수 있습니다. 설정에서 조작 바를 숨길 수 있습니다.
- **펫과 말풍선 표시 개선**: 말풍선과 타이머 조작 바를 별도 창으로 표시해 알림이 바뀔 때 펫의 표시 영역이 움직이지 않도록 했습니다.
- **즉시 중지와 숫자 전환**: 확인 창 없이 타이머를 중지합니다. 설정 시간으로 복귀하거나 알림 간격을 늘리고 줄일 때 숫자가 부드럽게 전환됩니다.
- **홈 시간 자동 저장**: 저장 버튼을 제거했습니다. 실행 중에도 알림 간격을 조정할 수 있으며, 유효한 시간 변경은 바로 적용·저장됩니다.
- **홈 펫 미리보기 유지**: 홈과 펫 편집의 미리보기는 유지하며, 팩을 설치할 때 별도로 열리던 재생 미리보기 창을 제거했습니다.

## 웹사이트·결제

- Lemon Squeezy Live 결제를 연결하고 한국 구매 가격을 **부가세 포함 4,900원, 한 번 구매**로 안내합니다.
- 결제 모달과 가격 카드를 단순하게 정리했습니다. 핵심 기능 네 가지와 구매 버튼을 함께 배치하고 ‘이용 권한 다시 확인’ 버튼을 제거했습니다.

## 내부 관리

- 운영 데이터 조회에 계정별 접근 제한을 적용하고, 새 테이블·함수의 기본 공개 권한을 제한했습니다. 기존 초대 코드는 유지합니다.
- 웹 보안 헤더와 공개 파일의 비밀값 검사를 추가했습니다. 폐기한 편집·팩 미리보기 코드를 정리했습니다.

미리보기 회전의 끊김 개선은 후속 작업입니다. Google 로그인 브랜딩 설정은 사용자 요청으로 보류했습니다.
