# Unfold Beta v1.0.2

2026년 10월 1일

## 변경 사항

- macOS 메뉴 막대와 Windows 트레이 아이콘을 Unfold 브랜드 아이콘으로 교체했습니다.
- 첫 로그인·결제 화면의 좌측 상단에 브랜드 로고를 배치했습니다. 어두운 테마에서는 밝은 로고로 전환됩니다.
- 왼쪽 패널의 문구를 제거하고 Mochi만 중앙에 표시합니다.
- 결제 화면에서 가격·통화 드롭다운을 제거했습니다. 국내 가격은 기존과 동일하게 표시합니다.
- Mac 공증 배포 파일에는 Developer ID 서명과 Apple 공증 티켓을 포함합니다. 앱 기능과 버전은 동일합니다.

## 설치·업데이트

앱을 완전히 종료한 뒤 새 설치 파일을 사용하세요. .NET을 별도로 설치할 필요가 없습니다.

- Windows x64: 설치 ZIP의 압축을 풀고 `Unfold-v1.0.2-beta-win-x64-setup.exe`를 실행합니다. 현재 사용자 계정의 `%LOCALAPPDATA%\Programs\Unfold`에 설치됩니다.
- Apple Silicon: 설치 ZIP의 압축을 풀고 `Unfold-v1.0.2-beta-osx-arm64.dmg`를 엽니다. 앱을 Applications로 옮깁니다.
- Intel Mac: 설치 ZIP의 압축을 풀고 `Unfold-v1.0.2-beta-osx-x64.dmg`를 엽니다. 앱을 Applications로 옮깁니다.

Mac은 파일명이 `-notarized-installer.zip`으로 끝나는 공증 배포 파일을 선택하세요.
기존 `-installer.zip` Mac 파일은 공증 이전 파일로 보존합니다.

기존 설정·휴식 기록·커스텀 펫과 OS 보안 저장소의 로그인 정보는 유지됩니다. 로그인 복원 후에는 서버에서 계정의 이용 권한을 다시 확인합니다. 새 사용자에게는 Google 로그인과 유효한 구매 또는 무료 이용 코드가 필요합니다.

## 베타 상태

Mac 공증 배포 파일은 앱과 DMG에 공증 티켓을 첨부합니다. macOS의 일반적인 첫 실행 확인창은 표시될 수 있습니다.
Windows 설치 파일은 기존 배포물을 유지하며 코드 서명은 미완료입니다. Windows의 실제 설치·제거·재부팅과 Intel Mac에서의 실제 실행은 별도 검증이 필요합니다. 실제 판매 결제의 운영 전환은 별도 작업입니다.
