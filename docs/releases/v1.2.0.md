# Unfold v1.2.0

2026-10-15 · 정식 버전

## 달라진 점

- 한국어·영어·일본어·중국어를 지원합니다. 첫 로그인 화면에서 언어를 고르고, 설정에서도 바로 바꿀 수 있습니다.
- GLB 펫에 요소별 외곽선을 자동으로 적용합니다. 두께는 내부 고정값 1%로, 메시·재질 사이의 경계를 얇게 보여 줍니다.
- 말풍선 본체와 꼬리가 만나는 부분의 겹친 테두리를 제거했습니다. 투명도를 낮춰도 접합선이 생기지 않습니다.
- 휴식 타이머에서 바뀐 숫자가 부드럽게 전환됩니다.
- 구매 가격을 US$2.99 일회성 결제로 맞췄습니다.

## 설치와 업데이트

Windows x64, Apple Silicon Mac, Intel Mac 설치 파일을 제공합니다.
Mac 앱과 DMG는 Developer ID 서명과 Apple 공증을 거쳐 배포합니다.
기존 베타의 앱 내 업데이트에서도 v1.2.0을 받을 수 있습니다. 업데이트 후에는 정식 버전 업데이트를 확인합니다.
설정·휴식 기록·커스텀 펫은 기존 데이터 폴더를 사용합니다.

## 배포 정비

정식 버전 번호·설치 안내·업데이트 채널을 적용하고, 기존 베타에서 정식 버전으로 전환하는 호환 피드를 추가했습니다.
