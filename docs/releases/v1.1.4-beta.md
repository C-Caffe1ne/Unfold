# Unfold beta_v1.1.4

2026년 10월 14일 · 내부 버전 `1.1.4-beta`.
`v1.1.3-beta` 이후의 변경을 포함합니다.

## 핵심 변경

- 3D 펫 미리보기를 확대하고 회전·행동 설정을 정리했습니다.
- 펫 아래에서 현재 시간과 타이머를 확인하고 조작할 수 있습니다.
- 말풍선과 타이머 조작을 분리해 펫 표시 안정성을 개선했습니다.
- 들기·알림·스트레칭 행동을 유지하고 완료 애니메이션을 끝까지 재생합니다.
- 홈에서 펫 표시와 관리를 조작하고 타이머 중지 상태에서 시간을 설정할 수 있습니다.
- 업데이트 창에 핵심 변경만 짧게 표시합니다.

## 상세 변경

### 3D 펫 편집

- 미리보기를 전체 폭으로 확대하고 창 크기에 맞춰 높이와 펫 표시 크기를 조절합니다.
- 미리보기 안에서 좌우·상하 회전 화살표와 초기화를 사용합니다. 각도 입력·Z축 조작을 제거했습니다.
- 미리보기에서 정한 방향과 행동별 애니메이션·속도·재생 설정을 저장합니다.
- 별도 ‘드래그 중’ 연결을 제거하고 들어 올리기·놓기 설정으로 처리합니다.

### 펫과 타이머

- 타이머 조작 바를 펫 아래에 배치하고 현재 시간을 `오전/오후 hh:mm`으로 표시합니다.
- 펫 또는 타이머에 커서를 유지하면 표시하고, 영역을 벗어나면 바로 페이드 아웃합니다.
- 펫 클릭·들기 때는 타이머를 즉시 숨깁니다. 알림 말풍선은 실제 펫 몸체 가까이에 배치합니다.
- 펫·말풍선·타이머의 별도 창을 유지해 버튼 조작과 좌우 전환이 펫 캔버스를 변경하지 않게 합니다.
- 들어 올리기는 누르는 동안 반복하거나 끝 자세를 유지합니다. 클릭·놓기·하품·잠자기는 전체 재생 후 복귀합니다.
- 휴식 알림은 버튼 선택·자동 미루기까지, 스트레칭은 완료·중지까지 반복하거나 끝 자세를 유지합니다.
- 완료 말풍선이 사라져도 완료 애니메이션은 전체 재생 후 기본 동작으로 돌아갑니다.

### 홈과 업데이트

- 펫 선택 오른쪽에 ‘화면에 펫 표시’를 배치하고 펫 카드 우측 상단에 펫 관리 아이콘을 추가했습니다.
- 홈의 알림 간격·휴식 시간은 중지 상태에서만 조절하고 자동 저장합니다. 일시정지 중에는 입력이 잠깁니다.
- 자동 저장 전에 타이머를 시작하면 미적용 입력을 저장값으로 복원합니다.
- 업데이트 모달은 핵심 변경을 최대 6개 짧은 항목으로 표시합니다.

## 검증 범위

- 이번 홈 시간·업데이트 노트 변경의 집중 검사 32개가 통과했습니다.
- 펫 재생·GLB 편집의 이전 자동 검사와 macOS 관찰 기록은 해당 검증 문서에 보관했습니다.
- 이번 릴리스는 변경 항목 검사와 빌드·패키징·서명·공증·파일 확인을 수행합니다.
- 사용자 요청에 따라 전체 테스트·새 앱 OS 진단·설치와 업데이트 재시작 진단은 실행하지 않습니다.

## 별도 운영 변경
