# Unfold v0.2.1 패치노트

2026년 9월 22일

기본 펫 5종과 새로운 상호작용을 추가하고, 화면 구성과 휴식 알림을 다듬었습니다.

## 새로운 펫과 상호작용

- **Mochi(고양이), 보리(토끼), 강아지, 고슴도치, 펭귄**을 기본 제공해 별도 설치 없이 선택할 수 있습니다.
- Mochi와 보리를 따뜻한 선과 간결한 표정의 새 디자인으로 바꿨습니다.
- 기본 펫에 잠자기·두리번거리기·하품 등 무작위 대기 행동을 추가했습니다.
- 펫을 누르면 살짝 눌리고, 놓으면 튀어오른 뒤 놀라서 주변을 둘러봅니다.
- 스트레칭을 연속 세 번 미루면 펫이 삐진 표정을 짓습니다.
- 휴식을 시작하면 펫이 스트레칭한 뒤 화면 안을 걸어 다닙니다. 휴식 완료·중지 시 이동을 멈춥니다.
- 홈에서 펫 크기를 50~150%로 조절할 수 있으며, 미리보기에도 크기 변경을 반영합니다.

## 화면과 사용성 개선

- 홈·펫 추가·기록·설정을 같은 창의 탭으로 정리하고, 콘텐츠 배치와 간격을 통일했습니다.
- 홈에 타이머와 시간 설정을 먼저 배치하고, 아래에서 펫을 미리 보고 선택하도록 바꿨습니다.
- 설정을 알림 설정·타이머 설정·앱 동작으로 구분했습니다. 변경한 내용은 하단의 **취소·저장**으로 처리합니다.
- 사용하지 않는 루틴·프로필 설정 UI를 제거했습니다. 기존 기록과 저장 데이터는 유지합니다.
- **다정한 오트·숨 고르는 숲·밤의 버터·유연한 라일락** 네 가지 테마를 추가했습니다. 기본 테마는 다정한 오트입니다.
- 최소 640×560 창을 지원하고, 좁은 창에서는 홈을 한 열로 배치해 가로 스크롤을 줄였습니다.
- 펫 팩 만들기에서 행동별 파일 카드를 눌러 미리볼 수 있습니다. 긴 파일명으로 카드 크기가 변하지 않도록 정리했습니다.
- 펫 팩 열기의 파일 선택·동작 선택·크기·재생 버튼 배치를 정돈하고, 저장 성공 후 입력 상태를 초기화합니다.
- 날짜별 기록에서 휴식 완료 시각과 실제 휴식 시간을 보여 주고, 날짜를 누를 때의 축소 모션을 제거했습니다.
- 입력 필드의 숫자 정렬, 테두리·모서리, 불필요한 설명 문구와 클릭 효과를 정리했습니다.

## 타이머와 알림 개선

- 타이머를 중지해도 `00:00` 대신 설정한 전체 시간이 표시됩니다.
- 홈의 시간 설정은 변경이 있을 때 **저장** 버튼이 나타납니다. 진행 중에는 스트레칭 간격을 바꿀 수 없습니다.
- 타이머 중지와 앱 종료에 확인 창을 추가하고, 제목표시줄 없는 앱 디자인으로 통일했습니다.
- 말풍선의 본문 설명을 줄이고 제목·타이머·버튼을 중앙 정렬했습니다. 말풍선 꼬리의 테두리 연결도 다듬었습니다.
- 사전 안내와 완료 말풍선은 5초 뒤 사라집니다. 휴식 시작 선택지와 진행 중 타이머는 유지됩니다.
- 알림 음량을 0~100%로 조절하고 미리 들을 수 있습니다.
- 5분 간격을 사용할 때 불필요한 사전 알림이 나오지 않도록 수정했습니다.
- 펫 우클릭 메뉴에 **펫 숨기기**를 추가했습니다. 숨겨도 진행 중인 휴식은 유지됩니다.
- 설정에 스트레칭 알림과 휴식 상태를 바로 확인할 수 있는 디버그 미리보기를 추가했습니다.

## 오류 수정과 안정성

- macOS에서 펫을 클릭하는 동안 이전 모습이 겹쳐 보이던 잔상 문제를 수정했습니다.
- 확인 창이 나타날 때 발생하던 작은 바운스·이동 모션을 제거했습니다.
- 일부 설정값이 잘못 저장되어도 정상인 설정은 유지하고, 문제가 있는 값만 기본값으로 복구하도록 개선했습니다.
- 펫 파일의 투명도·프레임 경계·재생 종료와 패키지 저장·설치 검사를 보강했습니다.

## 업데이트 안내

- macOS Apple Silicon·Intel, Windows x64용 파일을 제공합니다. .NET을 별도로 설치할 필요가 없습니다.
- 앱을 완전히 종료한 뒤 새 파일로 교체하세요. 사용자 설정·휴식 기록·커스텀 펫은 별도 데이터 폴더에 보관됩니다.
- 일반 GIF·MP4 커스텀 펫은 기존 다섯 행동 슬롯을 유지합니다. 확장 상호작용은 기본 펫에 적용됩니다.
- 자동 업데이트는 지원하지 않습니다. macOS는 ad hoc 서명이며 Developer ID 공증은 포함하지 않았고, Windows는 코드 서명이 없는 포터블 배포본입니다.
