# Unfold Beta v1.0.3

- macOS 메뉴 막대·Windows 트레이의 **업데이트 확인**에서 새 버전을 확인하고 앱 안에서 다운로드할 수 있습니다.
- 다운로드가 끝나면 **재시작하여 적용**을 선택합니다. 진행 중인 휴식과 저장하지 않은 펫 작업을 마친 뒤 적용합니다.
- 설정·휴식 기록·커스텀 펫·로그인 정보는 기존 사용자 데이터 위치를 유지합니다.
- 이전 Beta는 이번 업데이트 기능이 포함된 설치본을 한 번 직접 설치해야 합니다. 실행 중인 이전 Unfold를 트레이·메뉴 막대에서 완전히 종료한 뒤 설치하세요.
- Windows의 새 관리 설치 위치는 `%LOCALAPPDATA%\DokhuStudio.Unfold.Updates`입니다. 이전 NSIS 설치본의 제거 항목과 분리하며, 기존 자동 실행을 켠 경우에만 새 실행 경로로 연결합니다. 새 앱을 확인한 뒤 이전 설치본은 별도로 제거할 수 있습니다.
- macOS는 기존 `app.unfold.desktop` 번들 식별자를 유지합니다. 현재 앱을 교체하는 방식으로 설치합니다.

이번 변경에는 앞서 수정한 펫 추가, 타이머 상태·애니메이션, 창 버튼·외곽 라운딩과 설정 즉시 적용도 포함됩니다.

업데이트 릴리스에는 OS·CPU별 `releases.<runtime>-beta.json`과 대응하는 `.nupkg`가 함께 게시되어야 합니다. 로컬 패키지 생성은 공개 게시 완료를 의미하지 않습니다.
