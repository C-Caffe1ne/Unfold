# Unfold Beta v1.1.2

2026년 10월 8일 · 내부 버전 `1.1.2-beta`

## 변경내용

- **시작 시 업데이트 안내**: 새 버전이 있으면 로그인 복원이 끝난 뒤 변경내용과 업데이트 버튼을 모달로 안내합니다. 백그라운드 자동 실행에서는 앱 화면을 열 때 안내합니다. 다운로드와 재시작은 직접 선택할 수 있습니다.
- **설치한 펫 편집·삭제**: 3D·이미지·영상·스프라이트 커스텀 펫을 펫 관리에서 편집하거나 삭제할 수 있습니다. 기본 제공 펫은 유지됩니다.
- **소리 크기 표시**: 소리 설정 슬라이더에 현재 크기를 %로 표시합니다.
- **OGG 소리 지원**: WAV·MP3에 더해 OGG Vorbis·Opus 파일을 알림 소리로 사용할 수 있습니다.
- **미리듣기 개선**: 소리 미리듣기가 끝부분에서 잘리는 현상과 재생 중 볼륨을 바꿀 때 중단되는 현상을 개선했습니다. 변경한 볼륨은 다음 미리듣기부터 적용됩니다.
- **테마 색상 일관성**: 툴팁·입력 안내·아이콘·체크박스 등 일부 요소가 현재 테마와 다른 색으로 표시되는 문제를 수정했습니다.
- **사용하지 않는 파일 정리**: Piskel·업무 프로필·내 휴식 만들기의 남은 파일과 문서를 정리했습니다. 기존 설정·기록·펫 데이터 호환은 유지합니다.

## 설치 및 업데이트

- 앱 메뉴나 설정의 **업데이트 확인**에서 다운로드한 뒤 **재시작하여 적용**을 선택하세요. 업데이트를 지원하지 않는 설치본은 새 설치 파일을 직접 설치하세요.
- Mac은 Apple Silicon 또는 Intel에 맞는 `-notarized-installer.zip`을 사용하세요. 압축을 풀고 DMG 안의 앱을 Applications로 옮깁니다.
- Windows x64는 `-win-x64-installer.zip`의 설치 프로그램을 실행하세요.
- 직접 교체할 때는 이전 앱을 완전히 종료하세요. 설정·휴식 기록·커스텀 펫·계정 정보는 기존 데이터 위치를 유지합니다.
