# Unfold Beta_v1.1.0

2026년 10월 5일 · 내부 버전 `1.1.0-beta`

## 핵심 변경

- **OS 기본 창 버튼**: macOS는 기본 신호등 버튼, Windows는 기본 제목표시줄의 창 버튼을 사용합니다. 창을 닫아도 타이머는 트레이에서 유지됩니다.
- **펫 관리 통합**: 한 화면에서 GLB·GIF·MP4·이미지·기존 펫 팩을 열고, 행동별 파일과 방향·반복 재생을 설정할 수 있습니다. 유효한 이전 버전 펫 팩도 다시 적용할 수 있습니다.
- **펫 반응 안정화**: 마우스를 올리거나 클릭할 때 펫이 튀거나 변형되던 효과를 정리하고, 투명한 영역의 클릭 처리와 GLB 렌더링·메모리 사용을 개선했습니다.
- **타이머와 알림 개선**: 알림 간격을 최소 1분부터 설정할 수 있습니다. 응답하지 않은 휴식 안내는 30초 뒤 설정된 시간만큼 자동으로 미룹니다. 말풍선 시간 표시와 화면 전환도 다듬었습니다.
- **업데이트 접근 개선**: 사이드바에 현재 버전을 표시하고 설정에서도 업데이트를 확인할 수 있습니다.

## 설치 및 업데이트

- Beta v1.0.3 이상은 앱의 **업데이트 확인**에서 새 버전을 받을 수 있습니다. v1.0.2 이하는 새 설치 파일로 직접 설치하세요.
- Mac은 Apple Silicon 또는 Intel에 맞는 `-notarized-installer.zip`을 사용하세요. 압축을 풀고 DMG 안의 앱을 Applications로 옮깁니다.
- Windows x64는 `-win-x64-installer.zip`의 설치 프로그램을 실행하세요. Windows 코드 서명은 아직 제공하지 않습니다.
- 직접 교체할 때는 이전 앱을 완전히 종료하세요. 기존 설정·휴식 기록·커스텀 펫·로그인 정보는 기존 데이터 위치를 유지합니다.

## 베타 검증 범위

자동 회귀 검사와 macOS 통합 진단을 수행했습니다. macOS 네이티브 버튼의 실제 호버·드래그·전체 화면 입력과 Windows 실기 설치·실행·스냅·배율 검증은 남아 있습니다. Windows 빌드 성공을 실기 검증 완료로 표시하지 않습니다.
