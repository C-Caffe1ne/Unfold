# Unfold v1.2.1

2026-10-20 · 정식 버전

## 달라진 점

- Mac에서 창의 닫기·최소화·확대 버튼이 다른 Mac 앱과 같은 크기와 위치로 표시됩니다. 로그인 창과 업데이트 창에도 같은 버튼이 생겼습니다.
- Windows 11에서 창 제목 표시줄이 앱 테마 색으로 이어지고, 제목 글자와 아이콘이 표시되지 않습니다.
- GIF·사진으로 만든 새 펫을 바로 저장하고 적용할 수 있습니다. 펫 팩을 내보낼 때 펫 이름이 기본 파일 이름으로 제안됩니다.
- Google 로그인을 마치면 브라우저에 Unfold 안내 화면이 표시됩니다.
- Windows에서 펫·말풍선·타이머가 다른 창 뒤로 가려지지 않도록 항상 위에 유지합니다.
- 모니터를 연결·분리하거나 배치를 바꾸면 펫이 보이는 화면 안으로 돌아옵니다.
- 시스템의 동작 줄이기를 켜면 타이머 숫자가 움직임 없이 바뀝니다.
- 홈 창의 최소 크기를 넓혀 큰 펫도 잘리지 않고 보입니다.
- Windows를 로그아웃하거나 종료할 때 Unfold가 확인 창 없이 정상 종료됩니다.

## 설치와 업데이트

Windows x64, Apple Silicon Mac, Intel Mac 설치 파일을 제공합니다.
Mac 앱과 DMG는 Developer ID 서명과 Apple 공증을 거쳐 배포합니다.
v1.2.0과 기존 베타의 앱 내 업데이트에서 v1.2.1을 받을 수 있습니다.
설정·휴식 기록·커스텀 펫은 기존 데이터 폴더를 그대로 사용합니다.
