# Unfold Beta v1.0.4

내부 버전: `1.0.4-beta` · 업데이트 채널: Beta

## 변경 사항

- **GLB 펫 추가**: 펫 추가 화면에서 GLB 파일을 가져오고 미리 본 뒤 사용자 펫으로 저장할 수 있습니다.
- **상황별 행동 지정**: 기본, 마우스 올리기, 클릭, 잡기, 들고 있기, 내려놓기, 알림, 스트레칭, 축하, 걷기, 잠자기, 둘러보기, 하품, 삐짐에 애니메이션과 반복·속도를 지정할 수 있습니다. 저장한 펫을 다시 열어 수정할 수 있습니다.
- **몸 회전 고정**: 캐릭터의 기준 방향을 유지하면서 기존 마우스 반응과 펫 창 드래그를 사용할 수 있습니다.
- **확대 화질 개선**: 표시 크기와 화면 배율에 맞춰 GLB를 다시 렌더링하고 가장자리를 부드럽게 처리합니다. 정지한 애니메이션도 크기 변경 시 선명도를 갱신합니다.
- 최신 Beta의 Dock 주변 위치 보정, 설정 화면, 계정 연결과 앱 내 업데이트 흐름을 유지합니다.

## 설치 및 업데이트

- Mac: 기기에 맞는 `osx-arm64`(Apple Silicon) 또는 `osx-x64`(Intel)의 `-notarized-installer.zip`을 풀고 DMG 안의 앱을 Applications 폴더로 복사합니다. 공개 Mac 설치본은 Developer ID 서명과 Apple 공증을 사용합니다.
- Windows: `win-x64-installer.zip`을 풀고 설치 프로그램을 실행합니다. Windows 설치본에는 아직 코드 서명이 없습니다.
- Beta v1.0.3 이상에서 메뉴 막대·트레이의 **업데이트 확인**을 사용할 수 있습니다. v1.0.2 이하에서는 새 설치본을 한 번 직접 설치해야 합니다.
- 직접 설치로 교체할 때는 실행 중인 Unfold를 종료하세요. 기존 설정·휴식 기록·사용자 펫은 별도 데이터 폴더에 보존됩니다.

## GLB 지원 범위

현재 GLB 2.0의 내장 PNG 텍스처, 스켈레톤·모프 애니메이션을 지원합니다. 외부 파일 참조, JPEG 텍스처, 압축 메시 및 일부 재질은 지원하지 않으며 가져오기 시 안내합니다. 파일은 최대 32 MiB, 메시 합계는 최대 100,000 삼각형입니다. 고해상도 출력은 최대 1024픽셀이며 원본 텍스처의 세부 묘사에는 한계가 있습니다.

예시로 검증한 사용자 GLB 파일은 설치본에 포함하지 않습니다. 자세한 형식과 동작은 [GLB 펫 안내](../glb-pets.md)를 참고하세요.
