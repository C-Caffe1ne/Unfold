# Unfold Beta_v1.1.1

2026년 10월 7일 · 내부 버전 `1.1.1-beta`

## 핵심 변경

- **로그인 상태 유지**: 앱을 다시 실행할 때 저장된 계정 세션을 먼저 복원해 로그인 화면이 잠깐 나타나는 현상을 개선했습니다. 일시적인 네트워크 오류로 저장된 세션을 지우지 않습니다.
- **사용하지 않는 화면 정리**: 루틴·업무 프로필 설정과 픽셀 에디터 진입 화면을 제거했습니다. 기존 설정·휴식 기록·펫 데이터와 이전 루틴 실행 호환은 유지합니다.
- **애니메이션 메모리 개선**: 2D·GIF 프레임 공유, 재사용 가능한 화면 버퍼, 제한된 프레임 캐시로 중복 할당을 줄였습니다. 펫 팩과 GLB 파일 검사도 스트리밍 방식으로 처리합니다.

## 설치 및 업데이트

- Beta v1.0.3 이상은 앱 메뉴 또는 설정의 **업데이트 확인**에서 다운로드한 뒤 **재시작하여 적용**을 선택하세요. v1.0.2 이하는 새 설치 파일을 직접 설치하세요.
- Mac은 Apple Silicon 또는 Intel에 맞는 `-notarized-installer.zip`을 사용하세요. 압축을 풀고 DMG 안의 앱을 Applications로 옮깁니다.
- Windows x64는 `-win-x64-installer.zip`의 설치 프로그램을 실행하세요. Windows 코드 서명은 아직 제공하지 않습니다.
- 직접 교체할 때는 이전 앱을 완전히 종료하세요. 기존 설정·휴식 기록·커스텀 펫·계정 정보는 기존 데이터 위치를 유지합니다.

## 베타 검증 범위

메모리 절감은 적용했지만 모든 환경에서 400 MB 이하를 보장하지 않습니다. Retina 2배율의 짧은 실행 검사에서 대표 구성 447.07 MB, GIF 구성 406.93 MB가 측정됐습니다. 장시간 실행과 실제 Windows 사용자 입력·배율별 검증은 남아 있습니다. 배포와 업데이트 검증 결과는 별도 릴리스 검증 기록에 정리합니다.
