# Unfold 출시 콘텐츠 초안

작성: 2026-10-06. Content Creator 담당 산출물. 공개 게시 전 검토용이다.
근거: 최신 개발 worktree의 `docs/mvp.md`, `docs/glb-pets.md`, `src/Unfold.Desktop/AppRuntime.Account.cs`. 현재 로컬 구현과 공개 배포 버전의 차이는 게시 직전에 다시 확인한다.

## 메시지와 대상

핵심 문장: **Mochi와 잠깐 쉬고, 내 리듬으로 돌아오는 작은 데스크톱 동료.**
대상: 컴퓨터 앞에서 작업하다 쉬는 시간을 놓치는 사람. 실제 휴식 실천률이나 건강 효과는 아직 측정하지 않았으므로 효능·생산성 수치로 홍보하지 않는다.
콘텐츠 축: 휴식 초대 → 내 페이스로 시작·미루기 → 펫 선택과 직접 만들기 → 실제 기록 확인.

## 30초 데모 대본

| 시간 | 화면 | 내레이션·자막 |
|---|---|---|
| 0–4초 | 작업 화면 옆 Mochi | “작업에 몰입하다 보면, 쉬는 시간을 놓치곤 하죠.” |
| 4–9초 | 홈에서 작업 간격·휴식 시간 설정 후 저장 | “Unfold에서 내 작업 간격과 휴식 시간을 정해 보세요.” |
| 9–14초 | 자동 휴식 초대 말풍선 | “시간이 되면 작은 동료가 휴식을 초대해요.” |
| 14–20초 | 휴식 시작 → 펫 스트레칭 → 카운트다운 | “지금 잠깐 쉬거나, 조금 뒤로 미룰 수 있어요.” |
| 20–25초 | 완료 클릭 → 돌아보기 화면 | “완료한 휴식은 돌아보기에서 확인하세요.” |
| 25–30초 | 다섯 기본 펫과 제품 이름 | “Mochi와 잠깐 쉬고, 내 리듬으로 돌아오는 작은 데스크톱 동료. Unfold.” |

촬영 조건: 확인된 게시본, 격리 데이터, 개인정보 없는 화면. 알림 시간을 편집으로 압축하면 “시연을 위해 대기 시간을 편집했습니다”를 표시한다. 진단 모드 영상은 실제 구매·로그인 성공의 증거로 사용하지 않는다. 사용자가 실제로 쉬었다는 연출·주장은 별도 동의를 받은 관찰 자료가 있을 때만 추가한다.

## 게시 초안 4개

### 1. 제품 소개

작업에 몰입하다 쉬는 시간을 놓친 적 있나요?
Unfold는 작은 데스크톱 동료가 정해 둔 시간에 휴식을 초대하는 앱이에요.
지금 쉬거나 조금 뒤로 미루고, 완료한 휴식은 돌아보기에서 확인할 수 있어요.
Mochi와 잠깐 쉬고, 내 리듬으로 돌아오세요.

CTA: 확인된 다운로드 페이지 연결. 첨부: 30초 데모.

### 2. 사용 흐름

Unfold로 휴식을 시작하는 순서:
1. 작업 간격과 휴식 시간을 정하고 저장해요.
2. 펫의 말풍선이 나타나면 **휴식 시작**을 눌러요.
3. 쉬었다면 **완료**를 눌러 기록해요.

아직 바쁘다면 **n분 뒤에**로 미룰 수도 있어요. 완료 버튼을 눌러야 기록이 남아요.

CTA: 사용법 안내 연결. 첨부: 설정·말풍선·돌아보기 3장.

### 3. 내 동료 선택

Mochi, 보리, 강아지, 고슴도치, 펭귄.
Unfold에서 오늘 함께할 동료를 골라 보세요.
이미지·GIF·MP4로 펫 팩을 만들고, 지원되는 GLB 모델에는 상황별 애니메이션을 연결할 수도 있어요.

사용할 파일의 권리와 지원 조건을 먼저 확인해 주세요. 모델에 없는 애니메이션을 새로 만들지는 않아요.

CTA: 펫 만들기 안내 연결. 첨부: 권리 확인된 기본 자산과 직접 제작 자산만 사용.

### 4. Beta 피드백 모집

Unfold Beta의 휴식 흐름을 다듬고 있어요.
알림을 알아차렸는지, 시작·미루기·완료가 이해되었는지, 펫이 작업을 방해하지 않았는지 궁금합니다.
사용 중 불편한 점이 있다면 앱 버전, 운영체제와 재현 순서를 알려 주세요.

CTA: 확정된 지원 채널 연결. Beta 참여를 무료 체험으로 표현하지 않는다. 버그 제보에 결제 토큰·비밀번호·카드 정보를 요청하지 않는다.

## 가격 안내 초안

다운로드는 무료이며 사용하려면 Google 로그인 후 1회 구매가 필요합니다. 현재 계획 가격은 한국 **4,900원**, 해외 **US$3.99**이며 무료 체험은 없습니다.

가격은 `docs/mvp.md`의 판매 계획 기준이다. 실제 결제 통화·세금·최종 금액, 주문 권한 부여와 구매 복원은 운영 결제 검증 후 확정 안내한다. “영구 업데이트”, 기기 수 무제한, 오프라인 사용 보장, 환불 기간은 합의된 정책과 검증 근거 없이 추가하지 않는다.

## GLB 설명에 반드시 포함할 조건

- 로컬 개발본 기준: 32 MiB 이하 GLB 2.0, 내장 PNG, 비압축 삼각형 최대 10만 개, 정점당 최대 4개 관절 가중치.
- JPEG·외부 파일 참조·압축 메시·필수 확장·sparse accessor는 지원하지 않는다. 동작 길이 120초 초과 및 잘못된 시간 키는 오류로 안내한다.
- CPU 투명 렌더링 최대 20fps. 게임 전용 셰이더·조명·그림자를 그대로 재현하지 않으며 복잡한 모델의 품질·성능은 달라질 수 있다.
- BLEND 반투명 재질과 중복 동작명 대응, 공통 메모리 개선은 로컬 수정 기준이다. 공개 배포 확인 전에는 공개 버전의 기능으로 홍보하지 않는다.
- 사용자 모델과 텍스처의 사용·배포 권리는 사용자가 확인해야 한다. 검증용 외부 모델을 마케팅 이미지나 배포물에 포함하지 않는다.

## 게시 전 남은 결정과 검증

| 항목 | 담당 | 완료 기준 |
|---|---|---|
| 공개 버전·Windows 입력·GLB 성능 | 개발·QA | 실제 배포물과 대상 OS 증거 확인 |
| 실제 OAuth·결제·구매 복원 | 계정·운영 | 운영 환경 시나리오 결과 기록 |
| 세금·환불·업데이트·기기 수 정책 | 제품 책임자 | 승인된 정책과 안내 URL 확정 |
| 다운로드·문의·개인정보 URL | 운영 | 실제 링크와 접수 경로 확인 |
| 자산 권리·화면 개인정보 | 콘텐츠 담당 | 사용 허락 및 비식별 화면 확인 |

성과 기록은 채널이 이미 제공하는 노출·링크 클릭 집계, 기존 다운로드 집계가 있는 경우 해당 자료, 주문·환불·자발적 문의를 사용한다. 앱 행동 추적을 새로 추가하지 않는다. 다운로드와 주문을 개인별로 연결한 구매 전환은 현재 측정된 값으로 표현하지 않는다. 임의 성장률·전환 목표를 기존 성과로 표기하지 않는다. 외부 게시·광고 집행은 이 문서 작성에 포함하지 않는다.
