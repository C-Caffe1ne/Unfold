# Unfold 지원 FAQ와 접수·복구 초안

작성: 2026-10-06. 외부 공개 전 운영 담당 검토용.
근거: 최신 개발본 `docs/mvp.md`, `docs/glb-pets.md`, `AppRuntime.Account.cs`, `AccountScreenContent.cs`, `AccountScreenModel.cs`.

## FAQ

**다운로드하면 바로 사용할 수 있나요?**
현재 판매 계획은 무료 다운로드 후 Google 로그인과 1회 구매입니다. 한국 4,900원, 해외 US$3.99이며 무료 체험은 없습니다. 실제 결제의 최종 금액은 결제 화면을 확인하세요. 운영 결제 검증과 정책 확정이 남아 있습니다.

**결제했는데 구매가 확인되지 않아요.**
구매한 Google 계정인지 확인하고 앱의 구매 확인을 다시 시도하세요. 네트워크 연결을 확인한 뒤에도 같으면 앱 버전·OS·표시 메시지·결제 시각과 주문 식별자를 지원 담당에게 전달하세요. 추가 결제부터 안내하지 않습니다. 주문 식별자는 비공개 지원 경로에서만 받습니다.

**로그인 정보 확인에 실패하거나 계정 화면으로 돌아갔어요.**
현재 코드는 접근 권한을 주기적으로 다시 확인하며, 세션 만료·권한 비활성·확인 실패 시 타이머와 펫 표시를 중지하고 계정 화면을 표시합니다. 네트워크 확인 후 재시도하고 인증이 필요한 경우 다시 로그인하세요. 네트워크 장애만으로 구매 취소라고 단정하지 않습니다.

**오프라인에서도 계속 쓸 수 있나요?**
현재 코드에는 권한 재확인 실패 시 사용을 잠그는 경로가 있습니다. 오프라인 사용·구매 복원을 보장할 수 없으며, 오프라인 정책과 운영 검증은 아직 확정되지 않았습니다.

**“로그인 정보를 안전하게 저장하거나 삭제하지 못했어요”가 나와요.**
OS 보안 저장소 접근을 확인하세요. 계속되면 OS·앱 버전과 메시지를 접수합니다. 토큰을 수동 복사하거나 보안 저장소 전체를 삭제하는 방법은 안내하지 않습니다.

**로그아웃 메시지에 서버 종료를 확인하지 못했다고 나와요.**
앱의 로그아웃과 서버 세션 종료 확인은 별개입니다. 서버 세션 종료가 확인되지 않은 상태로 접수하고 네트워크 상태를 확인합니다. 서버에서도 로그아웃되었다고 확답하지 않습니다.

**휴식 기록이 없어요.**
휴식을 시작한 뒤 **완료**를 눌러야 기록됩니다. 미루기·중지·단순히 시간이 끝난 경우에는 완료 기록이 추가되지 않습니다. 최근 7일 요약·이전 기간·CSV 내보내기를 확인하세요. 기록은 로컬이며 최대 2,000개, 새 기록 추가 시 90일이 지난 기록을 정리합니다.

**펫이 사라졌어요.**
펫 숨김 설정과 계정 접근 상태를 확인하세요. 권한 확인 실패 시 펫이 숨겨질 수 있습니다. 숨김을 켜 둔 펫도 새 휴식 알림 때 잠시 나타날 수 있습니다. 문제 접수 전 설정·현재 타이머 상태를 기록하세요.

**GLB가 열리지 않거나 다르게 보여요.**
32 MiB 이하 GLB 2.0, 내장 PNG, 비압축 메시 등의 지원 조건을 확인하세요. JPEG·외부 파일 참조·압축 메시·필수 확장·sparse accessor는 지원하지 않습니다. 게임 셰이더·조명·그림자의 동일 재현은 보장하지 않습니다. BLEND 등 최신 로컬 수정이 공개 버전에 포함됐는지 먼저 확인하세요.

**파일 옆 휴지통과 펫 삭제의 차이는 무엇인가요?**
3D 파일 행의 휴지통은 현재 초안의 모델·행동 연결·미리보기만 비웁니다. 이름·원본 파일·저장된 펫은 유지합니다. **펫 삭제**는 확인 후 설치된 editable GLB 펫을 목록에서 제거하며 사용 중이면 기본 펫으로 전환합니다.

**환불받을 수 있나요?**
확정된 환불 정책과 실제 결제 사업자 절차를 확인한 뒤 안내합니다. 지원 담당이 자동 승인하거나 즉시 환불을 약속하지 않습니다. 주문 상태 확인과 책임자 판단으로 연결합니다.

## 접수 템플릿

- 발생 시각과 시간대:
- 앱 버전·설치/다운로드 출처:
- OS 버전·CPU 종류:
- 화면에 표시된 정확한 메시지:
- 기대한 동작 / 실제 동작:
- 재현 단계와 빈도:
- 타이머·펫·로그인 상태:
- 관련 파일 형식·크기(파일 제공은 필요성과 권리 확인 후):
- 스크린샷 또는 최소 로그(개인정보 제거):
- 구매 문제인 경우: 구매한 계정과 현재 계정의 일치 여부, 결제 시각, 비공개 주문 식별자:

비밀번호, 세션·접근 토큰, 카드 번호, 전체 보안 저장소, 다른 사용자 정보는 요청하지 않는다. 로그·모델 원본은 필요한 최소 범위만 받는다. 공개 댓글에서는 주문·계정 정보를 받지 않고 비공개 경로로 전환한다.

## 분류·조치

| 유형 | 초기 확인과 복구 | 이관·종료 기준 |
|---|---|---|
| 로그인 실패 | 연결·브라우저 복귀·계정 확인, 사용자 의사에 따라 재시도 | 반복 실패나 callback 오류는 계정 담당; 성공 화면 확인 시 종료 |
| 세션 만료·인증 필요 | 재로그인 안내; 구매 이력이 없다고 단정하지 않음 | 동일 계정 권한 조회 결과 확인 |
| 권한·구매 확인 실패 | 구매 계정 일치, 재확인; 주문 상태 운영 조회 | 결제 담당이 결제·권한 상태 확인; 중복 결제 유도 금지 |
| 네트워크·서버 오류 | 온라인 상태 확인 후 재시도 | 반복·다수 발생은 서비스 장애; 복구 후 사용자 확인 |
| 보안 저장소 오류 | OS 보안 저장소 접근 상태 확인 | 계정 담당; 삭제·재설치로 데이터 손실 유발 금지 |
| GLB 호환성·느림 | 버전·지원 조건·파일 크기·환경·재현 확보 | GLB 담당, 권리 확인된 최소 재현 파일로 검증 |
| Windows 클릭·드래그 | 실제 OS·표시 배율·모니터·재현 영상 확보 | Windows 담당; headless 통과로 해결 종료 금지 |
| 기록·설정 저장 | 원본 데이터 보존 후 정확한 증상 확인 | 저장 계약 담당; 원본 삭제·초기화 안내 금지 |
| 환불 요청 | 주문 식별자와 사유를 비공개로 수집 | 제품·결제 책임자에게 이관, 정책에 따른 결과 전달 |

우선순위: 결제 후 전체 사용 불가·반복 크래시·데이터 손실 가능성은 우선 조사, 주요 흐름 오류는 다음, 외형·문의는 일반으로 분류한다. 응답·해결 시간을 계약처럼 약속하지 않는다. 모든 케이스는 담당자, 재현 여부, 다음 조치, 사용자에게 알린 사실을 기록한다.

## 답변 문구

구매 확인: “구매한 Google 계정과 앱에 로그인한 계정이 같은지 확인해 주세요. 구매 확인을 다시 시도한 후에도 같다면 앱 버전, 표시 메시지와 결제 시각을 알려 주세요. 주문 정보는 비공개 지원 경로에서 확인하겠습니다.”

네트워크: “이용 권한을 확인하는 과정에 실패한 상태입니다. 인터넷 연결을 확인하고 다시 시도해 주세요. 계속되면 정확한 메시지와 앱 버전을 알려 주세요.”

환불: “요청을 접수했습니다. 주문 상태와 적용되는 환불 정책을 확인한 뒤 담당자가 결과를 안내하겠습니다.”

## 출시 전에 남은 정책

지원 연락처·운영시간·목표 응답 시간, 환불 조건·처리 주체·처리 기간, 세금·결제 통화, 기기 수·계정 이전, 업데이트 제공 범위, 오프라인 접근, 구매 복원 기준, 수집 로그 범위·보관/삭제·접근 권한을 책임자가 확정해야 한다.
실제 OAuth·운영 결제·복원·세션 만료·네트워크 중단·환불 후 권한 변경을 게시본으로 검증한다. 이 문서는 법률·환불 정책 확정이나 운영 거래 성공의 증거가 아니다.
