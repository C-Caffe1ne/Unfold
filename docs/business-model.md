# Unfold Cat MVP 방향 및 비즈니스 모델 초안

2026-09-13 · 최초 유료 가치 가설 기록
2026년 10월 8일 · `codex/remove-unused-features`의 `1.1.2-beta` 현재 기능과 문서 정합성 갱신
2026-09-27 · 무료 체험 제외, 국내 4,900원 / 해외 US$3.99 일회성 구매로 확정

상품 구성은 ‘캐릭터 팩만 검증’ → ‘개인화 Plus + 펫 팩’을 거쳐 현재
**무료 다운로드 + 단일 유료 앱**으로 정리했다. 자세한 상품 구성은
[제품 방향](product-direction.md), 실제 구현은 [MVP 범위](mvp.md)에 있다.
시장 규모, 실제 잔존율, 지불 의사, 전환율, 획득 비용은 아직 **미확인**이다.

## 1. 현재 방향 재확인

| 구분 | 확인된 사실과 그 의미 |
|---|---|
| 제품 | Windows/macOS의 C#·Avalonia 데스크톱 휴식 동료. 작업 시간에 맞춰 펫의 휴식 말풍선을 표시하고, 사용자가 휴식을 시작하면 선택한 펫이 반응한다. [MVP 범위](mvp.md), [README](../README.md) |
| 사용 경험 | 트레이/메뉴바 타이머, 유휴 시 일시 정지, 일시정지·정지, 펫 표시·숨김, 기본 휴식 안내, 미루기·휴식 시작·명시적 완료와 로컬 기록을 제공한다. 루틴/업무 프로필 편집과 수동 즉시 휴식은 일반 UI에 없다. 실제 신체 활동과 사용 지속성은 별도 관찰이 필요하다. [MVP 범위](mvp.md) |
| 자산 | 기본 펫은 Mochi·보리·강아지·고슴도치·펭귄 5종이다. 기존 로컬 캐릭터를 불러오고 `.unfoldpet` 파일을 미리보기·설치·갱신·재설치할 수 있다. 미디어·GLB 커스텀 팩 제작과 계정·결제·권한 확인 경로가 앱에 연결되어 있다. 실제 운영 로그인·구매·재설치 복원은 별도 검증이 필요하다. [팩 안내](pet-packs.md), [MVP 범위](mvp.md) |
| 출시 준비 | 공개 Beta v1.1.1의 Mac arm64/x64 서명·공증, 공개 다운로드 파일, Mac ARM64·Windows x64 CI의 실제 업데이트 교체·재시작을 검증했다. 1.1.2는 후속 개발본이며 새 공개 설치본은 없다. 물리 Windows 입력·기기별 사용, 실제 OAuth/결제와 최종 장시간 메모리 검증은 별도다. [검증 안내](verification.md), [플랫폼 안내](cross-platform.md) |

**방향 판단 — 유지하며 검증.** Unfold의 핵심은 기능이 많은 운동 앱이 아니라,
책상에서 오래 일하는 사람이 귀여운 동료의 신호를 보고 짧게 몸을 움직이도록 돕는
경험이다. “부드럽게 환기한다”는 포지셔닝은 아직 가설이다. 펫의 휴식 말풍선이
집중에 미치는 영향은 실제 사용으로 확인해야 한다. Mochi의 기지개는 사용자가
휴식을 시작할 때 재생한다. Garden 실험이나 에디터 확장은 이 BM의 전제가 아니다.

## 2. 고객과 가치 제안

- **첫 고객 가설:** 하루 대부분을 PC에서 일하고, 기존 휴식 알림을 무시하거나
  끄지만 작은 시각적 동료는 좋아하는 개인 사용자. 개발자·디자이너·글쓰기
  종사자는 모집 가능한 초기 집단이며, 전체 시장 규모를 대표하지 않는다.
- **해결할 일:** 작업 흐름을 지나치게 끊지 않으면서 휴식 시점을 알아차리고
  실제로 한 번 기지개를 켜기. 의료 효과나 통증 치료는 약속하지 않는다.
- **제안 문구:** “Mochi와 잠깐 쉬고, 내 리듬으로 돌아오세요.”
- **차별화 가설:** 정확한 타이머 자체보다, 화면에 머무는 오리지널 캐릭터와
  휴식 순간의 연결이 알림 수용성과 재사용을 높일 수 있다. 사용자 관찰 전에는
  경쟁 우위로 확정하지 않는다.

## 4. 확정 BM

**앱 하나를 일회성으로 판매한다. 국내 4,900원 / 해외 US$3.99.**
다운로드에는 가입이나 결제를 요구하지 않는다. 앱을 실행한 뒤 Google로 로그인하고,
계정에 구매 권한이 없을 때 결제한다. 기존 구매자는 복원해 사용한다.
무료 체험, 체험 만료, 재설치로 체험 초기화를 막는 기능은 만들지 않는다.

타이머·말풍선 알림·기본 펫 5종·펫 상호작용·테마·로컬 기록·CSV·커스텀 팩을
단일 상품에 포함한다. 구독이나 기능별 Free/Plus 분기를 두지 않는다.
별도 펫 팩 상점·클라우드 동기화는 이번 범위에 포함하지 않는다.

Supabase로 최소 계정·주문·구매 권한을 관리한다. 휴식 기록·설정·펫 파일은 기기에 남긴다.
행동 분석이나 사전 체험 사용자 모집을 출시 조건으로 두지 않는다. 판매 가격은 확정했지만,
실제 수요·전환율·수익성은 검증되지 않았다.

## 5. 결제·배포 경계

국내 4,900원과 해외 US$3.99를 독립 가격으로 관리한다. 서버가 상품 가격을 결정하고
사용자가 보낸 금액이나 결제 완료 화면만으로 사용 권한을 부여하지 않는다.
Lemon Squeezy의 원화 표시는 실제 원화 청구와 다르므로 국내 PG 선택을 선행한다.
공급자 문서와 가격·통화 검증 항목은 [출시 계획](plans/2026-09-27-paid-launch.md)에 있다.

세금 포함 여부, 사용 기기 수, 업데이트 제공 범위, 오프라인 권한 기간, 환불·지원 정책은
운영 전에 확정한다. 이 미정 항목을 출시 약속이나 클라이언트 하드코딩으로 만들지 않는다.
구매자의 통신 오류를 미구매로 바꾸거나 기존 데이터를 삭제하지 않는다.

공헌이익은 확정 가격에서 결제·정산 수수료, 해당 세금, 환불·지원 비용을 차감해 확인한다.
호스팅·서명·공증 비용은 별도다. 이전 $12.99/$14.99 시험 가격과 체험 전환 목표는 폐기했다.

## 6. 실행과 검증

[출시 계획](plans/2026-09-27-paid-launch.md)의 P0~P7을 따른다.
도메인 전에는 화면 시안·Supabase 스키마·서버 권한 검사·인증 클라이언트와 테스트를 준비한다.
개발 프로젝트와 테스트 키가 준비되면 실제 Google 로그인과 테스트 결제를 연결한다.
운영 결제는 판매자 설정, 공개 정책, 서명·공증, 실제 Mac/Windows 구매 흐름 검증 후 연다.

자동 검사·공급자 테스트·실제 운영 결제·수요 근거를 구별한다. 거래 기록을 구매 복원과
환불 처리에 사용하되 휴식 이력이나 사용 행태를 서버에 모으는 기능은 이번 범위에 없다.
