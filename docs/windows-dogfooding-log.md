# Windows Unfold Beta 실기 체크리스트

2026년 10월 8일 · 개발 `1.1.2-beta` 또는 공개 `1.1.1-beta`의 실제 Windows 동작을 기록하는 양식이다.
시험한 설치 파일·소스 버전을 아래에 정확히 기록한다. **이 양식에는 물리 기기 실행 결과가 기입되지 않았다.**
공개 1.1.1의 Windows native CI 설치·실행·업데이트 결과는
[배포 검증](validation/2026-10-07-beta-v1.1.1-release.md)에 따로 기록했다.
자동 테스트와 다른 OS의 결과를 여기에 옮기지 않는다. 새 세션은 이 양식을 참고해
`docs/validation/YYYY-MM-DD-windows.md`처럼 기록을 만들고, 아래 환경 정보를 채운다.
본문을 복사했다면 상대 링크도 새 파일 위치에 맞게 조정한다.
제품 범위는 [MVP 문서](mvp.md), 검증 수준은 [검증 안내](verification.md)를 따른다.

원격 데스크톱을 사용하지 않고 실제 입력 장치로 진행한다.

## 실행·종료

- [ ] 전체 압축을 풀고 `Unfold.exe`가 실행된다.
- [ ] 일반 시작에서는 계정·구매 권한 확인을 거친다. 콘솔 창 없이 실행되고, 권한이 있는 계정에서 펫과 트레이가 나타난다. 진단 모드의 구매 우회를 별도 기록한다.
- [ ] 설정이 열리고, X로 닫으면 트레이에서 계속 실행된다.
- [ ] 다시 실행하면 중복 펫 없이 기존 설정 또는 계정 화면이 활성화된다.
- [ ] 종료 확인에서 취소하면 계속 실행되고, 승인하면 프로세스·펫·트레이가 모두 사라진다.
- [ ] `unfold.log`에 시작·종료 실패가 없다.

## 화면과 입력

- [ ] 브라우저·에디터·터미널 위에서 투명 배경과 펫 크기가 정상이다.
- [ ] 투명 영역을 클릭하면 아래 앱에 입력이 전달된다.
- [ ] 불투명 영역은 펫에 입력이 전달되고 드래그된다.
- [ ] 드래그를 끝낸 뒤에도 투명 영역 클릭 통과가 유지된다.
- [ ] 우클릭 메뉴의 **설정**과 **펫 숨기기**가 동작하며 수동 즉시 휴식 항목은 없다.
- [ ] 기본 펫의 짧은 클릭은 지정된 클릭 반응으로 처리하고 휴식 시작으로 오인하지 않는다. 펫별 할당 동작과 실제 결과를 기록한다.
- [ ] Win+D, 잠금·해제, 창 전환 후 펫이 정상적으로 보인다.
- [ ] 밝은 배경·어두운 배경에서 이미지 가장자리와 클릭 영역이 자연스럽다.


2D 기본 펫과 GLB 펫을 각각 검사한다. 투명 여백뿐 아니라 실루엣 내부의 투명 구멍에서
아래 앱의 클릭·스크롤 전달을 확인하고, 불투명 픽셀의 클릭/드래그와 말풍선 버튼이
아래 앱으로 누출되지 않는지 확인한다. 드래그 중·해제 직후·메뉴 닫기·모델 전환·숨김 복원에서
입력이 막히지 않는지도 확인한다. 100/150/200% DPI와 서로 다른 배율의 모니터를 구분한다.
각 결과에는 아래 앱에서 관찰한 입력, 창 좌표 전후, OS/GPU/DPI와 캡처를 남긴다.

## 배율·모니터

- [ ] 현재 배율에서 이미지와 클릭 영역이 일치한다.
- [ ] 다른 배율을 시험했다면 값과 재시작 여부를 기록했다.
- [ ] 다른 모니터로 드래그할 수 있다.
- [ ] 재시작하면 위치가 복원된다.
- [ ] 서로 다른 배율의 모니터에서도 클릭 위치가 일치한다.
- [ ] 모니터를 분리해도 펫이 화면 밖에 남지 않는다.
- [ ] 시험한 전체화면 앱에서 펫 표시·입력이 의도와 맞는다.

시험할 장비가 없는 항목은 미검증으로 남긴다. 소스에 관련 코드가 있다는 사실만으로
체크하지 않는다. 모니터 분리와 실행 중 배율 변경의 복구는 특히 실제 확인이 필요하다.

## 타이머·휴식

- [ ] 트레이와 Settings의 카운트다운이 일치한다.
- [ ] 진행 중에는 알림 간격 입력이 비활성화되고, 상태 배지가 진행 중으로 표시된다.
- [ ] 일시정지·정지 상태에서만 간격을 1분 단위로 바꿀 수 있다.
- [ ] 간격을 바꾼 뒤 홈의 **저장**으로 반영하며, 재실행해도 저장한 설정이 유지된다. 알림·유휴·미루기 설정의 자동 저장은 별도 확인한다.
- [ ] 홈의 **저장**과 타이머 제어가 최소 640×560 창에서도 잘리지 않는다.
- [ ] 일시정지·재생 아이콘은 남은 시간을 보존하며 멈추고 다시 진행한다.
- [ ] **정지** 확인을 승인하면 저장된 전체 간격을 표시하고, **재생**하면 그 시간부터 시작한다. 취소하면 기존 상태를 유지한다.
- [ ] 정지 상태에서 간격을 바꿔 저장해도 자동 시작하지 않고 **재생**을 눌러야 시작한다.
- [ ] 유휴 기준 이상 입력하지 않으면 유휴 일시정지 상태와 함께 카운트다운이 멈춘다.
- [ ] 입력을 재개하면 카운트다운이 다시 진행된다.
- [ ] sleep/wake 동안 경과한 시간이 작업 시간에 더해지지 않는다.
- [ ] 자동 타이머가 펫에 연결된 휴식 말풍선을 표시한다. 별도 휴식 창이나 OS toast를 기대하지 않는다.
- [ ] **휴식 시작**을 누르면 선택된 펫이 지정된 휴식 동작을 재생한다. 기본 펫의 스트레칭 후 이동·대기 전환을 확인한다.
- [ ] 진행 중 휴식의 클릭·드래그·메뉴 조작이 세션 완료 기록을 임의로 추가하지 않는다.
- [ ] 초대/휴식 세션 동안 작업 타이머가 보류되고, 같은 알림을 다시 요청해도 중복 말풍선·효과음이 생기지 않는다.
- [ ] 설정·트레이·펫 메뉴에 수동 즉시 휴식 항목이 없다.
- [ ] 초대/휴식 중 **정지**를 승인하면 완료 기록 없이 세션·말풍선이 닫힌다.
- [ ] **완료**를 눌러야 완료 기록이 추가된다. 카운트다운 종료는 자동 완료가 아니며 초과 시간으로 표시된다.
- [ ] 초대의 **n분 뒤에**와 30초 자동 미루기가 수동 일시정지·완료 기록을 보존한다.
- [ ] 방해금지/전체화면 상황의 실제 말풍선·효과음 결과를 기록했다. 자동 회의 감지나 OS toast를 구현된 기능으로 가정하지 않는다.

## 표시 설정·로그인

- [ ] 트레이·설정의 펫 표시 상태가 일치한다.
- [ ] 숨긴 펫이 새 휴식 알림 때 잠시 나타나고, 저장된 표시 설정은 숨김으로 유지된다. 초대 만료·미루기 뒤 다시 숨는지 확인한다.
- [ ] 펫 표시를 켜면 다시 표시되고 위치가 유지된다. **펫 숨기기**는 현재 말풍선을 숨기되 열린 세션의 완료를 추가하지 않는다.
- [ ] 재시작 후 표시 설정이 유지된다.
- [ ] 최종 설치 위치에서 Launch at login을 켜고 등록된 경로가 일치한다.
- [ ] 실제 OS 로그아웃·로그인 후 백그라운드 시작이 적용된다. 구매 권한 복원이 성공하면 설정 창이 자동으로 열리지 않는지, 인증/권한 확인이 필요한 경우 계정 화면이 표시되는지 각각 기록한다.
- [ ] Launch at login을 끈 뒤 등록이 해제된다.

레지스트리 값만 확인한 경우와 실제 로그인 실행을 구분한다:

```powershell
Get-ItemProperty 'HKCU:\Software\Microsoft\Windows\CurrentVersion\Run' -Name Unfold
```

## 배포와 장시간 사용

- [ ] 실제 다운로드 받은 배포물에서 설치·실행 경고와 서명 상태를 기록했다.
- [ ] 60–90분 동안 앱이 응답하고 펫이 사라지거나 중복되거나 멈추지 않는다.
- [ ] 시작·종료 시 CPU/메모리와 팬 소음을 기록했다.
- [ ] 알림이 집중을 방해했는지, 펫·말풍선·효과음이 중복되어 느껴졌는지 기록했다.
- [ ] 알림을 알아차렸는지, 실제로 스트레칭했는지 기록했다.
- [ ] 다음 날에도 앱을 켜 두고 싶은지 기록했다.

로컬에서 만든 실행 파일과 실제 다운로드 파일의 신뢰 검증은 다르다. 이번 세션에
시험하지 않은 서명·설치 경로를 배포 준비 완료로 표시하지 않는다.
