# MVP improvement plan — 2026-09-12

목표: 현재 데스크탑 동료와 스트레칭 알림 MVP의 신뢰성과 배포 준비도를 개선한다. 신규 기능보다 오류 복구, 비동기 수명 관리, 화면 상태 일치, 정확한 배포 안내를 우선한다.

기준점: `release/mvp`, `dc77ab9`. Windows에서 `dotnet test Unfold.slnx -c Release --no-restore` 36개 통과. 이 결과는 실제 macOS 동작이나 OS 알림 검증을 의미하지 않는다.

| 담당 | 우선순위 | 조사 근거 및 작업 | 완료 기준 |
|---|---|---|---|
| Claude 1 | P1 | 설정 로드/저장 검증과 시작 시 오류 복구 경로 확인 | 재현한 오류 수정, 설정 회귀 테스트, 데이터 보존 |
| Claude 2 | P1 | SetFrames의 타이머 재시작과 숨김/종료 후 비동기 React 완료 점검 | 숨김·해제된 뷰에서 작업이 재개되지 않음, 정상 재생 유지 |
| Claude 3 | P2 | 설정 저장 실패 후 표시 상태, 비동기 미리보기, MVP와 맞지 않는 화면 제목 개선 | 실제 상태와 컨트롤 일치, 최신 선택 표시, 실패 후 복구 |
| Claude 4 | P2 | 배포 README가 숨겨진 편집기 기능을 안내하는 불일치 수정 | MVP에 맞는 문서 및 플랫폼별 출시 검증 목록 |

코드상 위험은 재현 전까지 확정 버그로 취급하지 않는다. 각 담당은 독립된 파일을 수정하고 `docs/agent-reports/`에 근거와 결과를 남긴다. 기존 테스트 파일과 공통 프로젝트 설정은 관리자와 조정 없이 수정하지 않는다. 관리자는 변경을 검토하고 전체 테스트를 실행한다.

범위 밖: 픽셀 에디터 기능 확대, Swift 전환, 계정·클라우드·스토어, 의존성 업그레이드. 자동 커밋·푸시·배포는 하지 않는다.
