# 스트레칭 말풍선 알림

## 알림과 휴식

- 작업 타이머에 5분이 남으면 펫이 최대 5초 동안 미리 알려 준다. 작업 간격이 5분 이하면 사전 안내를 생략한다. 작업 중지·일시정지·자리 비움 중에는 새 사전 알림을 만들지 않는다.
- 알림 시간이 되면 **n분 뒤에 / 휴식 시작**을 보여 준다. 기본 n은 5분이며 설정에서 1~60분으로 바꾼다.
- 초대 말풍선을 표시한 뒤 30초 동안 응답하지 않으면 설정된 다시 알림 시간만큼 자동으로 미룬다.
  갱신이나 중복 알림 요청으로 이 시간이 연장되지 않는다. 휴식을 시작하거나 직접 미루면 자동 미루기를 취소한다.
- 홈에서 휴식 시간을 1~10분으로 설정한다. **휴식 시작**을 누르면 초대를 열 때 저장된 휴식 시간부터
  남은 시간을 표시한다. 설정을 나중에 바꿔도 이미 열린 휴식 시간은 바뀌지 않는다. 그 아래 **완료**는 바로 누를 수 있다.
- 시간이 지나면 **+00:01**처럼 초과 시간을 계속 표시한다. **+60:00**에서 멈추며 자동 완료하지 않는다.
- 사용자가 **완료**를 눌러야 기록하고 완료 안내·효과음을 낸다. 완료 안내는 5초 뒤 사라진다. 진행 중인 휴식은 자동으로 닫지 않는다.
- 알림·휴식 중에는 작업 타이머를 유지한다. 완료 후 전체 작업 간격으로, 미루기 후 지정한 간격으로 다시 예약한다. 수동 일시정지 상태는 유지한다.
- 작업 타이머 **중지**는 확인 창에서 승인하면 진행 중 알림·휴식을 취소하고 완료를 기록하지 않는다.
- 시스템 절전이나 UI가 10초 넘게 멈춘 구간은 휴식 시간으로 계산하지 않는다.

5분 이하의 미루기와 작업 간격이 5분 이하인 경우에는 ‘5분 전’ 안내를 내지 않는다.
완료 안내가 표시 중이면 완료 안내를 우선한다.

## 펫과 말풍선

펫 위에 커서를 올리면 작은 말풍선 상단에 현재 시각(`오전/오후 hh:mm`, 예: `오후 01:07`), 하단에 다음 스트레칭까지
남은 시간(`mm:ss`)을 표시한다. 일시정지·중지·자리 비움 상태는 시간 옆에 함께 표시하고,
중지 중에는 설정한 전체 간격을 보여 준다. 현재 시각에는 초를 표시하지 않는다.
시계·남은 시간·휴식 타이머의 텍스트가 바뀌면 180ms 동안 위치와 투명도가 짧게 전환된다.
말풍선·펫·창 크기와 위치는 바꾸지 않으며, 숨겨지거나 닫히면 전환 타이머를 중지한다.
커서를 벗어나거나 펫을 숨기면 닫힌다.
알림·휴식 말풍선과 디버그 미리보기가 있을 때는 해당 알림을 우선하며, 호버는 소리·기록·예약을 만들지 않는다.
호버 말풍선은 240×96px이며 설정한 방향을 우선한다. 화면 끝에서는 펫 위치를 유지하고
말풍선을 다른 방향으로 배치한다. 누르기·드래그 중에는 열린 시간 말풍선과 창 크기를 유지한다.
스퀴시·클릭 프레임이 바뀌어도 펫의 고정된 영역에서 커서가 벗어날 때까지 유지하며,
우클릭 메뉴를 열면 시간 말풍선을 잠시 숨긴다.

기존 가운데 플로팅 알림 창과 OS 알림은 사용하지 않는다. 말풍선과 펫을 하나의 투명 창 안에
배치해 펫을 드래그하면 함께 이동한다. 내비게이션의 **설정 → 알림 설정**에서 위·아래·왼쪽·오른쪽을
선택한 뒤 우측 하단의 **저장**을 누른다. 화면 끝에서는 말풍선을 포함한 창을 작업 영역 안으로 옮긴다.
말풍선 본체는 외곽선을 유지한다. 삼각형 꼬리는 바깥쪽 두 변에만 같은 외곽선을 적용하고,
본체와 맞닿는 변은 그리지 않아 테두리가 연결되어 보이게 한다.

펫 우클릭 메뉴에는 **설정**, **펫 숨기기**를 표시한다. 숨기기는 펫 표시 설정을 저장하고
현재 말풍선과 펫을 함께 숨기지만 진행 중인 휴식과 기록은 유지한다. 현재 알림의 갱신으로 다시 나타나지 않으며,
다음 새 알림이나 **휴식 알림으로 이동**에서 다시 표시한다. 트레이에는 초대 중 **휴식 대기 중**,
휴식 진행 중 **휴식 중**을 표시한다. **휴식 알림으로 이동**은 초대의 ‘휴식 시작’ 또는 진행 중의 ‘완료’ 버튼으로 포커스를 옮긴다.
사용자가 이 메뉴를 선택했을 때만 창을 활성화하며, 자동 알림은 기존처럼 작업 포커스를 가져오지 않는다.
말풍선 텍스트는 가운데 정렬하며, 사전·완료 문구는 말풍선 세로 중앙에도 배치한다.
너비는 320px, 높이는 사전 96px·초대 159px·휴식 196px·완료 113px이며 네 방향 배치에 같은 높이를 사용한다.
펫을 숨겨 둔 경우 알림 동안만 잠시 표시하고, 미루기·취소·완료 안내 종료 후 다시 숨긴다.
저장된 펫 표시 설정은 바꾸지 않는다.

선택한 펫의 애니메이션 파일을 읽지 못해도 휴식 알림과 효과음 요청은 유지한다.
이때 이미 읽어 둔 펫 시트의 첫 이미지를 표시하고 미루기·휴식 시작·완료를 계속 사용할 수 있다.
선택한 펫이나 표시 설정은 변경하지 않는다. 파일이 복구되면 다음 알림 또는
**휴식 알림으로 이동**에서 다시 읽는다. 실패한 파일을 반복해서 자동 로딩하지 않는다.

홈의 **펫 크기** 슬라이더는 50~150%를 10% 단위로 저장한다. 말풍선 폭과 글자 크기는
유지하고 펫 영역과 말풍선 위치만 새 크기에 맞춰 다시 계산한다.

설정 하단의 **디버그 도구 사용**을 켜면 5분 전·스트레칭·휴식 진행·완료 상태를 즉시
미리볼 수 있다. 이 미리보기는 실제 작업 타이머, 알림 세션, 완료 기록, 다시 알림 예약,
효과음 호출 횟수를 바꾸지 않으며 페이지 이동·창 숨김·미리보기 종료 시 닫힌다.

## 효과음

스트레칭 시간과 완료 버튼에 각각 다른 기본 효과음을 제공한다. ‘5분 전’ 안내에는 소리를 내지 않는다.
설정 탭에서 완료 알림 아래의 **알림 효과음 사용**을 끄고 **저장**하면 두 효과음이 모두 꺼진다.
**스트레칭 알림**과 **완료 알림**의 **파일 가져오기**로 사용자 WAV·MP3를 가져오거나 **기본**으로 복원한다.
MP3는 로컬에서 모노·44.1 kHz·16비트 PCM WAV로 변환하며 원본은 수정하지 않는다.
파일당 5 MiB·30초 이하이며 초과 시간은 잘라 저장하지 않고 거부한다.
파일 선택과 기본 복원도 **저장**을 눌러야 저장된다. **취소**하면 마지막 저장값으로 돌아간다.
설정이 달라졌을 때만 저장 버튼이 활성화된다. **재생 / 중지 아이콘 버튼**으로 저장 전 소리를 확인할 수 있으며,
알림을 꺼 둔 상태에서도 명시적으로 미리들을 수 있다. 미리듣기는 한 번에 하나만 재생하고 페이지 이동·창 숨김 시 중지한다.

**전체 소리**, **스트레칭 알림**, **완료 알림**의 세 슬라이더로 각각 0~100%를 조절한다.
실제 음량은 전체 값과 해당 알림의 개별 값을 곱해 적용한다. 전체 80%·완료 50%이면 완료 소리는 40%다.
각 슬라이더의 왼쪽에 음량 아이콘을 표시하고 퍼센트 텍스트는 표시하지 않는다. 0은 음소거, 1~49는 작은 소리, 50~100은 큰 소리다.
개별 슬라이더 오른쪽에 **재생 / 중지 아이콘 버튼**을 배치하고 전체 소리에는 미리듣기를 두지 않는다. 재생 완료·중지·실패 시 재생 아이콘으로 돌아온다.
변경한 세 값은 저장 전 미리듣기에 반영되며, **저장** 후 실제 알림에 적용된다. **취소**는 마지막 저장값으로 되돌린다.
전체 0%는 두 소리 모두 무음이고 개별 0%는 해당 소리만 무음이다. 기존 전체 음량을 유지하고 새 개별 값은 100%로 시작한다.
사용자 WAV·MP3 원본과 운영체제의 시스템 음량은 변경하지 않는다.

WAV 입력은 PCM, 8/16비트, 모노/스테레오, 8–96kHz이며 MP3는 위 규격으로 변환한다. 둘 다 최대 30초·5 MiB다.
가져온 WAV 또는 변환한 WAV는 데이터 폴더의 `Sounds/`에 보관하므로 원본 이동·삭제와 무관하게 유지된다.
설정에는 파일의 SHA-256 ID와 표시용 파일명을 저장한다. 파일명은 경로 탐색에 사용하지 않는다.
가져오기·교체·기본 복원·취소·저장 후에는 저장된 설정과 현재 초안에서 쓰지 않는 사본을 정리한다.
탭 이동과 창 숨김은 초안을 유지하므로 해당 사본도 보존한다. 앱 종료 시 버린 초안과 이전 실행의
미사용 사본은 종료·다음 시작 때 정리한다. 재생 중인 파일은 재생이 실제로 끝날 때까지 보존하고,
미리듣기 종료 또는 다음 정리 시 다시 확인한다. 정리 대상은 `Sounds/` 바로 아래의 해시 이름 WAV뿐이며,
기본 효과음·하위 폴더·심볼릭 링크와 가져오기 원본은 정리하지 않는다.
실제 알림에서 손상·유실된 사용자 소리는 기본 소리로 대체한다. 미리듣기에서는 선택한 파일의 실패를 표시한다.
기본 소리는 앱에서 합성하며 외부 음원이나 다운로드가 필요 없다.

`ReminderSounds`는 검증·보관·기본 소리 생성, `ReminderSoundPlayer`는 OS 재생을 담당한다.
macOS는 `/usr/bin/afplay`, Windows는 [PlaySoundW](https://learn.microsoft.com/en-us/previous-versions/dd743680(v=vs.85))의 비동기 파일 재생을 사용한다.
새 소리 형식이나 선택 목록은 보관 계층을 확장해 추가할 수 있다. 효과음 실패는 휴식 완료와 기록을 막지 않는다.

## 기록 호환성

새 기록에는 홈에서 설정한 계획 시간과 별도로 `actualSeconds`를 저장한다. 조기 완료와 초과 시간을 반영하며,
시작 직후 바로 완료하면 0초로 기록할 수 있다. 날짜별 합계는 실제 시간이 있으면 그 값을 쓴다.
과거 기록은 기존 계획 시간을 유지한다. CSV의 기존 열 순서는 보존하고 끝에 `actual_seconds`를 추가했다.
